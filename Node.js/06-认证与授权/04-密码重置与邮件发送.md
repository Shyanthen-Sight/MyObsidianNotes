# 密码重置与邮件发送

> [!abstract] 本篇定位
> 覆盖课程 #112–#114（本篇无视频截图：原始视频未获取到，内容依据课程字幕整理）。用户忘记密码时的标准流程：**邮件里放"一次性短命令牌"**——而不是直接改密码的任何后门。

> [!note] 说明
> 课程 #112–#122 的视频文件未成功下载，本篇及后两篇依据课程字幕与官方文档整理；命令行/代码与课程实现一致。

## 一、流程全景（#112）

```text
① POST /forgotPassword {email}
② 服务器生成 resetToken（随机），库里存【哈希后】的 token + 10 分钟有效期
③ 用 Nodemailer 把【明文 token】放进重置链接发邮件
④ 用户点击链接 → PATCH /resetPassword/:token {password, passwordConfirm}
⑤ 服务器把传入 token 哈希 → 查库比对 + 检查过期 → 设新密码 → 签发新 JWT
```

> [!important] 为什么库里存哈希、邮件发明文
> 邮件一旦泄露（转发/截图/泄露的数据库），数据库里的哈希无法直接用于重置——与密码哈希同一逻辑（[[06-认证与授权/01-用户模型与密码加密|bcrypt 原理]]）。令牌 10 分钟过期，把"泄露窗口"压到最短。

## 二、生成与存储 Reset Token（#113）

```javascript
// User Schema 方法（与 correctPassword 同层，[[04-Mongoose实战/05-虚拟属性与中间件|Schema methods]]）
const crypto = require('crypto');

userSchema.methods.createPasswordResetToken = function () {
  const resetToken = crypto.randomBytes(32).toString('hex');   // 64 位十六进制随机串

  // 库里只存 sha256 哈希 —— 拿到数据库 ≠ 能重置
  this.passwordResetToken = crypto
    .createHash('sha256')
    .update(resetToken)
    .digest('hex');

  this.passwordResetExpires = Date.now() + 10 * 60 * 1000;     // 10 分钟
  return resetToken;                                            // 返回明文（只发邮件用）
};
```

Schema 新增字段：`passwordResetToken: String`、`passwordResetExpires: Date`（`select: false` 亦可，登录时不外泄）。

## 三、Nodemailer 发信（#113）

```bash
npm i nodemailer
```

```javascript
const nodemailer = require('nodemailer');

const sendEmail = async (options) => {
  // 1) 传输器：SMTP 凭据（开发用 Mailtrap 假 SMTP，邮件不会真发出去）
  const transporter = nodemailer.createTransport({
    host: process.env.EMAIL_HOST,
    port: process.env.EMAIL_PORT,
    auth: { user: process.env.EMAIL_USERNAME, pass: process.env.EMAIL_PASSWORD },
  });

  // 2) 邮件选项
  const mailOptions = {
    from: 'CineFlix <admin@cineflix.io>',
    to: options.email,
    subject: options.subject,
    text: options.message,
  };

  // 3) 发送
  await transporter.sendMail(mailOptions);
};
```

forgotPassword 控制器：

```javascript
exports.forgotPassword = asyncError(async (req, res, next) => {
  // 1) 按邮箱找用户
  const user = await User.findOne({ email: req.body.email });
  if (!user) {
    return next(new AppError('There is no user with that email address.', 404));
  }
  // 2) 生成（库里存哈希）
  const resetToken = user.createPasswordResetToken();
  await user.save({ validateBeforeSave: false });   // ★ 跳过验证：此时没有 passwordConfirm

  // 3) 发邮件（含明文 token 的前端重置页链接）
  const resetURL = `${req.protocol}://${req.get('host')}/resetPassword/${resetToken}`;
  const message = `Forgot your password? Submit a PATCH request with your new password and
passwordConfirm to: ${resetURL}.\nIf you didn't forget your password, please ignore this email!`;

  try {
    await sendEmail({ email: user.email, subject: 'Your password reset token (valid for 10 min)', message });
    res.status(200).json({ status: 'success', message: 'Token sent to email!' });
  } catch (err) {
    user.passwordResetToken = undefined;
    user.passwordResetExpires = undefined;
    await user.save({ validateBeforeSave: false });
    return next(new AppError('There was an error sending the email. Try again later!', 500));
  }
});
```

> [!tip] 两个易漏细节
> - `validateBeforeSave: false`：这次 save 的目的只是存 token，不该被 passwordConfirm 拦截
> - 发送失败要**回滚** token 字段，否则用户拿着失效 token 困惑、或令牌悬置库中

官方文档：[Nodemailer](https://nodemailer.com/about/)

## 四、resetPassword：用令牌换新密码（#114）

```javascript
exports.resetPassword = asyncError(async (req, res, next) => {
  // 1) 把 URL 路由参数里的明文 token 哈希，与库中比对
  const hashedToken = crypto.createHash('sha256').update(req.params.token).digest('hex');

  const user = await User.findOne({
    passwordResetToken: hashedToken,
    passwordResetExpires: { $gt: Date.now() },   // 且未过期
  });

  // 2) 令牌无效或过期 → 400
  if (!user) {
    return next(new AppError('Token is invalid or has expired', 400));
  }
  // 3) 设新密码（走 pre('save') 的 bcrypt 加密 + passwordChangedAt 记录）
  user.password = req.body.password;
  user.passwordConfirm = req.body.passwordConfirm;
  await user.save();

  // 4) 全新登录态：签发新 JWT（[[06-认证与授权/02-JWT原理与登录注册|signToken]]）
  const token = signToken(user._id);
  res.status(200).json({ status: 'success', token });
});
```

改密码后旧 JWT 全部作废的机制：`pre('save')` 写入 `passwordChangedAt` + `protect` 里 `changedPasswordAfter`，见 [[06-认证与授权/03-路由保护与权限]]。
