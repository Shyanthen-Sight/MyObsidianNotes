# Node.js 完全课程导航

> [!info] 课程来源
> procademy《A Complete NODE JS Course》，共 **122 集 / 约 27 小时**，分 6 大板块。
> 本目录的笔记树与课程板块一一对应：**文件夹 = 课程板块，笔记 = 章节，`##` = 单集知识点**。

