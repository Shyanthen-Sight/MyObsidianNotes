# 聚合管道（Aggregation Pipeline）

> [!abstract] 本篇定位
> 覆盖课程 #82–#83。过滤/排序只能"取数据"，**聚合管道**能让 MongoDB 在服务端做"统计报表"：按组求平均、计数、拼接展开。课程用它给 CINEFLIX 做"电影统计"和"按类型统计"两个接口。

## 一、管道思维：数据流过一站站加工

聚合管道 = **一组按顺序执行的处理阶段（stage）**，上一个阶段的输出就是下一个阶段的输入：

```
集合全部文档 ──► $match(过滤) ──► $group(分组统计) ──► $sort(排序) ──► 结果文档
```

类比 [[01-Node.js基础/07-事件驱动与Streams|Streams]]：都是"流过一站加工一站"，只不过加工的是**文档**不是字节块。官方总览：[Aggregation Pipeline](https://www.mongodb.com/docs/manual/aggregation/)

## 二、`$match` + `$group`：分组统计（#82）

```javascript
exports.getMovieStats = async (req, res) => {
  const stats = await Movie.aggregate([
    { $match: { ratings: { $gte: 4.5 } } },          // 阶段1：先过滤（省下后面的计算量）

    { $group: {                                       // 阶段2：按 _id 分组
        _id: '$ratings',                              // 按评分值分组（$字段名 = 引用字段）
        numMovies: { $sum: 1 },                       // 每组计数
        avgRatings: { $avg: '$ratings' },             // 每组均值
        avgPrice:  { $avg: '$price' },
        minPrice:  { $min: '$price' },
        maxPrice:  { $max: '$price' },
    }},

    { $sort: { avgRatings: 1 } },                     // 阶段3：组内结果再排序
  ]);
  res.status(200).json({ status: 'success', data: { stats } });
};
```

常用分组键：
- `'$ratings'` —— 按某字段值分组
- `null` —— 全体文档一组，得到全局统计
- `'$genre.name'` —— 按嵌入/引用字段分组

常用累计器：`$sum / $avg / $min / $max / $first / $last / $push`（[Group 官方文档](https://www.mongodb.com/docs/manual/reference/operator/aggregation/group/)）

> [!tip] `$match` 尽量放最前面
> 管道是流式的，越早过滤，后面阶段要搬运的数据越少——课程明确强调这一点。

## 三、`$unwind` + `$project`：展开数组与重塑字段（#83）

![聚合接口响应](img/course-mg04-aggregation.jpg)
*图 G4-02 · 视频 #83 · Postman 里"按类型统计"接口的 JSON 响应*

```javascript
exports.getMovieByGenre = async (req, res) => {
  const stats = await Movie.aggregate([
    { $unwind: '$genres' },          // 数组里有 3 个 genre？文档被拆成 3 条，各带 1 个 genre
    { $group: {
        _id: '$genres',              // 现在可以按"单个类型"分组了
        numGenreMovies: { $sum: 1 },
        numMoviesWithName: { $sum: { $cond: [{ $ne: ['$name', null] }, 1, 0] } }, // 条件计数
        avgRatings: { $avg: '$ratings' },
        avgPrice:   { $avg: '$price' },
    }},
    { $sort: { numGenreMovies: -1 } },
    { $project: {                    // 重塑输出：只留想要字段，可改名（numMovies: '$numGenreMovies'）
        numMoviesWithName: 1, avgRatings: 1, avgPrice: 1,
    }},
  ]);
  res.status(200).json({ status: 'success', data: { stats } });
};
```

| 阶段 | 作用 | 记忆 |
| :--- | :--- | :--- |
| `$unwind` | 数组展开成多条文档 | "拆行" |
| `$project` | 选择/重命名/隐藏输出字段 | "选列" |
| `$cond` | 管道里的三元表达式 | `[$if, $then, $else]` |

官方参考：[$unwind](https://www.mongodb.com/docs/manual/reference/operator/aggregation/unwind/) · [$project](https://www.mongodb.com/docs/manual/reference/operator/aggregation/project/)

## 四、`aggregate` 与 Mongoose 的关系

- `Model.aggregate([...])` 返回**普通文档数组**（不是 Model 实例！没有 `.save()` 等）
- 所以聚合中间件（[[04-Mongoose实战/05-虚拟属性与中间件|#87]]）只对 `aggregate()` 调用生效
- 建议在 Schema 上预定义 `movieSchema.statics` 或直接在控制器写管道（课程选后者）
