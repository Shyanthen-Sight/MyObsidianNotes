## 二、从 `req.query` 拿过滤条件（#74/#75）

![getAllMovies 按查询过滤](img/course-mg03-getall-query.jpg)
*图 G3-02 · 视频 #74 · `Movie.find(req.query)` 的雏形：duration/ratings 过滤*

![排除保留字段](img/course-mg03-exclude-fields.jpg)
*图 G3-03 · 视频 #75 · 把 page/sort/limit 等控制字段从过滤条件中剔除*

```javascript
exports.getAllMovies = async (req, res) => {
  try {
    const excludeFields = ['sort', 'page', 'limit', 'fields'];
    const queryObj = { ...req.query };                    // 浅拷贝（req.query 不能直接改）
    excludeFields.forEach((el) => delete queryObj[el]);   // 剩下的才是真正的过滤条件

    const movies = await Movie.find(queryObj);
    res.status(200).json({ status: 'success', results: movies.length, data: { movies } });
  } catch (err) { res.status(400).json({ status: 'fail', message: err.message }); }
};
```

请求示例：`GET /api/v1/movies?duration=115&ratings=7` → `Movie.find({duration:'115', ratings:'7'})`。注意字符串 '115' 能匹配是靠 Mongoose 的类型转换（SchemaType Cast）。

## 三、进阶过滤：`$gte/$lte` 与正则（#76）

![高级过滤正则](img/course-mg03-advanced-filter.jpg)
*图 G3-04 · 视频 #76 · 把 `duration[gte]=115` 转成 `{duration: {$gte: 115}}`*

URL 里的 `duration[gte]=115` 到达 Node 时是 `{duration: {gte: '115'}}` ——**`$` 被 Express 剥掉了**，得自己补回去：

```javascript
// {gte:'115'} → {$gte:115}：给每个操作符前面补 $
let queryStr = JSON.stringify(queryObj);
queryStr = queryStr.replace(/\b(gte|gt|lte|lt)\b/g, (match) => `$${match}`);
const queryObj2 = JSON.parse(queryStr);

// 再加模糊搜索（课程演示了对 name 用正则）
queryObj2.name = { $regex: queryObj2.name, $options: 'i' };

const movies = await Movie.find(queryObj2);
```

操作符参考：[MongoDB Comparison Query Operators](https://www.mongodb.com/docs/manual/reference/operator/query-comparison/)

## 四、排序、字段裁剪与分页（#77–#80）

`find()` 返回的是 Mongoose **Query 对象**——不像 `findOne` 直接执行，它可以**链式调用**直到 `await` 才发请求：

![Mongoose Query API 文档](img/course-mg03-query-docs.jpg)
*图 G3-05 · 视频 #77 · 官方文档中 Query.prototype 的可链方法列表*

![排序与字段裁剪](img/course-mg03-sort-limit.jpg)
*图 G3-06 · 视频 #78 · `query.sort(...)` 与 `query.select('-name -duration price ratings')`*

```javascript
// SORTING：?sort=price → 'price'；?sort=-price → '-price'（倒序）
if (req.query.sort) {
  const sortBy = req.query.sort.split(',').join(' ');   // 'price,ratings' → 'price ratings'
  query = query.sort(sortBy);
}

// LIMITING FIELDS：?fields=name,duration → 只返回这些字段；-name 表示排除
if (req.query.fields) {
  const fields = req.query.fields.split(',').join(' ');
  query = query.select(fields);                          // 又叫 query projection
} else {
  query = query.select('-__v');                          // 常态：隐藏 Mongoose 内部版本号
}

// PAGINATION：?page=2&limit=10
const page  = Number(req.query.page)  || 1;
const limit = Number(req.query.limit) || 10;
const skip  = (page - 1) * limit;                       // 第2页跳过前10条
query = query.skip(skip).limit(limit);

if (req.query.page) {
  const numMovies = await Movie.countDocuments();
  if (skip >= numMovies) throw new Error('This page is not found');
}

const movies = await query;                              // 到这里才真正查库
```

> [!important] 四件套对应 REST API 惯例
> | 功能 | 参数 | 方法 |
> | :--- | :--- | :--- |
> | 过滤 | `?ratings[gte]=7` | `find()` |
> | 排序 | `?sort=-price` | `sort()` |
> | 裁剪 | `?fields=name,price` | `select()` |
> | 分页 | `?page=2&limit=10` | `skip().limit()` |
> 官方文档：[Mongoose Queries](https://mongoosejs.com/docs/queries.html)

## 五、别名路由 + 封装成 `APIFeatures` 类（#80/#81）

![别名路由与分页判断](img/course-mg03-pagination.jpg)
*图 G3-07 · 视频 #80 · `router.route('/movies-stats')` 与 page 越界检查*

![APIFeatures 类](img/course-mg03-apifeatures.jpg)
*图 G3-08 · 视频 #81 · 把四件套收编为 importAllFeatures 可复用类*

```javascript
// alias：/api/v1/movies/top-5-best 预置好过滤排序参数，复用同一个控制器
exports.aliasTopMovies = async (req, res, next) => {
  req.query.limit = '5';
  req.query.sort   = 'price';
  req.query.fields = 'name,price,ratings';
  next();                                    // 中间件链：改完 query 再放行
};

// 可复用类：传入 query 对象 + queryString，链式处理
const importAllFeatures = require('./../utils/APIFeatures');
const features = new importAllFeatures(Movie.find(), req.query)
  .filter()
  .sort()
  .limitFields()
  .paginate();
const movies = await features.query;
```

> [!success] 为什么要抽类
> 四件套对**任何集合**都一样——抽成类后，Movie/Genre/User 的控制器都 `new` 一下就得到同样的能力。这个模式源自课程讲师的 Node/Express 实战经验，也是 MongoDB 官方 [cursor 方法链](https://www.mongodb.com/docs/manual/tutorial/iterate-a-cursor/) 的应用层映射。
