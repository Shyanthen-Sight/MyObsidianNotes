# 数据库与集合操作（含 BSON）

> [!abstract] 本篇定位
> 覆盖课程 #51–#53。在 mongosh 里学会**数据库的隐式创建**、**集合的隐式创建**，并弄懂 MongoDB 存的到底是 JSON 还是 BSON。CRUD 本体在 [[03-MongoDB基础/03-文档CRUD操作|下一篇]]。

![mongosh 中查看数据库](img/course-m01-show-dbs.jpg)

## 一、数据库：创建即"使用"

mongosh 连上后的第一组命令（对照[官方 Manual: Databases](https://www.mongodb.com/docs/manual/core/databases-and-collections/)）：

```javascript
show dbs            // 列出所有【有数据】的数据库
// → admin  config  local   (系统自带的三个)

db                  // 查看当前选中的数据库
// → test           (默认；它还没数据所以不在 show dbs 列表里)

use sampleDB        // 切换/选中数据库
switched to db sampleDB

show collections    // 看当前库里的集合
```

> [!important] 隐式创建（lazy creation）
> `use sampleDB` **不会真的创建**任何东西——`show dbs` 里也看不到它。只有当你往里面**写入第一条数据**后，数据库（和集合）才真正落盘。想删同样简单：
> ```javascript
> use sampleDB
> db.dropDatabase()   // 删除当前库，返回 { ok: 1 }
> ```

## 二、集合：插入即创建

集合（collection）≈ 关系库的"表"，但存的是**文档**。同样遵循隐式创建：

```javascript
use sampleDB
show collections          // → 无输出，还没有集合

db.customer.insertOne({ name: "John", age: 25 })
// customer 集合不存在？MongoDB 直接帮你建一个再插入

show collections
// → customer
```

课程强调的三点：
1. 最简建集合方式就是**直接插一条数据**，不用预先 `createCollection`
2. 需要显式建（如指定 capped/validator）时可用 `db.createCollection("xxx")`，[官方文档](https://www.mongodb.com/docs/manual/reference/method/db.createCollection/)
3. 集合名是 `db.` 后面那个标识符——`db.customer`、`db.products`，**命名即访问路径**，所以集合名不能有 `$`、不能空、不能以 `system.` 开头

## 三、JSON vs BSON：存的不是你输入的那个 JSON

![BSON 与 JSON 对比幻灯片](img/course-m01-bson-json.jpg)
*图 M2-02 · 视频 #53 · 课程对比 customer.json 与存储格式的幻灯片*

**BSON = Binary JSON**。你在 shell 里写 JSON，MongoDB 落盘和网络传输用的是 BSON：

| 维度 | JSON | BSON |
| :--- | :--- | :--- |
| 形态 | 文本 | 二进制 |
| 数据类型 | string / number / boolean / null / object / array | 多出 `ObjectId`、`Date`、`Int32/Int64`、`Decimal128`、`BinData`、正则等 |
| 遍历效率 | 需解析整段文本 | 头部带长度信息，可快速跳转/扫描字段 |
| 你看到的 | shell 里插入时写的 | shell 查询结果会被**渲染回 JSON-like** 展示 |

> [!important] 由此产生的两个实际影响
> 1. **`_id` 默认是 `ObjectId`**（12 字节：4 时间戳 + 5 随机 + 3 递增计数器），字符串化后是 24 位十六进制——后面 Express 里 `req.params.id` 传进来的是字符串，直接查会类型不匹配，这是 [[04-Mongoose实战/03-高级查询与分页|Mongoose 自动转换]] 要解决的问题。
> 2. **日期是真正的 `Date` 类型**而非字符串，才能做范围查询和排序。

完整类型清单见官方 [BSON Types](https://www.mongodb.com/docs/manual/reference/bson-types/)，课程在 #59 有一节专门演示，见 [[03-MongoDB基础/04-数据类型与嵌入文档]]。

## 四、命令速查

```javascript
show dbs                 // 列出有数据的库
db                       // 当前库名
use <name>               // 切换库（隐式创建）
db.dropDatabase()        // 删除当前库
show collections         // 列出当前库集合
db.createCollection("t") // 显式建集合
db.<col>.drop()          // 删除集合
```
