# UI 组件库与样式方案

> 实际项目通常不会从零写所有控件。这一节整理 Element Plus、Vuetify、Tailwind CSS 等生态选择，以及 Vue 单文件组件中的样式组织方式。

## 一、核心概念

- **组件库**：Element Plus 面向中后台，组件齐全、文档完善；Vuetify 基于 Material Design，适合需要完整设计体系的桌面和移动端项目。
- **原子化 CSS**：Tailwind CSS 通过工具类组合样式，减少在模板和样式文件之间来回切换，适合设计规范明确、需要快速迭代的团队。
- **`scoped` 样式**：Vue 给组件元素添加唯一属性，样式默认只作用于当前组件，是最常用的隔离方式。
- **CSS Modules**：`<style module>` 把类名编译成哈希，模板通过 `$style` 或 `useCssModule()` 使用，适合需要严格局部类名的场景。
- **深度选择器**：`:deep()` 用于修改子组件内部样式；`:slotted()` 用于作用域插槽内容；`:global()` 用于注册全局样式。
- **CSS 变量与 `v-bind()`**：可以把组件状态以 CSS 变量形式传给样式，实现动态主题，而不必写大量内联样式。

## 二、基础语法

安装 Element Plus：

```bash
npm install element-plus
```

```js
// main.js
import { createApp } from 'vue'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import App from './App.vue'

createApp(App).use(ElementPlus).mount('#app')
```

```vue
<template>
  <el-button type="primary" @click="save">保存</el-button>
  <el-table :data="rows">
    <el-table-column prop="name" label="姓名" />
  </el-table>
</template>
```

Tailwind CSS（Vite 项目）：

```bash
npm install -D tailwindcss @tailwindcss/vite
```

```js
// vite.config.js
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [vue(), tailwindcss()]
})
```

```css
/* src/style.css */
@import "tailwindcss";
```

```vue
<template>
  <button class="rounded-lg bg-slate-900 px-4 py-2 text-white hover:bg-slate-700">
    保存
  </button>
</template>
```

Vue 样式特性：

```vue
<style scoped>
/* 修改子组件内部元素 */
:deep(.el-input__inner) {
  border-radius: 10px;
}

/* 作用域插槽内容 */
:slotted(.highlight) {
  color: #dc2626;
}

/* 全局样式 */
:global(.page-title) {
  margin-bottom: 16px;
}
</style>
```

## 三、完整示例

下面是一个不依赖组件库的数据卡片，使用 CSS 变量、`scoped` 样式、`v-bind()` 和 `:deep()`，展示如何把动态主题与局部样式结合：

```vue
<script setup>
import { computed, ref } from 'vue'

const props = defineProps({
  title: {
    type: String,
    required: true
  },
  value: {
    type: Number,
    default: 0
  },
  trend: {
    type: Number,
    default: 0
  },
  color: {
    type: String,
    default: '#42b883'
  }
})

const isUp = computed(() => props.trend >= 0)

const trendText = computed(() => {
  return `${isUp.value ? '+' : ''}${props.trend}%`
})

const cardColor = ref(props.color)
</script>

<template>
  <article class="stat-card" :style="{ '--accent': cardColor }">
    <header>
      <span class="title">{{ title }}</span>
      <span class="trend" :class="{ down: !isUp }">{{ trendText }}</span>
    </header>

    <p class="value">{{ value.toLocaleString('zh-CN') }}</p>

    <div class="bar">
      <span :style="{ width: `${Math.min(100, Math.abs(trend) * 4)}%` }"></span>
    </div>

    <p class="hint">
      <slot name="hint">较上周期{{ isUp ? '增长' : '下降' }}</slot>
    </p>

    <slot />
  </article>
</template>

<style scoped>
.stat-card {
  --accent: #42b883;
  width: 260px;
  padding: 20px;
  border: 1px solid #e5e7eb;
  border-top: 4px solid var(--accent);
  border-radius: 12px;
  background: #ffffff;
  font-family: system-ui, sans-serif;
}

header {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

.title {
  color: #6b7280;
  font-size: 13px;
}

.trend {
  padding: 2px 8px;
  border-radius: 999px;
  background: #ecfdf5;
  color: #047857;
  font-size: 12px;
}

.trend.down {
  background: #fef2f2;
  color: #b91c1c;
}

.value {
  margin: 16px 0;
  font-size: 32px;
  font-weight: 700;
}

.bar {
  height: 6px;
  overflow: hidden;
  border-radius: 999px;
  background: #f1f5f9;
}

.bar span {
  display: block;
  height: 100%;
  border-radius: inherit;
  background: var(--accent);
  transition: width 0.3s ease;
}

.hint {
  margin: 10px 0 0;
  color: #9ca3af;
  font-size: 12px;
}

/* 作用域插槽样式：让父组件传入的 .action 遵循卡片风格 */
:slotted(.action) {
  margin-top: 12px;
  width: 100%;
  padding: 8px;
  border: 1px solid var(--accent);
  border-radius: 8px;
  background: transparent;
  color: var(--accent);
  cursor: pointer;
}
</style>
```

父组件使用：

```vue
<script setup>
import StatCard from './components/StatCard.vue'
</script>

<template>
  <StatCard
    title="本月成交额"
    :value="128900"
    :trend="12.5"
    color="#f59e0b"
  >
    <template #hint>较上月增长 12.5%</template>
    <button class="action">查看明细</button>
  </StatCard>
</template>
```

## 四、常见坑 / 注意事项

1. **组件库样式被 `scoped` 挡住**：修改 Element Plus 内部类名时要用 `:deep(.el-button)`，直接写 `.el-button` 不会命中。
2. **`:deep()` 会影响所有后代**：选择器范围过宽会污染子组件，尽量限定在具体容器内，如 `.card :deep(.el-input)`。
3. **Tailwind 的动态类名不会被扫描**：`bg-${color}-500` 这种拼接写法在构建时无法识别，应使用完整类名映射表。
4. **全局样式要控制作用范围**：引入组件库 CSS 后，`body`、`a`、`button` 的默认样式可能被覆盖，布局前先确认基础样式。
5. **CSS Modules 的类名不能直接写字符串**：`class="title"` 在 `<style module>` 下无效，应使用 `:class="$style.title"`。
6. **`v-bind()` 在 CSS 中只能用于简单值**：复杂对象、数组不会自动序列化，动态主题更适合用 CSS 变量。
7. **按需引入要注意样式文件**：Element Plus 的按需引入需要同时处理组件和样式，否则会出现“有结构无样式”。
8. **设计 token 比零散颜色更可维护**：把主色、圆角、间距抽成 CSS 变量，组件库和自定义组件共用一套变量，主题切换更容易。

## 六、速查表

| 语法                 | 作用               | 示例                             |
| -------------------- | ------------------ | -------------------------------- |
| `<style scoped>`     | 组件级样式隔离     | `<style scoped>.card {}</style>` |
| `:deep(selector)`    | 修改子组件内部样式 | `:deep(.el-input__inner) {}`     |
| `:slotted(selector)` | 作用域插槽样式     | `:slotted(.tag) {}`              |
| `:global(selector)`  | 全局样式           | `:global(.page) {}`              |
| `<style module>`     | CSS Modules        | `<div :class="$style.card">`     |
