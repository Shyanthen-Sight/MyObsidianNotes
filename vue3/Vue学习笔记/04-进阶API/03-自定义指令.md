# 自定义指令

> 自定义指令用于封装对 DOM 的底层操作，例如自动聚焦、权限控制、懒加载、拖拽，让这些逻辑可以像 `v-if` 一样复用在模板中。

## 一、核心概念

- **指令对象**：一个自定义指令是一个包含生命周期钩子的对象，钩子会收到 `el`、`binding`、`vnode` 等参数。
- **钩子时机**：`created` 在元素属性应用前调用；`beforeMount` 在挂载前；`mounted` 在元素插入 DOM 后；`beforeUpdate` / `updated` 在组件更新前后；`beforeUnmount` / `unmounted` 在卸载前后。
- **`binding` 对象**：`value` 是指令表达式的值，`oldValue` 是上一次的值，`arg` 是冒号后的参数，`modifiers` 是修饰符对象，`instance` 是使用指令的组件实例。
- **局部注册**：在 `<script setup>` 中声明以 `v` 开头的变量，如 `const vFocus = { ... }`，模板中写 `v-focus`。
- **全局注册**：`app.directive('focus', { ... })`，注册后所有组件可用。
- **函数简写**：如果只需要 `mounted` 和 `updated`，可以直接写函数，Vue 会在两个时机调用它。

## 二、基础语法

局部指令：

```vue
<script setup>
// 变量名必须以 v 开头，模板中写 v-focus
const vFocus = {
  mounted(el) {
    el.focus()
  }
}
</script>

<template>
  <input v-focus />
</template>
```

全局指令：

```js
// main.js
const app = createApp(App)

app.directive('focus', {
  mounted(el) {
    el.focus()
  }
})

app.mount('#app')
```

带参数和修饰符：

```vue
<script setup>
const vDemo = {
  mounted(el, binding) {
    console.log(binding.value)      // 指令的值
    console.log(binding.arg)        // 'color'
    console.log(binding.modifiers)  // { bold: true }
  }
}
</script>

<template>
  <p v-demo:color.bold="'red'">内容</p>
</template>
```

函数简写：

```js
const vFocus = (el) => {
  el.focus()
}
```

## 三、完整示例

下面是一个后台管理页面，使用 `v-focus` 自动聚焦搜索框，使用 `v-permission` 根据权限显示或移除操作按钮：

```vue
<script setup>
import { reactive, ref } from 'vue'

const keyword = ref('')

const currentUser = reactive({
  name: '林晓',
  permissions: ['order:read', 'order:export']
})

// 自动聚焦
const vFocus = {
  mounted(el) {
    el.focus()
  }
}

// 权限指令：没有权限时隐藏元素
const vPermission = {
  mounted(el, binding) {
    const required = binding.value
    if (!currentUser.permissions.includes(required)) {
      el.style.display = 'none'
    } else {
      el.dataset.permission = required
    }
  },
  updated(el, binding) {
    const required = binding.value
    const allowed = currentUser.permissions.includes(required)
    el.style.display = allowed ? '' : 'none'
  },
  unmounted(el) {
    delete el.dataset.permission
  }
}

const orders = [
  { id: 1, no: 'SO2026001', customer: '陈默', amount: 1299 },
  { id: 2, no: 'SO2026002', customer: '周宁', amount: 499 },
  { id: 3, no: 'SO2026003', customer: '苏晚', amount: 899 }
]

function exportOrders() {
  console.log('导出订单')
}

function deleteOrder(id) {
  console.log('删除订单', id)
}

function grantDelete() {
  if (!currentUser.permissions.includes('order:delete')) {
    currentUser.permissions.push('order:delete')
  }
}
</script>

<template>
  <section class="admin">
    <header>
      <h1>订单管理</h1>
      <input v-focus v-model="keyword" type="search" placeholder="搜索订单" />
    </header>

    <div class="toolbar">
      <button v-permission="'order:export'" type="button" @click="exportOrders">
        导出订单
      </button>
      <button type="button" @click="grantDelete">模拟授予删除权限</button>
    </div>

    <ul>
      <li v-for="order in orders" :key="order.id">
        <span>{{ order.no }}</span>
        <span>{{ order.customer }}</span>
        <span>¥{{ order.amount }}</span>
        <button
          v-permission="'order:delete'"
          type="button"
          class="danger"
          @click="deleteOrder(order.id)"
        >
          删除
        </button>
      </li>
    </ul>
  </section>
</template>

  border-radius: 8px;
}

}

.toolbar button,
.danger {
  padding: 8px 14px;

}

}

```

全局注册带 `getSSRProps` 的指令，兼顾服务端渲染：

```js
app.directive('tooltip', {
  mounted(el, binding) {
    el.setAttribute('title', binding.value)
  },
  updated(el, binding) {
    el.setAttribute('title', binding.value)
  },
  getSSRProps(binding) {
    return {
      title: binding.value
    }
  }
})
```

## 四、常见坑 / 注意事项

1. **局部指令变量名必须以 `v` 开头**：`const focus = {}` 不会注册为 `v-focus`，必须写成 `const vFocus = {}`。
2. **`mounted` 只执行一次**：依赖响应式值变化的逻辑要放在 `updated`，或使用 `watchEffect` 手动追踪。
3. **指令不是组件，不能使用模板插槽**：它只操作 DOM，复杂 UI 应封装成组件。
4. **`binding.value` 是表达式的结果**：`v-permission="'order:delete'"` 传的是字符串；`v-permission="orderDelete"` 传的是变量。
5. **修改 DOM 后要清理**：在 `unmounted` 中移除事件监听、观察器、定时器和自定义属性，避免内存泄漏。
6. **SSR 中不会执行 `mounted`**：服务端渲染时指令的 DOM 操作不可用，需要实现 `getSSRProps` 或确保指令只在客户端生效。
7. **多个指令作用在同一元素上时顺序不保证业务语义**：不要依赖 `v-focus` 和 `v-permission` 的先后关系，权限判断应放在指令内部。
8. **不要用指令替代数据驱动**：能用 `v-if`、`:class`、`:style` 表达的逻辑优先用模板，指令只处理必须直接操作 DOM 的场景。

## 六、速查表

| 语法                         | 作用       | 示例                                  |
| ---------------------------- | ---------- | ------------------------------------- |
| `const vFocus = {}`          | 局部指令   | `<input v-focus />`                   |
| `app.directive('focus', {})` | 全局指令   | `app.directive('focus', { mounted })` |
| `mounted(el, binding)`       | 挂载后执行 | `el.focus()`                          |
| `updated(el, binding)`       | 更新后执行 | 根据新值修改 DOM                      |
| `binding.value`              | 指令值     | `v-permission="'order:delete'"`       |
