# 插件与应用配置

> 插件把一组全局能力（组件、指令、注入、配置）打包成一个可安装单元，通常用于路由、状态管理、国际化、埋点等跨应用功能。

## 一、核心概念

- **插件形态**：插件可以是一个带有 `install(app, options)` 方法的对象，也可以直接是一个函数。Vue 会在 `app.use()` 时调用它。
- **安装时机**：`app.use(plugin)` 必须在 `app.mount()` 之前调用，否则插件注册的全局组件、指令在首次渲染时还不存在。
- **插件能力**：在 `install` 中可以注册全局组件、全局指令、应用级 `provide`、全局属性，也可以注册其他插件。
- **全局属性**：`app.config.globalProperties.$http = ...` 会把属性挂到所有组件实例上，模板和选项式 API 可以通过 `this.$http` 访问。组合式 API 更推荐 `provide/inject` 或直接导入模块。
- **错误处理**：`app.config.errorHandler` 捕获组件渲染、事件处理器、生命周期钩子中未被捕获的错误；`warnHandler` 只用于开发环境。
- **性能追踪**：`app.config.performance = true` 会在浏览器 Performance 面板中标记组件初始化、编译和渲染的时间。

## 二、基础语法

对象形式插件：

```js
// plugins/logger.js
export default {
  install(app, options = {}) {
    const prefix = options.prefix ?? '[app]'

    // 全局属性
    app.config.globalProperties.$log = (...args) => {
      console.log(prefix, ...args)
    }

    // 全局指令
    app.directive('focus', {
      mounted(el) {
        el.focus()
      }
    })

    // 应用级注入
    app.provide('logger', {
      info: (...args) => console.log(prefix, ...args)
    })
  }
}
```

```js
// main.js
import { createApp } from 'vue'
import App from './App.vue'
import logger from './plugins/logger'

const app = createApp(App)

app.use(logger, { prefix: '[crm]' })

app.config.errorHandler = (error, instance, info) => {
  console.error('全局错误', error, info)
}

app.mount('#app')
```

函数形式插件：

```js
export function installAnalytics(app, options) {
  app.provide('analytics', {
    track(event, payload) {
      console.log('track', event, payload)
    }
  })
}

app.use(installAnalytics, { appId: 'crm' })
```

## 三、完整示例

下面实现一个轻量国际化插件，注册全局 `$t` 方法、`v-t` 指令和 `i18n` 注入，并在组件中同时使用组合式与选项式写法：

```js
// plugins/i18n.js
import { computed, inject, ref } from 'vue'

const messages = {
  'zh-CN': {
    welcome: '欢迎回来',
    logout: '退出登录',
    orders: '订单管理'
  },
  'en-US': {
    welcome: 'Welcome back',
    logout: 'Sign out',
    orders: 'Orders'
  }
}

export const i18nKey = Symbol('i18n')

export default {
  install(app, options = {}) {
    const locale = ref(options.locale ?? 'zh-CN')

    const t = (key) => {
      return messages[locale.value]?.[key] ?? key
    }

    const i18n = {
      locale,
      t,
      setLocale(nextLocale) {
        if (messages[nextLocale]) locale.value = nextLocale
      },
      availableLocales: computed(() => Object.keys(messages))
    }

    // 组合式 API 通过 inject 使用
    app.provide(i18nKey, i18n)

    // 选项式 API 通过 this.$t 使用
    app.config.globalProperties.$t = t
    app.config.globalProperties.$i18n = i18n

    // 模板中可直接写 v-t="'welcome'"
    app.directive('t', {
      mounted(el, binding) {
        el.textContent = t(binding.value)
      },
      updated(el, binding) {
        el.textContent = t(binding.value)
      }
    })
  }
}
```

```vue
<!-- App.vue -->
<script setup>
import { inject } from 'vue'
import { i18nKey } from './plugins/i18n'

const { locale, setLocale, availableLocales, t } = inject(i18nKey)

function switchLocale(event) {
  setLocale(event.target.value)
}
</script>

<template>
  <main class="app">
    <header>
      <h1>{{ t('welcome') }}</h1>

      <select :value="locale" @change="switchLocale">
        <option
          v-for="item in availableLocales"
          :key="item"
          :value="item"
        >
          {{ item }}
        </option>
      </select>
    </header>

    <nav>
      <a href="/orders" v-t="'orders'"></a>
      <button type="button" v-t="'logout'"></button>
    </nav>

    <p>当前语言：{{ locale }}</p>
  </main>
</template>

<style scoped>

  max-width: 640px;
  margin: 48px auto;
  font-family: system-ui, sans-serif;
}

header {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

h1 {
  margin: 0;
  font-size: 24px;
}

select {
  padding: 8px 10px;
  border: 1px solid #d1d5db;
  border-radius: 8px;
}

nav {
  display: flex;
  gap: 12px;
  margin-top: 20px;
}

nav a,
nav button {
  padding: 9px 14px;
  border: 1px solid #d1d5db;
  border-radius: 8px;
  background: #ffffff;
  color: inherit;
  cursor: pointer;
  text-decoration: none;
}

p {
  margin-top: 20px;
  color: #6b7280;
}
</style>
```

选项式 API 中使用全局属性：

```vue
<script>
export default {
  mounted() {
    this.$log('页面已加载')
    console.log(this.$t('welcome'))
  }
}
</script>
```

## 四、常见坑 / 注意事项

1. **`app.use` 必须在 `app.mount` 之前**：挂载后再安装插件，首次渲染的组件拿不到全局组件、指令和注入。
2. **插件要保证重复安装安全**：某些插件会被多个依赖重复 `use`，应在 `install` 中判断是否已安装，避免重复注册。
3. **全局属性不要滥用**：`globalProperties` 会污染所有组件实例，且不利于类型推导和 tree-shaking；优先使用模块导入或 `provide/inject`。
4. **全局属性命名加 `$` 前缀**：避免与组件自身的数据、方法重名，Vue 的模板和实例 API 也遵循这个约定。
5. **`errorHandler` 不能捕获异步回调中的错误**：`setTimeout`、未处理的 Promise rejection 需要单独监听 `window.onerror` / `unhandledrejection`。
6. **SSR 中插件状态必须按请求隔离**：不要把用户相关的响应式状态放在模块顶层，否则不同请求会共享同一份数据。
7. **`warnHandler` 只在开发环境生效**：生产环境不会调用，不要依赖它做错误上报。
8. **插件不要修改 Vue 原型**：Vue 3 没有 `Vue.prototype`，应使用 `app.config.globalProperties` 或 `app.provide`。

## 六、速查表

| 语法                       | 作用         | 示例                                  |
| -------------------------- | ------------ | ------------------------------------- |
| `app.use(plugin, options)` | 安装插件     | `app.use(router)`                     |
| `install(app, options)`    | 插件入口     | `install(app) { ... }`                |
| `app.component`            | 注册全局组件 | `app.component('BaseIcon', BaseIcon)` |
| `app.directive`            | 注册全局指令 | `app.directive('focus', { mounted })` |
| `app.provide`              | 应用级注入   | `app.provide('config', config)`       |
