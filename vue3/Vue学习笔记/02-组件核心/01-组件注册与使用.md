# 组件注册与使用

> 组件是 Vue 应用的基本复用单元。注册组件就是告诉 Vue：在当前作用域里，某个标签名对应哪个组件实现。

## 一、核心概念

- **局部注册**：在某个组件的 `<script setup>` 中 `import` 子组件，Vue 会自动把它注册到当前组件的作用域，只有当前组件能使用。
- **全局注册**：通过 `app.component('Name', Component)` 注册，注册后整个应用都能使用，适合基础按钮、图标等跨页面通用组件。
- **命名约定**：组件文件使用 PascalCase，如 `UserCard.vue`；模板中可以用 `<UserCard />` 或 `<user-card />`，Vue 会自动匹配。
- **组件树**：页面由根组件 `App.vue` 开始，逐层组合子组件。每个组件拥有独立的模板、逻辑和样式作用域。
- **父子通信**：父组件通过 `props` 向子组件传数据，子组件通过 `emits` 向父组件发事件。注册只是让组件可用，通信才让组件真正协作。
- **按需加载**：大型项目通常配合 `defineAsyncComponent` 或路由懒加载，避免首屏加载所有组件代码。

---

## 二、基础语法

局部注册（推荐）：

```vue
<script setup>
import UserCard from './components/UserCard.vue'
import BaseButton from './components/BaseButton.vue'
</script>

<template>
  <UserCard name="林晓" role="前端工程师" />
  <BaseButton>保存</BaseButton>
</template>
```

全局注册：

```js
// main.js
import { createApp } from 'vue'
import App from './App.vue'
import BaseIcon from './components/BaseIcon.vue'

const app = createApp(App)

// 全局注册后，任意组件模板都可以直接使用 <BaseIcon />
app.component('BaseIcon', BaseIcon)

app.mount('#app')
```

注册时可以使用 kebab-case 名称，避免与 HTML 标签冲突：

```js
app.component('base-icon', BaseIcon)
```

## 三、完整示例

下面是一个用户卡片组件，包含头像、角色标签、关注按钮和事件派发，展示组件自身的完整结构：

```vue
<script setup>
import { computed } from 'vue'

const props = defineProps({
  user: {
    type: Object,
    required: true
  },
  compact: {
    type: Boolean,
    default: false
  }
})

const emit = defineEmits(['follow', 'open-profile'])

const initial = computed(() => props.user.name.slice(0, 1))

const roleText = computed(() => {
  const map = {
    admin: '管理员',
    editor: '编辑',
    viewer: '访客'
  }
  return map[props.user.role] ?? '成员'
})

function toggleFollow() {
  // 子组件不直接修改 props，只把意图交给父组件
  emit('follow', props.user.id)
}

function openProfile() {
  emit('open-profile', props.user)
}
</script>

<template>
  <article class="user-card" :class="{ compact }">
    <div class="avatar" :style="{ backgroundColor: user.color || '#42b883' }">
      {{ initial }}
    </div>

    <div class="info">
      <h3 @click="openProfile">{{ user.name }}</h3>
      <p>{{ user.email }}</p>
      <span class="role">{{ roleText }}</span>
    </div>

    <button
      type="button"
      class="follow"
      :class="{ following: user.followed }"
      @click="toggleFollow"
    >
      {{ user.followed ? '已关注' : '关注' }}
    </button>
  </article>
</template>

<style scoped>
.user-card {
  display: flex;
  align-items: center;
  gap: 14px;
  padding: 16px;
  border: 1px solid #e5e7eb;
  border-radius: 12px;
  background: #ffffff;
  font-family: system-ui, sans-serif;
}

.user-card.compact {
  padding: 10px 12px;
}

.avatar {
  display: grid;
  width: 48px;
  height: 48px;
  flex-shrink: 0;
  place-items: center;
  border-radius: 50%;
  color: #ffffff;
  font-size: 18px;
  font-weight: 600;
}

.info {
  flex: 1;
  min-width: 0;
}

.info h3 {
  margin: 0 0 4px;
  font-size: 16px;
  cursor: pointer;
}

.info h3:hover {
  color: #2563eb;
}

.info p {
  overflow: hidden;
  margin: 0 0 6px;
  color: #6b7280;
  font-size: 13px;
  text-overflow: ellipsis;
  white-space: nowrap;
}

.role {
  padding: 2px 8px;
  border-radius: 999px;
  background: #f3f4f6;
  color: #4b5563;
  font-size: 12px;
}

.follow {
  padding: 7px 14px;
  border: 1px solid #111827;
  border-radius: 999px;
  background: #111827;
  color: #ffffff;
  cursor: pointer;
  font-size: 13px;
}

  background: #ffffff;
  color: #111827;
}
</style>
```

父组件使用该组件，并处理它派发的事件：

```vue
<script setup>
import { ref } from 'vue'
import UserCard from './components/UserCard.vue'

const users = ref([
  { id: 1, name: '林晓', email: 'lin@example.com', role: 'admin', followed: false },
  { id: 2, name: '陈默', email: 'chen@example.com', role: 'editor', followed: true }
])

function handleFollow(id) {
  const user = users.value.find((item) => item.id === id)
  if (user) user.followed = !user.followed
}

function handleOpen(user) {
  console.log('打开用户详情', user.name)
}
</script>

<template>
  <UserCard
    v-for="user in users"
    :key="user.id"
    :user="user"
    @follow="handleFollow"
    @open-profile="handleOpen"
  />
</template>
```

## 四、常见坑 / 注意事项

1. **局部注册的组件不能在兄弟组件中直接使用**：`UserCard` 只在导入它的组件作用域内可用，兄弟组件需要自己导入。
2. **全局注册会增加包体积且难以追踪来源**：大量全局组件会让模板里的标签来源不清晰，除基础 UI 外优先使用局部注册。
3. **组件名不要与原生标签重名**：如 `<table>`、`<button>`、`<header>`，容易产生歧义；组件名建议至少两个单词，如 `BaseButton`。
4. **PascalCase 与 kebab-case 要一致**：`import UserCard` 后模板写 `<user-card>` 可以工作；但 `app.component('UserCard')` 后在 DOM 模板中必须写 `<user-card>`。
5. **注册了但未使用不会有问题，导入错误会直接报错**：路径大小写、扩展名、默认导出缺失是常见错误来源。
6. **组件必须有可渲染内容**：模板为空或只有注释时，页面不会显示任何东西；多根组件还要注意属性透传。
7. **不要通过全局变量在组件间传数据**：那会绕过响应式和父子数据流，调试困难，应使用 props、events、provide/inject 或 Pinia。

## 六、速查表

| 语法                              | 作用         | 示例                                                              |
| --------------------------------- | ------------ | ----------------------------------------------------------------- |
| `import Child from './Child.vue'` | 局部注册     | `<script setup>import Child from './Child.vue'</script>`          |
| `<Child />`                       | 使用组件     | `<Child :data="item" />`                                          |
| `app.component('Name', Comp)`     | 全局注册     | `app.component('BaseIcon', BaseIcon)`                             |
| `<component :is="Comp" />`        | 动态组件     | `<component :is="currentTab" />`                                  |
| `defineAsyncComponent`            | 异步加载组件 | `const Chart = defineAsyncComponent(() => import('./Chart.vue'))` |
