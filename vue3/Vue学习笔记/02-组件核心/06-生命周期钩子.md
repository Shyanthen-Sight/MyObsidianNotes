# 生命周期钩子

> 生命周期钩子是组件从创建、挂载、更新到卸载过程中，Vue 在特定时刻调用的函数，用来放置“必须在某个时机执行”的副作用。

## 一、核心概念

- **创建阶段**：`setup` 在组件实例创建时执行，早于 `beforeCreate` 和 `created`。组合式 API 中大部分初始化逻辑直接写在 `setup` 顶层。
- **挂载阶段**：`onBeforeMount` 在首次渲染前调用，`onMounted` 在 DOM 挂载完成后调用。访问 DOM、初始化第三方库、发起首屏请求通常放在 `onMounted`。
- **更新阶段**：`onBeforeUpdate` 在数据变化导致重新渲染前调用，`onUpdated` 在 DOM 更新后调用。不要在这两个钩子里无条件修改状态，否则可能造成无限循环。
- **卸载阶段**：`onBeforeUnmount` 在组件销毁前调用，适合移除事件监听、取消定时器；`onUnmounted` 在销毁后调用。
- **缓存组件钩子**：被 `<KeepAlive>` 缓存的组件不会触发 `onUnmounted`，而是触发 `onDeactivated`；重新激活时触发 `onActivated`。
- **错误捕获**：`onErrorCaptured` 可以捕获后代组件抛出的错误，返回 `false` 阻止错误继续向上传播。

## 二、基础语法

```vue
<script setup>
import {
  onBeforeMount,
  onBeforeUnmount,
  onMounted,
  onUnmounted,
  onUpdated
} from 'vue'

onBeforeMount(() => {
  console.log('DOM 还没挂载')
})

onMounted(() => {
  console.log('DOM 已挂载，可以访问元素')
})

onUpdated(() => {
  console.log('组件完成一次更新')
})

onBeforeUnmount(() => {
  console.log('组件即将卸载，适合清理副作用')
})

onUnmounted(() => {
  console.log('组件已卸载')
})
</script>
```

选项式 API 对照：

```vue
<script>
export default {
  beforeCreate() {},
  created() {},
  beforeMount() {},
  mounted() {},
  beforeUpdate() {},
  updated() {},
  beforeUnmount() {},
  unmounted() {},
  activated() {},
  deactivated() {},
  errorCaptured(error, instance, info) {
    console.error(error, info)
    return false
  }
}
</script>
```

## 三、完整示例

下面是一个运营看板组件，在挂载后加载数据、启动轮询、监听窗口尺寸，并在卸载时完整清理资源：

```vue
<script setup>
import { onBeforeUnmount, onMounted, ref } from 'vue'

const stats = ref({
  visitors: 0,
  orders: 0,
  revenue: 0
})

const loading = ref(true)
const errorMessage = ref('')
const isMobile = ref(false)

let timer = null
let controller = null

// 模拟接口请求，支持取消
async function loadStats() {
  controller?.abort()
  controller = new AbortController()

  try {
    // 实际项目替换为真实接口
    await new Promise((resolve) => setTimeout(resolve, 600))

    if (controller.signal.aborted) return

    stats.value = {
      visitors: Math.floor(Math.random() * 5000),
      orders: Math.floor(Math.random() * 300),
      revenue: Math.floor(Math.random() * 90000)
    }
    errorMessage.value = ''
  } catch (error) {
    if (error.name !== 'AbortError') {
      errorMessage.value = '数据加载失败，请稍后重试'
    }
  } finally {
    loading.value = false
  }
}

function handleResize() {
  isMobile.value = window.innerWidth < 768
}

onMounted(() => {
  // DOM 已可用，可以读取尺寸、初始化图表
  handleResize()
  window.addEventListener('resize', handleResize)

  loadStats()

  // 每 30 秒刷新一次
  timer = window.setInterval(loadStats, 30000)
})

onBeforeUnmount(() => {
  // 清理定时器、事件监听和未完成请求
  if (timer) window.clearInterval(timer)
  window.removeEventListener('resize', handleResize)
  controller?.abort()
})
</script>

<template>
  <section class="dashboard" :class="{ mobile: isMobile }">
    <header>
      <h1>今日运营数据</h1>
      <button type="button" :disabled="loading" @click="loadStats">
        {{ loading ? '刷新中' : '刷新' }}
      </button>
    </header>

    <p v-if="errorMessage" class="error">{{ errorMessage }}</p>

    <div class="grid">
      <article>
        <span>访客数</span>
        <strong>{{ loading ? '--' : stats.visitors }}</strong>
      </article>
      <article>
        <span>订单数</span>
        <strong>{{ loading ? '--' : stats.orders }}</strong>
      </article>
      <article>
        <span>成交额</span>
        <strong>{{ loading ? '--' : `¥${stats.revenue}` }}</strong>
      </article>
    </div>
  </section>
</template>

<style scoped>
.dashboard {
  max-width: 900px;
  margin: 40px auto;
  padding: 24px;
  font-family: system-ui, sans-serif;
}

header {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

h1 {
  margin: 0;
  font-size: 22px;
}

header button {
  padding: 8px 16px;
  border: 0;
  border-radius: 8px;
  background: #111827;
  color: #ffffff;
  cursor: pointer;
}

header button:disabled {
  background: #9ca3af;
}

.error {
  color: #dc2626;
}

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
  margin-top: 20px;
}

  padding: 20px;

}

  display: block;
  margin-bottom: 10px;
  color: #6b7280;
  font-size: 13px;
}

.grid strong {
  font-size: 28px;
}

.mobile .grid {
  grid-template-columns: 1fr;
}
</style>
```

## 四、常见坑 / 注意事项

1. **`setup` 执行时 DOM 还不存在**：不要直接在 `setup` 顶层调用 `document.querySelector`，需要 DOM 的逻辑放在 `onMounted`。
2. **`onMounted` 在 SSR 中不会执行**：服务端渲染没有 DOM，依赖 `window`、`document` 的代码要放到客户端钩子或 `onMounted` 中。
3. **异步 `setup` 需要 `<Suspense>`**：`<script setup>` 顶层使用 `await` 会让组件变成异步组件，必须由 `<Suspense>` 包裹，否则不会渲染。
4. **清理副作用是必须的**：定时器、`window` 事件、WebSocket、IntersectionObserver 都要在 `onBeforeUnmount` 或 `onUnmounted` 中释放，否则会造成内存泄漏。
5. **不要在 `onUpdated` 中无条件改状态**：更新钩子中修改响应式数据会再次触发更新，容易形成死循环；应加条件判断。
6. **`onBeforeUnmount` 中仍可访问 DOM**：适合做过渡动画前的测量；`onUnmounted` 中 DOM 已被移除。
7. **KeepAlive 组件不会触发卸载钩子**：被缓存时应使用 `onActivated` 恢复轮询、`onDeactivated` 暂停轮询。
8. **父子组件的挂载顺序**：父组件 `onMounted` 在子组件全部挂载完成后才触发；卸载时父组件 `onBeforeUnmount` 先于子组件。

## 六、速查表

| 组合式 API        | 选项式 API      | 调用时机   |
| ----------------- | --------------- | ---------- |
| `onBeforeMount`   | `beforeMount`   | 首次挂载前 |
| `onMounted`       | `mounted`       | DOM 挂载后 |
| `onBeforeUpdate`  | `beforeUpdate`  | 更新前     |
| `onUpdated`       | `updated`       | DOM 更新后 |
| `onBeforeUnmount` | `beforeUnmount` | 卸载前     |
