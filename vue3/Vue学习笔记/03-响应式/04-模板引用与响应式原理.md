# 模板引用与响应式原理

> 模板引用让你在组件挂载后直接访问 DOM 元素或子组件实例；响应式原理则解释了 Vue 如何知道“哪个值变了、该更新哪块界面”。

## 一、核心概念

- **模板引用**：在元素上写 `ref="inputRef"`，在脚本中用同名的 `ref(null)` 接收。挂载完成后，`inputRef.value` 就是真实 DOM 元素。
- **组件引用**：给子组件加 `ref`，父组件可以访问子组件通过 `defineExpose` 暴露的方法和属性。`<script setup>` 组件默认是封闭的，不暴露内部变量。
- **`useTemplateRef`**：Vue 3.5 新增的组合式 API，用字符串 key 获取模板引用，避免变量名与模板 `ref` 字符串不一致。
- **`v-for` 中的引用**：同一个 `ref` 用在 `v-for` 上时，Vue 会把结果收集为数组；数组顺序不保证与 DOM 顺序一致，需要顺序时使用函数式 ref。
- **响应式核心**：Vue 3 用 `Proxy` 拦截对象的 `get` / `set`。读取时通过 `track` 记录当前副作用，写入时通过 `trigger` 通知相关副作用重新执行。
- **调度器**：数据变化不会立刻同步更新 DOM，而是把更新任务放入微任务队列，批量执行，避免同一轮多次修改触发多次渲染。

## 二、基础语法

```vue
<script setup>
import { onMounted, ref, useTemplateRef } from 'vue'

// 方式一：同名 ref
const inputRef = ref(null)

// 方式二：Vue 3.5+ 的 useTemplateRef
const videoRef = useTemplateRef('video')

onMounted(() => {
  inputRef.value?.focus()
  console.log(videoRef.value?.duration)
})
</script>

<template>
  <input ref="inputRef" />
  <video ref="video" src="/demo.mp4"></video>
</template>
```

访问子组件暴露的内容：

```vue
<!-- ChildForm.vue -->
<script setup>
import { ref } from 'vue'

const formRef = ref(null)

function validate() {
  return formRef.value?.checkValidity() ?? false
}

// 只暴露需要给父组件用的方法
defineExpose({ validate })
</script>

<template>
  <form ref="formRef">
    <input required />
  </form>
</template>
```

```vue
<!-- 父组件 -->
<script setup>
import { ref } from 'vue'
import ChildForm from './ChildForm.vue'

const child = ref(null)

function submit() {
  const ok = child.value?.validate()
  console.log('校验结果', ok)
}
</script>

<template>
  <ChildForm ref="child" />
  <button @click="submit">提交</button>
</template>
```

## 三、完整示例

下面是一个视频播放器组件，使用模板引用控制播放、进度和音量，并在挂载后读取视频元数据：

```vue
<script setup>
import { computed, onMounted, ref, useTemplateRef } from 'vue'

const video = useTemplateRef('video')
const isPlaying = ref(false)
const currentTime = ref(0)
const duration = ref(0)
const volume = ref(0.8)

const progress = computed(() => {
  if (!duration.value) return 0
  return (currentTime.value / duration.value) * 100
})

function togglePlay() {
  if (!video.value) return

  if (video.value.paused) {
    video.value.play()
  } else {
    video.value.pause()
  }
}

function seek(event) {
  if (!video.value) return
  const time = Number(event.target.value)
  video.value.currentTime = time
  currentTime.value = time
}

function changeVolume(event) {
  const next = Number(event.target.value)
  volume.value = next
  if (video.value) video.value.volume = next
}

function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60)
  const rest = Math.floor(seconds % 60)
  return `${minutes}:${String(rest).padStart(2, '0')}`
}

onMounted(() => {
  const el = video.value
  if (!el) return

  el.volume = volume.value

  el.addEventListener('play', () => {
    isPlaying.value = true
  })

  el.addEventListener('pause', () => {
    isPlaying.value = false
  })

  el.addEventListener('timeupdate', () => {
    currentTime.value = el.currentTime
  })

  el.addEventListener('loadedmetadata', () => {
    duration.value = el.duration
  })
})
</script>

<template>
  <section class="player">
    <video
      ref="video"
      class="screen"
      src="/media/product-demo.mp4"
      playsinline
    ></video>

    <div class="controls">
      <button type="button" @click="togglePlay">
        {{ isPlaying ? '暂停' : '播放' }}
      </button>

      <span class="time">{{ formatTime(currentTime) }}</span>

      <input
        class="progress"
        type="range"
        min="0"
        :max="duration || 0"
        :value="currentTime"
        @input="seek"
      />

      <span class="time">{{ formatTime(duration) }}</span>

      <input
        class="volume"
        type="range"
        min="0"
        max="1"
        step="0.05"
        :value="volume"
        @input="changeVolume"
      />
    </div>
  </section>
</template>

<style scoped>
.player {
  width: 640px;
  overflow: hidden;
  border-radius: 14px;
  background: #0f172a;
  font-family: system-ui, sans-serif;
}

.screen {
  display: block;
  width: 100%;
  aspect-ratio: 16 / 9;
  background: #000000;
}

.controls {
  display: flex;
  align-items: center;
  gap: 10px;
  padding: 12px;
  color: #e2e8f0;
}

.controls button {
  padding: 6px 14px;
  border: 0;
  border-radius: 6px;
  background: #42b883;
  color: #ffffff;
  cursor: pointer;
}

.time {
  min-width: 40px;
  font-size: 12px;
  text-align: center;
}

.progress {
  flex: 1;
}

.volume {
  width: 80px;
}
</style>
```

响应式原理的最小示意（不是 Vue 源码，只表达核心流程）：

```js
// 简化版：用 Proxy 拦截读写，用 Set 收集依赖
const targetMap = new WeakMap()
let activeEffect = null

function track(target, key) {
  if (!activeEffect) return

  let depsMap = targetMap.get(target)
  if (!depsMap) {
    depsMap = new Map()
    targetMap.set(target, depsMap)
  }

  let dep = depsMap.get(key)
  if (!dep) {
    dep = new Set()
    depsMap.set(key, dep)
  }

  dep.add(activeEffect)
}

function trigger(target, key) {
  const dep = targetMap.get(target)?.get(key)
  dep?.forEach((effect) => effect())
}

function reactive(target) {
  return new Proxy(target, {
    get(obj, key, receiver) {
      track(obj, key)
      return Reflect.get(obj, key, receiver)
    },
    set(obj, key, value, receiver) {
      const result = Reflect.set(obj, key, value, receiver)
      trigger(obj, key)
      return result
    }
  })
}
```

## 四、常见坑 / 注意事项

1. **挂载前 `ref.value` 是 `null`**：`setup` 执行时 DOM 还没创建，必须放到 `onMounted` 或之后的事件中访问。
2. **`v-if` 隐藏的元素没有引用**：元素被销毁后 `ref.value` 会变回 `null`，使用前要判空。
3. **`<script setup>` 组件默认不暴露内部状态**：父组件只能访问 `defineExpose` 暴露的内容，直接读 `child.name` 会得到 `undefined`。
4. **模板中的 `ref` 字符串要与脚本变量同名**：`ref="inputRef"` 对应 `const inputRef = ref(null)`；改名后忘记同步模板，引用会一直是 `null`。
5. **`v-for` 的 ref 数组顺序不保证**：Vue 官方明确说明数组不保证与源数组顺序一致；需要稳定顺序时使用函数式 ref，把元素按索引存入自己的数组。
6. **模板引用不是响应式的**：不要 `watch(inputRef, ...)` 期待 DOM 变化；它只在挂载/卸载时被赋值。
7. **`Proxy` 只能拦截对象**：`reactive` 不能包装基本类型；对象一旦被替换，旧代理不会自动指向新对象。
8. **深层响应式不是无限递归**：Vue 只在访问嵌套对象时惰性创建代理，未访问的属性不会被代理；这也意味着冻结对象、类实例的私有字段可能无法被追踪。

## 六、速查表

| 语法                         | 作用              | 示例                                 |
| ---------------------------- | ----------------- | ------------------------------------ |
| `ref="el"`                   | 标记模板引用      | `<input ref="inputRef" />`           |
| `const inputRef = ref(null)` | 接收 DOM 引用     | `inputRef.value.focus()`             |
| `useTemplateRef('el')`       | Vue 3.5+ 获取引用 | `const el = useTemplateRef('video')` |
| `defineExpose({ fn })`       | 暴露子组件方法    | `defineExpose({ validate })`         |
| `ref` + `v-for`              | 收集多个元素      | `<li v-for="i in list" ref="items">` |
