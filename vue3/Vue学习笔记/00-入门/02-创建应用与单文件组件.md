# 创建应用与单文件组件

> 这一节解决两个问题：Vue 应用从哪里启动，以及如何用一个 `.vue` 文件把逻辑、模板和样式组织成可复用的组件。

## 一、核心概念

- **应用实例**：`createApp(App)` 创建一个独立的应用实例，`.mount('#app')` 把它挂载到页面上指定的容器。一个页面可以有多个 Vue 应用，但常规项目通常只有一个。
- **根组件**：传给 `createApp` 的 `App.vue` 是组件树的根。根组件之下可以继续引用任意多层子组件。
- **单文件组件（SFC）**：`.vue` 文件由 `<script>`、`<template>`、`<style>` 三种顶层块组成，构建工具会把它们编译成普通 JavaScript 模块。
- **`<script setup>`**：Vue 3 推荐的语法糖。顶层声明的变量、函数、导入的组件可以直接在模板中使用，不需要 `return`。
- **`scoped` 样式**：给 `<style>` 加上 `scoped` 后，Vue 会为当前组件的元素添加唯一属性选择器，避免样式污染其他组件。
- **资源引用**：模板里的相对路径图片、`<style>` 里的 `url()` 会由 Vite 处理；需要原样保留路径时使用 `new URL('./asset.png', import.meta.url).href`。

## 二、基础语法

入口文件通常长这样：

```js
// src/main.js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import { createPinia } from 'pinia'

const app = createApp(App)

// 注册插件要在 mount 之前完成
app.use(createPinia())
app.use(router)

app.mount('#app')
```

一个标准 SFC 的基本结构：

```vue
<script setup>
import { ref } from 'vue'

// 顶层声明会自动暴露给模板
const title = ref('商品详情')
</script>

<template>
  <article>
    <h2>{{ title }}</h2>
  </article>
</template>

<style scoped>
article {
  padding: 16px;
}
</style>
```

## 三、完整示例

下面的商品卡片是一个完整可运行的 SFC，包含图片、价格计算、库存状态和加购事件，可以直接放到 `src/components/ProductCard.vue` 使用：

```vue
<script setup>
import { computed, ref } from 'vue'

// 父组件通过 props 传入商品数据
const props = defineProps({
  product: {
    type: Object,
    required: true
  }
})

// 子组件通过事件把“加购”意图通知父组件
const emit = defineEmits(['add-to-cart'])

// 本地状态：当前选择的数量
const quantity = ref(1)

// 计算折后价，保留两位小数
const finalPrice = computed(() => {
  const price = props.product.price * props.product.discount
  return price.toFixed(2)
})

// 计算节省金额
const saved = computed(() => {
  return (props.product.price - Number(finalPrice.value)).toFixed(2)
})

const inStock = computed(() => props.product.stock > 0)

function decrease() {
  if (quantity.value > 1) quantity.value -= 1
}

function increase() {
  if (quantity.value < props.product.stock) quantity.value += 1
}

function addToCart() {
  if (!inStock.value) return
  emit('add-to-cart', {
    id: props.product.id,
    quantity: quantity.value
  })
}
</script>

<template>
  <article class="product-card">
    <div class="cover">
      <img :src="product.cover" :alt="product.name" />
      <span v-if="product.discount < 1" class="badge">
        限时 {{ Math.round(product.discount * 10) }} 折
      </span>
    </div>

    <div class="content">
      <h2>{{ product.name }}</h2>
      <p class="desc">{{ product.description }}</p>

      <div class="price-row">
        <strong>¥{{ finalPrice }}</strong>
        <del v-if="product.discount < 1">¥{{ product.price }}</del>
        <span v-if="product.discount < 1" class="saved">省 ¥{{ saved }}</span>
      </div>

      <p class="stock" :class="{ empty: !inStock }">
        {{ inStock ? `库存 ${product.stock} 件` : '暂时缺货' }}
      </p>

      <div class="actions">
        <div class="stepper">
          <button type="button" :disabled="quantity <= 1" @click="decrease">-</button>
          <span>{{ quantity }}</span>
          <button type="button" :disabled="quantity >= product.stock" @click="increase">+</button>
        </div>

        <button class="buy" type="button" :disabled="!inStock" @click="addToCart">
          {{ inStock ? '加入购物车' : '到货提醒' }}
        </button>
      </div>
    </div>
  </article>
</template>

<style scoped>
```

父组件使用该组件时，只需要导入并传入数据：

```vue
<script setup>
import ProductCard from './components/ProductCard.vue'

function handleAdd(payload) {
  console.log('加入购物车', payload)
}
</script>

<template>
  <ProductCard
    :product="{
      id: 1,
      name: '无线降噪耳机',
      description: '40 小时续航，支持主动降噪',
      cover: '/images/headphone.jpg',
      price: 899,
      discount: 0.8,
      stock: 6
    }"
    @add-to-cart="handleAdd"
  />
</template>
```

## 四、常见坑 / 注意事项

1. **`mount` 的容器必须已存在**：`app.mount('#app')` 执行时，HTML 中必须有 `id="app"` 的元素，否则会得到 `null` 并报错。
2. **`<script setup>` 中的导入会自动注册组件**：不需要再写 `components: { ProductCard }`；如果同时使用普通 `<script>`，两者可以共存，但普通 `<script>` 主要用于声明 `inheritAttrs` 等选项。
3. **`scoped` 不是 CSS 作用域隔离的万能方案**：子组件根节点仍可能受父组件样式影响，深层选择器要用 `:deep()`，插槽内容要用 `:slotted()`。
4. **模板中不能写 `this`**：`<script setup>` 里没有组件实例的 `this`，直接使用顶层变量即可。
5. **多根节点组件会失去自动属性透传**：Vue 3 允许模板有多个根节点，但父组件传入的 `class`、`style` 等不会自动落到某个根节点上，需要显式绑定 `$attrs`。
6. **静态资源路径不要硬编码构建后的目录**：开发环境能访问不代表生产环境能访问，使用 `import` 或 `new URL(..., import.meta.url)` 让构建工具处理。
7. **组件文件名建议使用 PascalCase**：如 `ProductCard.vue`，模板中使用 `<ProductCard />`，与原生 HTML 标签区分更明显。
