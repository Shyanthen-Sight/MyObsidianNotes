# Vue 3 简介与开发环境

> Vue 3 是一个用于构建用户界面的渐进式 JavaScript 框架，核心解决的是“数据变化后如何高效、可维护地更新界面”这个问题。

## 一、核心概念

- **渐进式框架**：Vue 不要求一次性接管整个项目。可以只在页面某个角落用 CDN 引入做局部交互，也可以用 create-vue 搭建完整单页应用，还可以配合 Nuxt 做服务端渲染。
- **声明式渲染**：开发者描述“界面应该长什么样”，Vue 负责把数据映射到 DOM。与手动操作 `document.querySelector` 的命令式写法相比，状态和视图不容易脱节。
- **响应式系统**：Vue 3 使用 `Proxy` 拦截对象读写，在渲染过程中收集依赖，数据变化时精确通知相关组件重新渲染。
- **单文件组件**：一个 `.vue` 文件把 `<script>`、`<template>`、`<style>` 放在一起，配合构建工具完成编译，是目前 Vue 项目最主流的组织方式。
- **Vue 3 的核心能力**：组合式 API 让逻辑可以按关注点聚合；`Proxy` 响应式支持对象和数组的增删改；多根节点组件、`Teleport`、`Suspense` 扩展了组件结构能力；编译器与运行时也做了持续的性能优化。
- **两种 API 风格**：选项式 API 以 `data`、`methods`、`computed` 等选项组织逻辑；组合式 API 以 `setup` 和一系列函数组织逻辑。本笔记默认使用 `<script setup>` 组合式 API。

## 二、基础语法

使用官方脚手架创建项目，推荐 Node.js 20.19 及以上版本（或 22.12 及以上）：

```bash
# 创建项目，按提示选择 TypeScript、Router、Pinia 等能力
npm create vue@latest

# 进入项目并安装依赖
cd my-vue-app
npm install

# 启动开发服务器
npm run dev
```

一个最小的单文件组件如下：

```vue
<script setup>
import { ref } from 'vue'

// ref 创建响应式数据，脚本中通过 .value 读写
const message = ref('你好，Vue 3')
</script>

<template>
  <!-- 模板中自动解包 ref，不需要写 .value -->
  <h1>{{ message }}</h1>
</template>

<style scoped>
h1 {
  color: #42b883;
}
</style>
```

如果只是想在一个传统页面里试用 Vue，也可以使用全局构建版本：

```html
<div id="app">{{ message }}</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp, ref } = Vue

  createApp({
    setup() {
      const message = ref('Hello Vue')
      return { message }
    }
  }).mount('#app')
</script>
```

## 三、完整示例

下面是一个可直接放进 create-vue 项目的欢迎页组件，展示响应式数据、计算属性和事件绑定：

```vue
<script setup>
import { computed, ref } from 'vue'

// 当前登录用户，实际项目中通常来自接口或状态管理
const user = ref({
  name: '林晓',
  role: '前端工程师',
  loginCount: 12
})

// 今日日期用于页面展示
const today = new Date().toLocaleDateString('zh-CN', {
  year: 'numeric',
  month: 'long',
  day: 'numeric'
})

// 根据登录次数计算用户等级，computed 会缓存结果
const level = computed(() => {
  if (user.value.loginCount >= 30) return '资深用户'
  if (user.value.loginCount >= 10) return '活跃用户'
  return '新用户'
})

// 模拟签到，修改响应式数据后界面自动更新
function checkIn() {
  user.value.loginCount += 1
}
</script>

<template>
  <main class="welcome">
    <p class="date">{{ today }}</p>

    <section class="profile">
      <div class="avatar">{{ user.name.slice(0, 1) }}</div>
      <div>
        <h1>欢迎回来，{{ user.name }}</h1>
        <p>{{ user.role }} · {{ level }}</p>
      </div>
    </section>

    <div class="stats">
      <span>累计登录 {{ user.loginCount }} 次</span>
      <button type="button" @click="checkIn">今日签到</button>
    </div>
  </main>
</template>

<style scoped>
.welcome {
  max-width: 640px;
  margin: 48px auto;
  padding: 32px;
  border-radius: 16px;
  background: #ffffff;
  box-shadow: 0 12px 32px rgb(15 23 42 / 8%);
  font-family: system-ui, sans-serif;
}

.date {
  margin: 0 0 24px;
  color: #64748b;
  font-size: 14px;
}

.profile {
  display: flex;
  align-items: center;
  gap: 16px;
}

.avatar {
  display: grid;
  width: 56px;
  height: 56px;
  place-items: center;
  border-radius: 50%;
  background: #42b883;
  color: #ffffff;
  font-size: 22px;
}

h1 {
  margin: 0 0 6px;
  font-size: 24px;
}

.profile p {
  margin: 0;
  color: #475569;
}

.stats {
  display: flex;
  align-items: center;
  justify-content: space-between;
  margin-top: 28px;
  padding-top: 20px;
  border-top: 1px solid #e2e8f0;
}

button {
  padding: 10px 18px;
  border: 0;
  border-radius: 999px;
  background: #42b883;
  color: #ffffff;
  cursor: pointer;
}

button:hover {
  background: #369c6e;
}
</style>
```

## 四、常见坑 / 注意事项

1. **新项目直接用 Vue 3 的官方脚手架**：不要手动拼凑旧版构建配置，`npm create vue@latest` 会生成符合当前生态的 Vite + Vue 3 结构。
2. **`npm create vue@latest` 与 `npm create vite@latest` 不是一回事**：前者是 Vue 官方脚手架，会询问路由、状态管理、测试等选项；后者是通用 Vite 模板。
3. **Node.js 版本要满足要求**：当前 Vite 通常要求 Node.js 20.19+ 或 22.12+，版本过低会在创建项目或启动时直接报错。
4. **`ref` 在脚本中必须通过 `.value` 访问**：模板中 Vue 会自动解包，但 JavaScript 代码里漏写 `.value` 会得到整个 ref 对象。
5. **不要直接修改 `props` 或父组件数据**：Vue 的数据流是单向的，子组件应通过事件通知父组件修改。
6. **CDN 版本适合演示，不适合大型项目**：没有单文件组件、类型检查、代码分割和热更新，项目变大后维护成本很高。
7. **浏览器控制台里的警告不要忽略**：Vue 会在开发环境提示 props 类型错误、缺少 key、事件未声明等问题，这些都是真实缺陷的信号。

## 六、速查表

| 语法                    | 作用                           | 示例                                              |
| ----------------------- | ------------------------------ | ------------------------------------------------- |
| `npm create vue@latest` | 创建 Vue 3 项目                | 按提示选择 Router、Pinia、Vitest                  |
| `createApp`             | 创建应用实例                   | `createApp(App).mount('#app')`                    |
| `ref`                   | 创建基本类型或对象的响应式引用 | `const count = ref(0)`                            |
| `computed`              | 创建带缓存的派生状态           | `const total = computed(() => a.value + b.value)` |
| `<style scoped>`        | 让样式只作用于当前组件         | `<style scoped> .card { ... } </style>`           |
