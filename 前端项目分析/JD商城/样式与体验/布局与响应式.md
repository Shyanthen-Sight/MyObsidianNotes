# 布局与响应式

> [!abstract] 一句话
> 项目的布局主要靠 ==Flex（头部、结算栏、评论头）+ CSS Grid（商品网格、详情双栏、购物车表格）+ 固定定位（详情侧栏、结算栏）== 完成；断点集中在 1500 / 1200 / 900 / 800 / 640 / 600px。全局虽然定义了 CSS 变量，但绝大多数组件仍写死颜色和阴影。

---

## 一、全局基础样式

`src/style.css`：

```css
:root {
  font-family: Inter, "PingFang SC", "Microsoft YaHei", Arial, sans-serif;
  color: #1f2329;
  background: #f5f5f5;
  --jd-red: #e1251b;
  --text-primary: #1f2329;
  --text-secondary: #4e5969;
  --text-muted: #86909c;
  --surface: #fff;
  --border-light: #f0f0f0;
  --radius-md: 10px;
  --shadow-card: 0 8px 24px rgba(31, 35, 41, 0.05);
}

* { box-sizing: border-box; }

html {
  min-width: 320px;
  background: #f5f5f5;
  scroll-behavior: smooth;
}

body {
  min-width: 320px;
  min-height: 100vh;
  margin: 0;
}

input { font: inherit; }
button { font: inherit; }
```

要点：

| 规则 | 作用 |
| --- | --- |
| `box-sizing: border-box` | 宽高包含 padding 和 border，布局更直观 |
| `min-width: 320px` | 防止极窄视口挤压布局 |
| `margin: 0` | 去掉 body 默认外边距 |
| `font: inherit` | 让输入框和按钮继承页面字体 |
| `scroll-behavior: smooth` | 锚点跳转平滑滚动 |
| CSS 变量 | 定义了一套设计令牌 |

> [!warning] 设计令牌基本没有落地
> 全项目只有两处使用全局 CSS 变量：
>
> ```css
> /* goods-list.vue */
> border-color: var(--jd-red);
> background: var(--jd-red);
> ```
>
> 其余组件大量写死 `#e1251b`、`#f0f0f0`、`#86909c`、`rgba(...)`。结果是：变量改了，大部分界面不会变。要么统一改用变量，要么删掉未使用的变量，避免「看起来可配置、实际不可配置」。

## 二、应用外壳

`App.vue`：

```css
.app-shell {
  min-height: 100vh;
  background: #f5f5f5;
}

.page {
  max-width: 1400px;
  margin: 0 auto;
  padding: 80px 16px 24px;
}
```

```text
┌─────────────────────────────────────────────┐
│ TabHeader（正常文档流，高约 72px）           │
├─────────────────────────────────────────────┤
│         .page  max-width: 1400px            │
│         padding-top: 80px                   │
│  ┌───────────────────────────────────────┐  │
│  │ RouterView 页面                       │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

> [!warning] `padding-top: 80px` 与实际头部不匹配
> `.header-bar` **没有** `position: fixed` 或 `position: sticky`，它本身就在文档流中占据约 72px 高度。`.page` 又额外预留 80px 上内边距，因此头部和内容之间会出现约 80px 的空白。
>
> 两种修复方向：
>
> 1. **如果头部本应固定**：给 `.header-bar` 加
>    ```css
>    position: sticky;
>    top: 0;
>    z-index: 100;
>    ```
>    这时 `.page` 的 80px 上内边距才有意义。
> 2. **如果头部本应随页面滚动**：把 `.page` 的 `padding-top` 改成 `24px` 左右。

### 2.1 购物车全宽

```css
.page--full-width {
  max-width: none;
  width: 100vw;
  margin-left: calc(50% - 50vw);
  padding: 0;
}
```

- 取消 1400px 限制。
- `width: 100vw` + 负 margin：从视口左边缘开始。
- `padding: 0`：购物车页自己控制内边距。

`cart.vue` 再补：

```css
.cart-page {
  width: 100%;
  min-height: calc(100vh - 72px);
  padding: 24px clamp(16px, 4vw, 64px) 96px;
}
```

- `clamp(16px, 4vw, 64px)`：左右内边距随视口变化，最小 16px、最大 64px。
- 底部 96px：给固定结算栏留空间。

## 三、顶部导航

```css
.header-bar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
  min-height: 72px;
  padding: 12px max(16px, calc((100% - 1200px) / 2));
  background: linear-gradient(to bottom, #e1251b 0%, #8f140c 100%);
  box-shadow: 0 2px 8px rgba(31, 35, 41, 0.12);
}
```

### 3.1 居中的写法

```css
padding: 12px max(16px, calc((100% - 1200px) / 2));
```

含义：

- 视口很宽时：左右内边距 = `(100% - 1200px) / 2`，内容被限制在 1200px 并居中。
- 视口较窄时：取 `16px`，保证不贴边。

这比嵌套一层 `max-width: 1200px; margin: 0 auto` 更省 DOM，但在窄屏时内容区宽度会受到 padding 影响。

### 3.2 三段式 Flex

```text
[Logo 固定] [搜索框 flex-grow] [购物车 固定] [首页 固定]
```

```css
.logo { flex-shrink: 0; }
.search-bar {
  flex-grow: 1;
  flex-shrink: 1;
  flex-basis: 480px;
  max-width: 900px;
}
.cart-bar, .home-bar { flex-shrink: 0; }
```

- 搜索框占据剩余空间，但最多 900px。
- Logo 和两个圆形按钮不收缩。
- 两个圆按钮 44×44，`border-radius: 50%`。

### 3.3 红色渐变

```css
background: linear-gradient(to bottom, #e1251b 0%, #8f140c 100%);
```

从京东红到深红，营造头部层次。

### 3.4 640px 断点

```css
@media (max-width: 640px) {
  .header-bar { gap: 10px; min-height: 64px; padding: 10px 12px; }
  .logo img { height: 34px; }
  .search-bar { gap: 4px; padding: 2px 8px; }
  .search-bar input { height: 34px; font-size: 13px; }
  .cart-bar, .home-bar { width: 38px; height: 38px; }
}
```

手机上整体缩小，保证四个元素能排在一行。

## 四、商品网格

```css
.goods-grid {
  display: grid;
  grid-template-columns: repeat(4, minmax(0, 1fr));
  gap: 16px;
}

@media (max-width: 900px) {
  .goods-grid { grid-template-columns: repeat(3, minmax(0, 1fr)); }
}

@media (max-width: 640px) {
  .goods-grid { grid-template-columns: repeat(2, minmax(0, 1fr)); gap: 10px; }
}
```

| 断点 | 列数 | 典型设备 |
| --- | --- | --- |
| > 900px | 4 | 桌面 |
| 641–900px | 3 | 平板横屏 / 小桌面 |
| ≤ 640px | 2 | 手机 |

`minmax(0, 1fr)` 防止卡片内容撑破列宽。卡片内部标题用单行省略，图片用 `aspect-ratio: 1`。

## 五、商品详情双栏

```css
.detail-top {
  display: grid;
  grid-template-columns: minmax(0, 1fr) minmax(320px, 1fr);
  gap: 24px;
  align-items: start;
  margin-top: 16px;
}

@media (max-width: 800px) {
  .detail-top { grid-template-columns: 1fr; }
}
```

```text
> 800px：左轮播 | 右信息
≤ 800px：上轮播
        下信息
```

右侧最小 320px，保证价格和按钮不会被压得过窄。两侧 `minmax(0, 1fr)` 让小屏时能正常收缩。

### 5.1 固定侧边导航

```css
.detail-nav {
  position: fixed;
  top: 50%;
  left: 24px;
  z-index: 10;
  width: 112px;
  transform: translateY(-50%);
}

@media (max-width: 1500px) { .detail-nav { left: 8px; } }
@media (max-width: 1200px) { .detail-nav { display: none; } }
```

- 宽屏：固定在视口左侧中间。
- 1500px 以下：贴近边缘。
- 1200px 以下：隐藏，避免遮挡主内容。

### 5.2 卡片容器

详情页各区块统一使用：

```css
background: #fff;
border: 1px solid #f0f0f0;
border-radius: 10px;
box-shadow: 0 8px 24px rgba(31, 35, 41, 0.05);
```

形成「白卡片 + 浅灰背景」的层次。

### 5.3 参数表

```css
.params-list {
  display: grid;
  grid-template-columns: 160px 1fr;
  border-top: 1px solid #f0f0f0;
}
.params-list dt { background: #f7f8fa; color: #86909c; }
.params-list dd { color: #1f2329; }
```

两列网格模拟表格：左侧参数名、右侧参数值。比 `<table>` 更容易做圆角和边框控制。

## 六、购物车网格

```css
.cart-list {
  --cart-columns: 90px minmax(0, 1fr) 120px 140px 140px 60px;
}
.cart-header,
.cart-item {
  display: grid;
  grid-template-columns: var(--cart-columns);
  gap: 20px;
  align-items: center;
}
```

```text
┌──────┬──────────────────┬──────┬──────┬──────┬────┐
│ 封面 │ 商品信息          │ 单价 │ 数量 │ 小计 │操作│
│ 90px │ minmax(0,1fr)    │120px │140px │140px │60px│
└──────┴──────────────────┴──────┴──────┴──────┴────┘
```

表头「商品信息」跨前两列：

```css
.header-product { grid-column: 1 / 3; }
```

每一行通过 `grid-column` 精确放置单价、数量、小计、删除。详见 [[购物车组件]]。

### 6.1 移动端重排

```css
@media (max-width: 800px) {
  .cart-header { display: none; }

  .cart-item {
    grid-template-columns: 72px minmax(0, 1fr) auto;
    gap: 12px;
  }

  .cart-cover { width: 72px; height: 72px; }

  .unit-price,
  .quantity-control,
  .subtotal,
  .remove-button {
    grid-column: 2;
  }
}
```

移动端隐藏表头，商品行改为「封面 + 信息列」的卡片布局。

### 6.2 固定结算栏

```css
.footer-fixed {
  position: fixed;
  right: 0;
  bottom: 0;
  left: 0;
  z-index: 90;
  height: 72px;
}

.footer-inner {
  display: flex;
  align-items: center;
  justify-content: flex-end;
  gap: 28px;
  max-width: 1400px;
  height: 100%;
  margin: 0 auto;
  padding: 0 16px;
}
```

- 固定在底部，内容右对齐。
- 内部再限制 1400px 并居中，与普通页面宽度一致。
- 购物车页底部 `padding-bottom: 96px` 避免遮挡。

600px 以下：

```css
.footer-fixed { height: auto; }
.footer-inner { flex-wrap: wrap; gap: 8px 16px; padding: 10px 12px; }
.footer-inner button { width: 100%; }
```

按钮独占一行。

## 七、`scoped` 与 `:deep`

每个组件都使用 `<style scoped>`，样式只作用于当前组件。

### 7.1 为什么需要 `:deep`

```css
.main-image-swiper :deep(.swiper-slide) {
  display: flex;
  align-items: center;
  justify-content: center;
}
```

`.swiper-slide` 是 Swiper 组件内部生成的 DOM，不带当前组件的 `data-v-*` 属性。普通 `scoped` 选择器匹配不到，必须用 `:deep()` 穿透。

### 7.2 子组件根元素

`CartItem` 的根元素会被父组件 `CartList` 的 scoped 样式影响（Vue 会把父组件的 scope 属性加到子组件根元素上），因此 `CartList` 的 `--cart-columns` 能被 `CartItem` 继承。

## 八、布局技巧清单

| 技巧 | 使用位置 | 解决的问题 |
| --- | --- | --- |
| Flex `justify-content: space-between` | 头部 | 左右分布 |
| Flex `flex-grow` + `flex-basis` | 搜索框 | 自适应宽度 |
| `max(16px, calc((100% - 1200px) / 2))` | 头部 | 内容居中限宽 |
| Grid `repeat(4, minmax(0, 1fr))` | 商品列表 | 等宽列且不撑破 |
| Grid `minmax(0, 1fr)` | 详情双栏 | 可收缩 |
| CSS 自定义属性 `--cart-columns` | 购物车 | 表头与行共用列定义 |
| `position: fixed` + `translateY(-50%)` | 详情侧栏 | 垂直居中固定 |
| `position: fixed` + `left/right/bottom: 0` | 结算栏 | 通栏固定 |
| `calc(50% - 50vw)` | 购物车全宽 | 突破父容器 |
| `clamp(16px, 4vw, 64px)` | 购物车内边距 | 自适应留白 |
| `aspect-ratio: 1` | 商品图 | 固定比例防抖动 |
| `object-fit: cover` | 图片 | 裁剪不变形 |
| `-webkit-line-clamp: 2` | 购物车标题 | 两行截断 |
| `font-variant-numeric: tabular-nums` | 价格 | 数字等宽对齐 |
| `scroll-margin-top` | 详情锚点 | 滚动定位补偿 |

> [!note] `tabular-nums` 的意义
> 价格和数量变化时，等宽数字可以避免整行左右抖动。用在 `.unit-price`、`.subtotal`、`.amount` 上，是一个细节但专业的处理。

## 九、视觉设计

### 9.1 色彩

| 用途 | 颜色 |
| --- | --- |
| 京东红 / 主强调 | `#e1251b` |
| 头部渐变深红 | `#8f140c` |
| 主文字 | `#1f2329` |
| 次文字 | `#4e5969` |
| 弱文字 | `#86909c` |
| 页面背景 | `#f5f5f5` |
| 卡片背景 | `#fff` |
| 浅边框 | `#f0f0f0` / `#e5e6eb` |
| 角标 | `#cbce1e`（黄绿） |

### 9.2 层次

```text
页面背景 #f5f5f5
  └─ 白色卡片 + 10px 圆角 + 轻阴影
       ├─ 商品图
       ├─ 标题 15px 600
       ├─ 店铺 12px 灰
       └─ 价格 24px 700 红
```

### 9.3 交互反馈

- 商品卡片 `hover`：上移 4px + 红色边框 + 阴影加深。
- 按钮 `hover`：颜色变化 / 上移 2px。
- 图片 `hover`：无变化。
- 分页当前页：红底白字。
- 删除按钮 `hover`：变红。

## 十、响应式断点总表

| 断点 | 影响 |
| --- | --- |
| `max-width: 1500px` | 详情侧栏左移 |
| `max-width: 1200px` | 详情侧栏隐藏 |
| `max-width: 900px` | 商品网格 4 → 3 列 |
| `max-width: 800px` | 详情双栏 → 单栏；购物车隐藏表头并重排 |
| `max-width: 640px` | 头部缩小；商品网格 3 → 2 列 |
| `max-width: 600px` | 结算栏换行，按钮通栏 |

> [!tip] 断点比较密集
> 800/900、600/640 两组非常接近，可以合并成一套更简洁的断点体系（如 1200 / 900 / 640）。断点越多，样式越难维护。

## 十一、可以改进的点

| 问题 | 建议 |
| --- | --- |
| `.page` 的 80px 顶部留白与静态头部不匹配 | 头部改 `sticky`，或减少 padding |
| 全局 CSS 变量几乎未使用 | 统一替换硬编码颜色/阴影 |
| `100vw` 可能引入横向滚动 | 用 `width: 100%` + 去父级限宽 |
| 断点密集且不统一 | 合并为 3–4 个断点 |
| 移动端购物车网格依赖自动放置 | 改为 flex 布局 |
| 固定侧栏在 1200px 以下直接消失 | 可改为顶部横向导航 |
| 无 `prefers-reduced-motion` | 尊重用户减少动画偏好 |
| 大量重复的卡片阴影/圆角 | 抽成工具类或变量 |

---

## 十二、小结

```text
整体：浅灰背景 + 白色卡片 + 京东红强调
头部：Flex 三段式 + 红色渐变 + 内容限宽 1200
列表：Grid 4/3/2 列
详情：Grid 双栏 → 单栏；左侧固定锚点导航
购物车：CSS 变量统一六列网格；底部固定结算栏
```

项目在布局上是「够用且有一定细节」的：`minmax(0,1fr)`、`aspect-ratio`、`tabular-nums`、`scroll-margin-top`、`clamp()` 都是成熟写法；主要短板是设计令牌没有贯彻，以及头部定位与预留间距不一致。
