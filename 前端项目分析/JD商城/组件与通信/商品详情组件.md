# 商品详情组件

> [!abstract] 一句话
> 详情页 `goods-detail.vue` 是**数据容器**：它用路由参数 `skuId` ==先取商品、再取评论==，然后把 `product` 分发给轮播、信息面板、参数表、长图四个展示组件，把 `comments` 交给评论列表；页面本身只负责加载状态、错误状态和快速导航。

---

## 一、页面编排

```text
GoodsDetail（props: skuId）
├─ 左侧固定快速导航（锚点）
├─ loading            → 正在加载商品详情...
├─ error              → 商品不存在或加载失败
└─ product 就绪
   ├─ #detail-top
   │  ├─ GoodsGallery     :product
   │  └─ GoodsInfoPanel   :product
   ├─ ShowcaseBoard        :product
   ├─ #detail-images
   │  └─ GoodsScrollImg    :product
   └─ #detail-comments
      └─ CommentList       :comments
```

模板结构：

```vue
<section class="goods-detail-page">
  <nav class="detail-nav" aria-label="商品详情快速导航">
    <a href="#detail-top">商品信息</a>
    <a href="#detail-images">商品图片</a>
    <a href="#detail-comments">用户评价</a>
    <button type="button" aria-label="回到顶部" @click="scrollToTop">
      <el-icon><Top /></el-icon>
    </button>
  </nav>

  <p v-if="loading">正在加载商品详情...</p>
  <p v-else-if="error">{{ error }}</p>

  <template v-else-if="product">
    <div id="detail-top" class="detail-top">
      <GoodsGallery :product="product" />
      <GoodsInfoPanel :product="product" />
    </div>
    <ShowcaseBoard :product="product" />
    <div id="detail-images"><GoodsScrollImg :product="product" /></div>
    <div id="detail-comments"><CommentList :comments="comments" /></div>
  </template>
</section>
```

## 二、数据加载

```js
const props = defineProps({
  skuId: { type: String, required: true },
})

const product = ref(null)
const comments = ref([])
const loading = ref(false)
const error = ref('')

async function loadProduct() {
  loading.value = true
  error.value = ''

  try {
    product.value = await fetchGoodsDetail(props.skuId)
    comments.value = await fetchComments(props.skuId)
  } catch (requestError) {
    error.value = '商品不存在或加载失败'
    console.error('商品详情加载失败：', requestError)
  } finally {
    loading.value = false
  }
}

onMounted(loadProduct)
```

### 2.1 串行请求

```text
fetchGoodsDetail(skuId)  （200ms）
  ↓ 成功
fetchComments(skuId)     （150ms）
  ↓
product / comments 赋值
```

这是**串行**：评论要等商品返回后才请求。总耗时约 350ms。

可以改成并行：

```js
const [productData, commentData] = await Promise.all([
  fetchGoodsDetail(props.skuId),
  fetchComments(props.skuId),
])
```

但串行也有合理性：如果商品不存在，就没必要请求评论。当前实现中，商品 `reject` 后会直接进入 `catch`，评论不会请求。

### 2.2 错误状态

只要商品或评论任一失败，都会显示：

```text
商品不存在或加载失败
```

当前数据下评论接口不会失败，所以实际只会由「找不到商品」触发。

### 2.3 生命周期与路由复用

```js
onMounted(loadProduct)
```

只在组件**挂载**时加载一次。

> [!warning] 同路由不同参数的复用问题
> Vue Router 在 `/goods/A → /goods/B` 时会复用同一个组件实例，不会重新 `mount`。因此如果将来详情页里增加「相关商品」或「下一件」入口，`onMounted` 不会再次执行，页面会停留在 A 的数据。
>
> 修复方式：
>
> ```js
> watch(() => props.skuId, loadProduct)
> ```
>
> 或给 `<RouterView :key="$route.fullPath" />` 加 key 强制重建。当前项目没有页面内跳详情入口，所以问题尚未暴露。

## 三、快速导航

```vue
<nav class="detail-nav" aria-label="商品详情快速导航">
  <a href="#detail-top">商品信息</a>
  <a href="#detail-images">商品图片</a>
  <a href="#detail-comments">用户评价</a>
  <button type="button" aria-label="回到顶部" @click="scrollToTop">
    <el-icon><Top /></el-icon>
  </button>
</nav>
```

### 3.1 锚点跳转

三个 `<a href="#...">` 对应页面中的三个 `id`：

| 链接 | 目标 |
| --- | --- |
| `#detail-top` | 商品信息 + 主图区域 |
| `#detail-images` | 商品详情长图 |
| `#detail-comments` | 用户评价 |

配合全局样式：

```css
html { scroll-behavior: smooth; }
```

以及：

```css
.detail-top { scroll-margin-top: 24px; }
#detail-images,
#detail-comments { scroll-margin-top: 24px; }
```

`scroll-margin-top` 避免滚动后标题贴住视口顶部。

### 3.2 固定侧边导航

```css
.detail-nav {
  position: fixed;
  top: 50%;
  left: 24px;
  z-index: 10;
  width: 112px;
  transform: translateY(-50%);
  background: rgba(255, 255, 255, 0.96);
  border: 1px solid #f0f0f0;
  border-radius: 10px;
  box-shadow: 0 8px 24px rgba(31, 35, 41, 0.12);
}
```

- `top: 50% + translateY(-50%)`：垂直居中。
- `position: fixed`：滚动时始终可见。
- 响应式：
  - `max-width: 1500px` 时 `left: 8px`
  - `max-width: 1200px` 时 `display: none`，避免遮挡内容。

### 3.3 回到顶部

```js
function scrollToTop() {
  window.scrollTo({ top: 0, behavior: 'smooth' })
}
```

使用原生 `window.scrollTo`，不依赖路由。

## 四、主图轮播 `GoodsGallery`

```vue
<Swiper
  class="main-image-swiper"
  :modules="[Autoplay]"
  :autoplay="{ delay: 3000, disableOnInteraction: false }"
  :slides-per-view="1"
  :space-between="0"
>
  <SwiperSlide v-for="(image, index) in images" :key="image">
    <img class="main-image" :src="image" :alt="`商品图片 ${index + 1}`" />
  </SwiperSlide>
</Swiper>
```

```js
const images = computed(() => [
  props.product.mainImageUrls[0],
  ...props.product.detailImageUrls.slice(0, 5),
])
```

### 4.1 图片组成

```text
主图第 1 张
  + 详情图前 5 张
= 最多 6 张轮播图
```

这样详情页顶部既能展示商品主图，也能预览部分细节图。

### 4.2 自动播放

```js
:autoplay="{ delay: 3000, disableOnInteraction: false }"
```

- 每 3 秒切换。
- `disableOnInteraction: false`：用户手动滑动后仍继续自动播放。

### 4.3 样式

```css
.main-image-swiper { width: 100%; height: 590px; }
.main-image-swiper :deep(.swiper-slide) {
  display: flex; align-items: center; justify-content: center;
}
.main-image { width: 100%; height: 100%; object-fit: cover; }
```

- `:deep()` 用于穿透 `scoped` 样式，修改 Swiper 内部生成的 `.swiper-slide`。
- 固定高度 590px + `object-fit: cover`：保证不同比例的图片填满容器，但可能裁掉边缘。
- 容器最小高度 640px，与右侧信息面板对齐。

> [!note] 一个未使用的导入
> ```js
> import 'swiper/css/navigation'
> ```
> 但 `:modules` 只注册了 `Autoplay`，没有注册 `Navigation`。这行样式没有实际作用，可以删除以减少 CSS 体积。

> [!warning] `:key="image"` 可能重复
> 如果主图与某张详情图 URL 相同，`v-for` 的 key 会重复。更稳妥的是 `:key="index"` 或 `${image}-${index}`。

## 五、信息面板 `GoodsInfoPanel`

```vue
<section class="goods-info-panel">
  <h1 class="goods-title">{{ product.title }}</h1>
  <p class="goods-shop">店铺：{{ product.shopName }}</p>
  <p class="goods-price">¥{{ formatPrice(product.price) }}</p>

  <div class="quantity-control">
    <button type="button" @click="decrease">-</button>
    <span>{{ count }}</span>
    <button type="button" @click="increase">+</button>
  </div>

  <button class="add-cart-button" type="button" @click="addToCart">
    加入购物车
  </button>
</section>
```

```js
const count = ref(1)
const { add } = useCart()

function increase() {
  count.value = Math.min(count.value + 1, 99)
}
function decrease() {
  count.value = Math.max(count.value - 1, 1)
}
function addToCart() {
  add(props.product, count.value)
}
```

要点：

1. **数量是组件本地状态**，初始 1，范围 1–99。
2. **加购调用 store 的 `add(product, count)`**，成功后本地 `count` 不会自动归 1。
3. 数量加减逻辑与 `NumAddDel` 重复，可以复用组件：

```vue
<NumAddDel v-model="count" />
```

> [!tip] 加购后的反馈
> 当前点击「加入购物车」没有 `ElMessage` 提示，只有顶部角标数字变化。增加一个轻提示会更明确：
>
> ```js
> import { ElMessage } from 'element-plus'
> function addToCart() {
>   add(props.product, count.value)
>   ElMessage.success('已加入购物车')
> }
> ```

## 六、参数表 `ShowcaseBoard`

```vue
<dl v-if="params.length" class="params-list">
  <template v-for="([key, value]) in params" :key="key">
    <dt>{{ key }}</dt>
    <dd>{{ value }}</dd>
  </template>
</dl>
<p v-else class="empty-params">暂无商品参数</p>
```

```js
const params = computed(() => Object.entries(props.product.params || {}))
```

- `Object.entries` 把 `{ 品牌: '...', 屏幕: '...' }` 转成 `[['品牌', '...'], ['屏幕', '...']]`。
- 模板里用数组解构 `[key, value]`。
- `<template v-for>` 同时渲染 `<dt>` 和 `<dd>`，避免额外的包裹元素破坏 `<dl>` 结构。

样式：

```css
.params-list {
  display: grid;
  grid-template-columns: 160px 1fr;
  border-top: 1px solid #f0f0f0;
}
.params-list dt { color: #86909c; background: #f7f8fa; }
.params-list dd { color: #1f2329; }
```

两列网格：左边参数名、右边参数值。每个单元格都有下边框，形成表格效果。

> [!note] 参数顺序
> `Object.entries` 的顺序是对象键的插入顺序，也就是 JSON 中的书写顺序，不是按字母或重要性排序。对展示来说通常可接受；如果要固定顺序，需要维护一个「优先展示的参数名」数组。

## 七、详情长图 `GoodsScrollImg`

```vue
<section class="goods-scroll-img">
  <h2>商品图片</h2>
  <img
    v-for="(image, index) in product.detailImageUrls"
    :key="image"
    :src="image"
    :alt="`商品详情图 ${index + 1}`"
  />
</section>
```

- 渲染 `detailImageUrls` 的全部图片（轮播只取前 5 张）。
- 图片宽度 `min(100%, 720px)` 并居中，避免大图撑满宽屏。
- 没有 `loading="lazy"`，所有长图会一次性加载。详情图通常较大，这是性能改进点。

## 八、评论列表 `CommentList`

### 8.1 模板结构

```vue
<section class="comment-list">
  <h2>用户评价（{{ comments.length }}）</h2>

  <p v-if="comments.length === 0" class="empty">暂无评价</p>

  <article
    v-for="comment in comments"
    :key="`${comment.nickname}-${comment.time}`"
    class="comment-item"
  >
    <div class="comment-header">
      <img v-if="comment.avatar" :src="comment.avatar" :alt="comment.nickname" />
      <span v-else class="avatar-placeholder">
        {{ comment.nickname.slice(0, 1) }}
      </span>
      <span class="nickname">{{ comment.nickname }}</span>
      <time>{{ comment.time }}</time>
    </div>

    <p class="comment-content">{{ comment.content }}</p>
    <p v-if="comment.after" class="after-comment">追评：{{ comment.after }}</p>

    <div v-if="comment.images.length" class="comment-images">
      <img v-for="image in comment.images" :key="image" :src="image" alt="用户评价图片" />
    </div>
  </article>
</section>
```

### 8.2 细节设计

| 细节 | 实现 | 作用 |
| --- | --- | --- |
| 头像兜底 | `v-if="comment.avatar"`，否则显示昵称首字 | 头像缺失时不出现破图 |
| 昵称 | `{{ comment.nickname }}` | 已脱敏，如 `云***节` |
| 时间 | `<time>` 语义标签 | 语义化 |
| 追评 | `v-if="comment.after"` | 只有存在追评时显示 |
| 晒图 | `v-if="comment.images.length"` | 没图不占位 |
| 图片布局 | flex + wrap，120×120 | 多图自动换行 |

### 8.3 两个健壮性问题

**问题一：重复 key**

```js
:key="`${comment.nickname}-${comment.time}`"
```

600 条评论中有 **127 组** `昵称 + 时间` 重复。Vue 遇到重复 key 会出现渲染复用错误，可能导致评论错位或更新异常。

根源在数据层：`fetchComments` 把 `comment_id` 丢弃了。修复方式：

```js
// api/goods.js
.map((comment) => ({
  id: comment.comment_id,
  nickname: comment.user_nickname,
  // ...
}))
```

```vue
:key="comment.id"
```

**问题二：`comment.images.length` 无兜底**

如果某条评论缺少 `images_urls`，数据层得到 `images: undefined`，模板访问 `.length` 会抛错：

```text
Cannot read properties of undefined (reading 'length')
```

修复：

```js
images: comment.images_urls || [],
```

### 8.4 评论加载方式

- 一次性加载该商品的全部评论（每个商品 1–10 条），没有分页或「加载更多」。
- 当前数据量很小，不需要虚拟列表；如果评论上千条，需要分页或懒加载。
- 所有晒图一次性加载，建议加 `loading="lazy"`。

## 九、详情页数据流

```text
点击商品卡片
  ↓
router.push(`/goods/${skuId}`)
  ↓
路由匹配 /goods/:skuId，props: true
  ↓
GoodsDetail 收到 skuId
  ↓
onMounted(loadProduct)
  ↓
fetchGoodsDetail(skuId)  → product
  ↓
fetchComments(skuId)     → comments
  ↓
product 分发给 4 个组件；comments 分发给 CommentList
  ↓
用户点「加入购物车」
  ↓
GoodsInfoPanel.add(product, count)
  ↓
cart store 更新 → 角标 / 购物车页同步
```

## 十、可以改进的点

| 问题 | 影响 | 建议 |
| --- | --- | --- |
| 评论 key 重复 | 渲染错位 | 保留 `comment_id` |
| `images.length` 无兜底 | 缺字段时报错 | 默认 `[]` |
| 数量控件重复 | 维护两套逻辑 | 复用 `NumAddDel` |
| 加购无提示 | 反馈弱 | `ElMessage.success` |
| 详情图不懒加载 | 首屏流量大 | `loading="lazy"` |
| 轮播 key 可能重复 | 渲染警告 | 用索引 |
| 导入未使用的 Navigation CSS | 体积浪费 | 删除 |
| 参数变化不重载 | 同组件复用 bug | `watch(() => props.skuId)` |
| 评论无分页 | 大数据量卡顿 | 分页 / 懒加载 |
| 评分字段被丢弃 | 无法展示星级 | 归一化保留 `score` |

## 十一、小结

详情页可以概括成：

```text
一个参数（skuId）
  ↓
两个请求（商品、评论）
  ↓
五个展示组件（轮播、信息、参数、长图、评论）
  ↓
一个动作（加入购物车）
```

它展示了一个很典型的「容器组件 + 展示组件」模式：容器负责数据和状态，展示组件只负责把 props 变成 DOM。
