# 第 10 讲：JavaScript 中的闭包（Closures in JS）

> [!abstract] 本讲要点
> - 函数连同它的词法作用域一起打包，就构成闭包（Closure）。
> - 即使外层函数已经返回，闭包仍能记住并访问其外层作用域中的变量。
> - 闭包的典型应用包括模块设计模式、柯里化、记忆化、数据隐藏与封装、setTimeout。
> - 滥用闭包会带来内存过度占用、内存泄漏和浏览器卡顿。

## 一、什么是闭包

- 函数连同它的词法作用域一起打包，就是**闭包**（Closure）。

- JavaScript 具有词法作用域环境。如果函数需要访问某个变量，它首先去自己的本地内存中查找；在那里找不到时，就去其词法父级的内存中查找。看下面的代码，这里的函数 **y** 连同它的词法作用域（即函数 x）就被称为闭包。

  ```js
  function x() {
    var a = 7;
    function y() {
      console.log(a);
    }
    return y;
  }
  var z = x();
  console.log(z); // z 的值就是函数 y 的完整代码。
  ```

  - 在上面的代码中，当 y 被返回时，返回的不只是函数本身，而是整个闭包（函数 y + 它的词法作用域），并被放入 z 中。因此，当 z 在程序的其他地方被使用时，它仍然记得 x() 内部的 var a。

- 另一个例子：

```js
function z() {
  var b = 900;
  function x() {
    var a = 7;
    function y() {
      console.log(a, b);
    }
    y();
  }
  x();
}
z(); // 7 900
```

- 因此，用简单的话说：

  - **闭包是一个函数**，即使外层函数已经返回，它仍能访问外层函数的作用域。也就是说，闭包可以记住并访问其外层函数的变量和参数引用，即使外层函数已经返回。

## 二、闭包的优势

- 闭包的优势：

  下面为上面提到的每一项优势分别举例说明。

### 1. 模块设计模式

- 模块设计模式允许我们把相关的功能封装到一个模块或文件中。它有助于组织代码、防止全局命名空间污染，并提升代码的可复用性。
- 示例：假设我们在构建一个 Web 应用，想创建一个处理用户认证的模块。我们可以创建一个 `auth.js` 模块，导出 `login`、`logout` 和 `getUserInfo` 等函数。

  ```js
  // auth.js
  const authModule = (function () {
    let loggedInUser = null;

    function login(username, password) {
      // 用户认证逻辑……
      loggedInUser = username;
    }

    function logout() {
      loggedInUser = null;
    }

    function getUserInfo() {
      return loggedInUser;
    }

    return {
      login,
      logout,
      getUserInfo,
    };
  })();

  // 使用
  authModule.login("john_doe", "secret");
  console.log(authModule.getUserInfo()); // 'john_doe'
  ```

### 2. 柯里化

- 柯里化（Currying）是一种技术：把接收多个参数的函数转换为一系列每次只接收一个参数的函数。它支持部分应用（partial function application），并增强代码的灵活性。
- 示例：创建一个柯里化函数，用来计算含税的商品总价。

  ```js
  const calculateTotalPrice = (taxRate) => (price) =>
    price + price * (taxRate / 100);

  const calculateSalesTax = calculateTotalPrice(8); // 8% 销售税
  const totalPrice = calculateSalesTax(100); // 含税价格
  console.log(totalPrice); // 108
  ```

### 3. 记忆化

- 记忆化（Memoization）通过缓存函数结果来优化开销大的函数调用，适用于递归或重复计算。
- 示例：实现一个带记忆化的斐波那契函数。

  ```js
  function fibonacci(n, memo = {}) {
    if (n in memo) return memo[n];
    if (n <= 1) return n;

    memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo);
    return memo[n];
  }

  console.log(fibonacci(10)); // 55
  ```

### 4. 数据隐藏与封装

- 封装（Encapsulation）隐藏对象的内部细节，只暴露必要的方法和属性。它提升了代码的可维护性和安全性。
- 示例：创建一个带有私有属性的 `Person` 类。

  ```js
  class Person {
    #name; // 私有字段

    constructor(name) {
      this.#name = name;
    }

    getName() {
      return this.#name;
    }
  }

  const person = new Person("Alice");
  console.log(person.getName()); // 'Alice'
  // console.log(person.#name); // Error: Private field '#name' must be declared in an enclosing class
  ```

### 5. setTimeout

- `setTimeout` 允许把一个函数安排在指定延迟之后运行，常用于异步任务、动画和事件处理。
- 示例：延迟显示消息。

  ```js
  function showMessage(message, delay) {
    setTimeout(() => {
      console.log(message);
    }, delay);
  }

  showMessage("Hello, world!", 2000); // 2 秒后显示
  ```

- 这些示例展示了闭包在 JavaScript 中的强大与多样！🚀

## 三、闭包的劣势

- 闭包的劣势：
  - 内存占用过多
  - 内存泄漏
  - 使浏览器卡顿
