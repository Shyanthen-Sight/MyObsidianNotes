# 解构赋值（Destructuring）

> 一句话：解构赋值就是「**按一个模式，把对象或数组里的值一次取出来，赋给变量**」。等号左边写的是"我要什么形状的数据"，等号右边是要拆的数据源。

```js
// 不用解构
const message = object4.message;
const age = object4.age;

// 用解构
const { message, age } = object4;
```

两者结果完全一样，解构只是写法更短、意图更集中。

---

## 一、本质：左边是「模式」，右边是「值」

### 1.1 对照理解

```js
const user = { name: '小明', age: 18 };

// 等号左边 {} 里的 name，不是新对象，
// 而是在声明：从右边按属性名 name 取一个值，存进变量 name
const { name, age } = user;

console.log(name); // '小明'
console.log(age);  // 18
```

可以把它理解成**模式匹配**：

```
右边：{ name: '小明', age: 18 }
左边：{ name,          age      }
       ↓              ↓
变量：  name = '小明'   age = 18
```

### 1.2 两种形态：声明式 vs 赋值式

```js
// ① 声明式：在 const / let / var 后面直接解构（最常用）
const { name } = user;

// ② 赋值式：变量已经声明过了，用解构重新赋值
let name;
({ name } = user); // 注意：整体必须加圆括号
```

### 1.3 记忆口诀

- **对象看名字，数组看位置**
- **冒号左边是键，冒号右边是新变量名**
- **等号后面是默认值**
- **`...` 负责收集剩下的**

---

## 二、对象解构：按「键名」匹配

### 2.1 基本用法

```js
const user = { name: '小明', age: 18, city: '北京' };

const { name, age } = user;
console.log(name, age); // 小明 18
```

特点：

- 按**属性名**匹配，**和书写顺序无关**。
- 只取想要的字段，其他字段自动忽略。
- 属性不存在时，变量值为 `undefined`，**不会报错**。

```js
const { city, name } = user;
console.log(city, name); // 北京 小明

const { height } = user;
console.log(height); // undefined
```

### 2.2 重命名：`{ 原键名: 新变量名 }`

当变量名和属性名冲突，或者想换个更清晰的名字时：

```js
const { name: userName, age: userAge } = user;

console.log(userName); // 小明
console.log(userAge);  // 18
// console.log(name);  // 报错：name 没有被声明
```

方向很重要：**冒号左边是源对象的键，右边才是新变量。**

```js
const { message: msg } = object4;
console.log(msg); // 'Good job!'
```

### 2.3 默认值：`{ 键名 = 默认值 }`

当取到的值是 `undefined` 时使用默认值：

```js
const user = { name: '小明', age: 18 };

const { name = '游客', gender = '未知' } = user;
console.log(name);   // 小明（有值，不用默认）
console.log(gender); // 未知（没有该属性，用默认）
```

⚠️ **只有 `undefined` 会触发默认值**，`null`、`0`、`''`、`false` 都不会：

```js
const { a = 1 } = {};
const { b = 1 } = { b: null };
const { c = 1 } = { c: 0 };

console.log(a); // 1
console.log(b); // null  ← 不是 1
console.log(c); // 0     ← 不是 1
```

默认值可以是表达式，并且**只在真正需要时才求值**：

```js
let count = 0;

const { value = (count++, '默认值') } = { value: '有值' };
console.log(value); // 有值
console.log(count); // 0 ← 默认值表达式没有执行

const { other = (count++, '默认值') } = {};
console.log(other); // 默认值
console.log(count); // 1 ← 这次执行了
```

默认值还可以引用**同一个模式中前面已声明的变量**：

```js
const { a, b = a + 1 } = { a: 10 };
console.log(a, b); // 10 11
```

### 2.4 重命名 + 默认值

两者可以组合，顺序是「键 : 新名 = 默认值」：

```js
const { name: userName = '游客' } = {};
console.log(userName); // 游客

const { age: userAge = 0 } = { age: 18 };
console.log(userAge); // 18
```

### 2.5 剩余属性：`...rest`

把**没有显式取出的其余属性**收集到一个新对象里：

```js
const user = { name: '小明', age: 18, city: '北京' };

const { name, ...others } = user;
console.log(name);   // 小明
console.log(others); // { age: 18, city: '北京' }
```

注意：

- `rest` 必须放在**最后**，否则语法错误。
- `rest` 拿到的是**浅拷贝的新对象**，但里面的引用类型仍是同一份引用。

```js
const { ...rest, name } = user; // ❌ SyntaxError: Rest element must be last
```

### 2.6 嵌套解构

对象里套对象、对象里套数组，都可以一层层拆：

```js
const config = {
  user: { name: '小红', age: 20 },
  theme: 'dark'
};

const { user: { name }, theme } = config;
console.log(name, theme); // 小红 dark
```

嵌套时也可以顺便重命名：

```js
const { user: { name: userName } } = config;
console.log(userName); // 小红
```

嵌套层级缺失时，可以给**外层**一个默认值兜底：

```js
const { user: { name = '匿名' } = {} } = { theme: 'dark' };
console.log(name); // 匿名
```

如果不写 `= {}`，就会变成对 `undefined` 解构，直接报错：

```js
const { user: { name } } = { theme: 'dark' };
// ❌ TypeError: Cannot destructure property 'name' of 'undefined'
```

### 2.7 计算属性名：`{ [表达式]: 变量 }`

属性名不是固定字符串时，用方括号：

```js
const user = { name: '小明', age: 18 };
const key = 'name';

const { [key]: value } = user;
console.log(value); // 小明
```

⚠️ 不要写成 `{ key }`——那是在找名为 `key` 的属性：

```js
const { key } = user;
console.log(key); // undefined
```

计算属性名也可以配合重命名和默认值：

```js
const field = 'age';
const { [field]: userAge = 0 } = user;
console.log(userAge); // 18
```

### 2.8 给已有变量赋值：必须加圆括号

如果变量已经用 `let` / `var` 声明过：

```js
let name, age;
const user = { name: '小明', age: 18 };

({ name, age } = user); // ✅ 整体加圆括号

console.log(name, age); // 小明 18
```

为什么不加括号不行？

```js
{ name, age } = user; // ❌ 语法错误
```

因为语句开头的 `{` 会被 JS 当成**代码块**，而不是解构模式。加圆括号是为了告诉引擎："这是一个表达式"。

### 2.9 对象解构小结表

| 左侧写法 | 含义 | 例子 |
| --- | --- | --- |
| `{ a }` | 取属性 `a`，存为变量 `a` | `const { a } = obj` |
| `{ a: x }` | 取属性 `a`，存为变量 `x` | `const { a: x } = obj` |
| `{ a = 1 }` | 属性 `a` 为 `undefined` 时用 `1` | `const { a = 1 } = obj` |
| `{ a: x = 1 }` | 取 `a` 存为 `x`，缺失时用 `1` | `const { a: x = 1 } = obj` |
| `{ ...rest }` | 收集剩余属性 | `const { a, ...rest } = obj` |
| `{ a: { b } }` | 嵌套解构 | `const { a: { b } } = obj` |
| `{ [key]: x }` | 动态属性名 | `const { [key]: x } = obj` |

## 三、数组解构：按「位置」匹配

### 3.1 基本用法

```js
const arr = [10, 20, 30];

const [a, b] = arr;
console.log(a, b); // 10 20
```

数组看**顺序**：第一个变量拿第一个元素，第二个变量拿第二个元素，以此类推。

### 3.2 跳过元素：用逗号占位

```js
const arr = [10, 20, 30];

const [, , c] = arr;
console.log(c); // 30

const [, second] = arr;
console.log(second); // 20
```

### 3.3 默认值

```js
const [a = 1, b = 2] = [10];
console.log(a, b); // 10 2
```

同样是**只有 `undefined` 才触发**：

```js
const [x = 1] = [null];
console.log(x); // null
```

默认值也可以引用前面的变量：

```js
const [a, b = a * 2] = [3];
console.log(a, b); // 3 6
```

### 3.4 剩余元素：`...rest`

```js
const [first, ...rest] = [1, 2, 3, 4];
console.log(first); // 1
console.log(rest);  // [2, 3, 4]
```

- 数组的 `rest` 永远是**数组**。
- `rest` 必须在最后。

```js
const [first, second, ...others] = [1, 2, 3, 4, 5];
console.log(others); // [3, 4, 5]
```

### 3.5 交换变量（经典用法）

```js
let a = 1;
let b = 2;

[a, b] = [b, a];

console.log(a, b); // 2 1
```

不需要临时变量，也不需要中间对象。

### 3.6 嵌套数组

```js
const [[a], [b, c]] = [[1], [2, 3]];
console.log(a, b, c); // 1 2 3
```

嵌套缺失时同样可以用默认值兜底：

```js
const [[a = 0] = []] = [];
console.log(a); // 0
```

### 3.7 任意可迭代对象都能解构

数组解构本质上走的是**迭代器协议**，所以字符串、`Set`、`Map`、生成器等都可以：

```js
// 字符串
const [first, second] = 'hi';
console.log(first, second); // h i

// Set
const [x, y] = new Set([1, 2, 3]);
console.log(x, y); // 1 2

// Map 的每一项是 [key, value]
const map = new Map([
  ['a', 1],
  ['b', 2]
]);

for (const [key, value] of map) {
  console.log(key, value);
}
// a 1
// b 2

// 生成器
function* gen() {
  yield 1;
  yield 2;
}

const [g1, g2] = gen();
console.log(g1, g2); // 1 2
```

但**普通对象不可迭代**：

```js
const [a] = { 0: 'x', 1: 'y' };
// ❌ TypeError: object is not iterable
```

### 3.8 接收函数返回的多个值

```js
function getMinMax(nums) {
  return [Math.min(...nums), Math.max(...nums)];
}

const [min, max] = getMinMax([3, 1, 4, 1, 5]);
console.log(min, max); // 1 5
```

### 3.9 给已有变量赋值：注意分号

```js
let a, b;
[a, b] = [1, 2];
```

单独一行没问题，但如果**上一行没有写分号**，就会出问题：

```js
const x = 1
[a, b] = [1, 2]
// JS 会解析成：const x = 1[a, b] = [1, 2]
```

解决办法是行首加分号：

```js
const x = 1
;[a, b] = [1, 2]
```

或者干脆养成写分号的习惯。

### 3.10 数组解构小结表

| 左侧写法 | 含义 | 例子 |
| --- | --- | --- |
| `[a, b]` | 按位置取前两个 | `const [a, b] = arr` |
| `[, , c]` | 跳过前两个，取第三个 | `const [, , c] = arr` |
| `[a = 1]` | 位置值为 `undefined` 时用 `1` | `const [a = 1] = arr` |
| `[first, ...rest]` | 收集剩余元素 | `const [first, ...rest] = arr` |
| `[[a], [b]]` | 嵌套解构 | `const [[a], [b]] = arr` |

## 四、对象与数组混合解构

实际数据经常是"对象套数组"或"数组套对象"，两种模式可以自由组合：

```js
const data = {
  title: '列表',
  list: [
    { id: 1, name: '苹果' },
    { id: 2, name: '香蕉' }
  ]
};

// 取出 list 的第一项
const { list: [firstItem] } = data;
console.log(firstItem); // { id: 1, name: '苹果' }

// 再往里取第一项的 name
const { list: [{ name: firstName }] } = data;
console.log(firstName); // 苹果

// 同时取多个
const {
  title,
  list: [first, second]
} = data;

console.log(title);       // 列表
console.log(first.name);  // 苹果
console.log(second.name); // 香蕉
```

数组里套对象：

```js
const users = [
  { name: '小明', age: 18 },
  { name: '小红', age: 20 }
];

const [{ name: firstUserName }, { age: secondUserAge }] = users;
console.log(firstUserName); // 小明
console.log(secondUserAge); // 20
```

## 五、函数参数解构（实践中最常用）

### 5.1 对象参数：调用方按需传

```js
// 传统写法：函数体里反复点 options
function greet(options) {
  console.log(options.name, options.age);
}

// 参数解构：函数体里直接用 name / age
function greet({ name, age }) {
  console.log(name, age);
}

greet({ name: '小明', age: 18 }); // 小明 18
```

好处：参数含义一目了然，调用方不用记参数顺序。

### 5.2 防止不传参报错：`= {}`

```js
function greet({ name, age }) {
  console.log(name, age);
}

greet(); // ❌ TypeError: Cannot destructure property 'name' of 'undefined'
```

加一个整体默认值：

```js
function greet({ name = '游客', age = 0 } = {}) {
  console.log(name, age);
}

greet();                 // 游客 0
greet({ name: '小明' }); // 小明 0
```

注意末尾的 `= {}` **不能省**，它负责在"完全没传参"时兜底。

### 5.3 只取部分字段 + 剩余字段

```js
function createUser({ name, age, ...extra }) {
  console.log(name, age); // 小明 18
  console.log(extra);     // { city: '北京', role: 'admin' }
}

createUser({
  name: '小明',
  age: 18,
  city: '北京',
  role: 'admin'
});
```

### 5.4 数组参数

```js
function distance([x1, y1], [x2, y2]) {
  return Math.hypot(x2 - x1, y2 - y1);
}

console.log(distance([0, 0], [3, 4])); // 5
```

### 5.5 混合参数

```js
function request(url, { method = 'GET', body = null } = {}) {
  console.log(url, method, body);
}

request('/api/user');
// /api/user GET null

request('/api/user', { method: 'POST', body: '{"name":"小明"}' });
// /api/user POST {"name":"小明"}
```

## 六、实战场景

### 6.1 处理接口返回数据

```js
const response = {
  code: 200,
  data: {
    list: [
      { id: 1, name: '苹果' },
      { id: 2, name: '香蕉' }
    ],
    total: 2
  }
};

const {
  code,
  data: { list = [], total = 0 } = {}
} = response;

console.log(code);  // 200
console.log(list);  // [{ id: 1, ... }, { id: 2, ... }]
console.log(total); // 2
```

接口字段可能缺失时，用默认值 + 外层 `= {}` 双重兜底：

```js
const { data: { user = null } = {} } = response;
```

### 6.2 React 组件 props

```js
function Card({ title, children, onClick = () => {} }) {
  return (
    <div onClick={onClick}>
      <h3>{title}</h3>
      {children}
    </div>
  );
}

<Card title="标题">内容</Card>;
```

### 6.3 配置合并

```js
const defaultConfig = {
  theme: 'light',
  size: 'md',
  showSidebar: true
};

const userConfig = {
  theme: 'dark'
};

const config = { ...defaultConfig, ...userConfig };
const { theme, size, showSidebar } = config;

console.log(theme, size, showSidebar);
// dark md true
```

### 6.4 模块导入

`import` 的命名导入本质上也是解构：

```js
import { ref, computed } from 'vue';
import { useState, useEffect } from 'react';

// 相当于从模块暴露的对象里按名字取值
```

### 6.5 遍历 Map / entries()

```js
const scores = new Map([
  ['小明', 90],
  ['小红', 95]
]);

for (const [name, score] of scores) {
  console.log(`${name}: ${score}`);
}

const arr = ['a', 'b'];

for (const [index, item] of arr.entries()) {
  console.log(index, item); // 0 'a' / 1 'b'
}
```

### 6.6 排序比较函数

```js
const users = [
  { name: '小明', age: 18 },
  { name: '小红', age: 20 }
];

users.sort(({ age: a }, { age: b }) => a - b);
console.log(users.map(({ name }) => name)); // ['小明', '小红']
```

### 6.7 解析 JSON / LocalStorage

```js
const raw = localStorage.getItem('user');
const { name = '游客', age = 0 } = raw ? JSON.parse(raw) : {};

console.log(name, age);
```

### 6.8 一次返回多个值

```js
function parseUser(input) {
  const [name, age] = input.split(',');
  return { name, age: Number(age) };
}

const { name, age } = parseUser('小明,18');
console.log(name, age); // 小明 18
```

## 七、常见坑

### 1. 拼错键名不会报错，只会拿到 `undefined`

```js
const user = { name: '小明' };
const { nmae } = user;
console.log(nmae); // undefined ← 静默错误
```

### 2. 解构 `null` / `undefined` 会直接报错

```js
const { a } = null;
// ❌ TypeError: Cannot destructure property 'a' of 'null'

const [b] = undefined;
// ❌ TypeError: undefined is not iterable
```

需要用默认值或可选链兜底：

```js
const { a } = obj ?? {};
const [b] = arr ?? [];
```

### 3. 默认值只认 `undefined`

```js
const { a = 1 } = { a: null }; // a 是 null，不是 1
const { b = 1 } = { b: 0 };    // b 是 0，不是 1
```

### 4. `const` 声明必须当场赋值

```js
const { a }; // ❌ SyntaxError: Missing initializer
```

只有 `let` / `var` 可以先声明后赋值：

```js
let a;
({ a } = obj);
```

### 5. 对象整体赋值必须加圆括号

```js
let a, b;
{ a, b } = obj;   // ❌ 被当成代码块
({ a, b } = obj); // ✅
```

### 6. 数组赋值前一行注意分号

```js
const x = 1
[a, b] = [1, 2] // ❌ 被解析成 1[a, b] = ...
```

改成：

```js
const x = 1
;[a, b] = [1, 2] // ✅
```

### 7. `...rest` 必须放在最后

```js
const { ...rest, a } = obj; // ❌ SyntaxError
const [ ...rest, a] = arr;  // ❌ SyntaxError
```

### 8. 解构不是深拷贝

```js
const config = {
  user: { name: '小红' }
};

const { user } = config;
user.name = '小明';

console.log(config.user.name); // 小明 ← 原对象被改了
```

解构出来的对象引用和原对象指向同一块内存。需要独立副本时要手动拷贝：

```js
const { user: userCopy } = config;
const independent = { ...userCopy };
```

### 9. 数组解构要求「可迭代」

```js
const [a] = 123;
// ❌ TypeError: 123 is not iterable

const [b] = { 0: 'x' };
// ❌ TypeError: object is not iterable
```

### 10. 计算属性名必须加方括号

```js
const key = 'name';

const { key } = obj;        // ❌ 找的是名为 "key" 的属性
const { [key]: value } = obj; // ✅ 找的是 obj[key]
```

### 11. 函数参数解构时，不传参会报错

```js
function f({ a }) {}
f(); // ❌ TypeError
```

应写成：

```js
function f({ a } = {}) {}
f(); // ✅
```

### 12. 解构会触发 getter

```js
const obj = {
  get a() {
    console.log('getter 被调用');
    return 1;
  }
};

const { a } = obj;
// 打印：getter 被调用
```

如果 getter 有副作用，解构时要注意。

## 八、速查表

### 8.1 语法总览

```js
// 对象
const { a, b: newName, c = 1, d: x = 2, ...rest } = obj;
//      ↑   ↑           ↑       ↑            ↑
//     取a 取b并改名     c默认    d改名且默认   其余属性

// 数组
const [first, , third = 3, ...others] = arr;
//      ↑    ↑  ↑            ↑
//     第一  跳过 默认值       其余元素

// 函数参数
function fn({ a, b = 1 } = {}) {}
function fn2([x, y]) {}
```

### 8.2 两类解构对比

| | 对象解构 | 数组解构 |
| --- | --- | --- |
| 匹配依据 | **属性名** | **位置 / 顺序** |
| 重命名 | `{ a: x }` | 不支持（位置本身就是名字） |
| 默认值 | `{ a = 1 }` | `[a = 1]` |
| 剩余 | `{ ...rest }` → 对象 | `[...rest]` → 数组 |
| 跳过 | 不取即可 | `[, , c]` |
| 数据源要求 | 任意对象（含字符串） | 任意**可迭代对象** |
| 常见用途 | 配置、props、接口数据 | 多返回值、交换、Map 遍历 |

### 8.3 解构 vs 展开运算符

| 写法 | 方向 | 作用 |
| --- | --- | --- |
| `const { a } = obj` | 右 → 左 | 把属性拆成变量 |
| `const copy = { ...obj }` | 右 → 左 | 把对象展开成新对象（浅拷贝） |
| `const [a] = arr` | 右 → 左 | 按位置拆元素 |
| `const copy = [...arr]` | 右 → 左 | 把数组展开成新数组（浅拷贝） |
| `function f(...args)` | 调用方 → 参数 | 收集剩余参数 |

### 8.4 什么时候用解构

- 从对象 / 数组里**只取几个字段**时。
- **函数参数很多**，希望调用方按名字传参时。
- 处理**接口返回数据**（`response.data`）时。
- 需要**一次返回多个值**时。
- **交换变量**、遍历 `Map` / `entries()` 时。
- 模块 `import { x, y }` 时。
