# 第 18 讲：高阶函数与函数式编程（Higher-Order Functions ft. Functional Programming）

> [!abstract] 本讲要点
> - 高阶函数（Higher-Order Function）就是接收一个或多个函数作为参数，或者把函数作为返回值返回的普通函数。
> - 求面积和求周长的代码骨架完全一样，只有计算逻辑不同，重复书写会违反 DRY 原则。
> - 把计算逻辑抽成独立函数后，同一个 `calculate` 就能复用于面积、周长等不同运算。
> - `calculate` 本质上就是 `map` 函数的 polyfill 实现。

## 一、什么是高阶函数？

**问：什么是高阶函数？**

**答**：高阶函数就是普通的函数，它可以接收一个或多个函数作为参数，也可以把函数作为返回值返回。例如：

```js
function x() {
  console.log("Hi");
}
function y(x) {
  x();
}
y(x); // Hi
// y 是高阶函数
// x 是回调函数
```

> [!note] 关键点
> `y` 之所以是高阶函数，是因为它把函数 `x` 作为参数接收；`x` 则是回调函数（Callback Function），因为它被当作参数传给了 `y`。

## 二、面试中该如何切入

下面来看看在面试中应该怎样思考解法。现在有一个半径数组，我需要用这些半径算出面积，并把结果存进一个数组。

**第一种写法：**

```js
const radius = [1, 2, 3, 4];
const calculateArea = function (radius) {
  const output = [];
  for (let i = 0; i < radius.length; i++) {
    output.push(Math.PI * radius[i] * radius[i]);
  }
  return output;
};
console.log(calculateArea(radius));
```

上面的解法完全可以正常工作。但如果现在的需求变成计算周长数组，代码就会变成这样：

```js
const radius = [1, 2, 3, 4];
const calculateCircumference = function (radius) {
  const output = [];
  for (let i = 0; i < radius.length; i++) {
    output.push(2 * Math.PI * radius[i]);
  }
  return output;
};
console.log(calculateCircumference(radius));
```

但这样一来，我们就违反了某些原则，比如 DRY 原则。下面看看更好的写法。

> [!warning] 问题所在
> 两段代码只有中间的计算公式不同，循环和收集结果的骨架完全重复，这正是 DRY（Don't Repeat Yourself，不要重复自己）原则所反对的。

## 三、更好的写法：把逻辑抽成函数

```js
const radiusArr = [1, 2, 3, 4];

// 计算面积的逻辑
const area = function (radius) {
    return Math.PI * radius * radius;
}

// 计算周长的逻辑
const circumference = function (radius) {
    return 2 * Math.PI * radius;
}

const calculate = function(radiusArr, operation) {
    const output = [];
    for (let i = 0; i < radiusArr.length; i++) {
        output.push(operation(radiusArr[i]));
    }
    return output;
}
console.log(calculate(radiusArr, area));
console.log(calculate(radiusArr, circumference));
// 这里 calculate 就是 HOF（高阶函数）
// 这里我们把逻辑抽取到了独立的函数中。这正是函数式编程的美妙之处。
```

> [!tip] 换个角度看
> 这里的 `calculate` 其实就相当于 `map` 函数的 polyfill。也就是说，`console.log(radiusArr.map(area))` 与 `console.log(calculate(radiusArr, area))` 是等价的。

## 四、把 calculate 改造成 map

下面把上面的 `calculate` 函数改造成 `map` 函数的形式，并尝试使用它。于是：

```js
Array.prototype.calculate = function(operation) {
    const output = [];
    for (let i = 0; i < this.length; i++) {
        output.push(operation(this[i]));
    }
    return output;
}
console.log(radiusArr.calculate(area))
```
