# 启动与路由

> [!abstract] 一句话
> 应用从 `index.html` 的 `#app` 开始，由 `main.js` 执行 ==`createApp(App)` → `app.use(ElementPlus)` → `app.use(router)` → `app.mount('#app')`==；`App.vue` 作为常驻外壳渲染顶部导航和 `<RouterView />`，路由表把 3 个 URL 映射到 3 个页面，并用重定向和通配路由兜底。

---

## 一、启动链路

```text
index.html
  └─ <div id="app"></div>
  └─ <script type="module" src="/src/main.js"></script>
        ↓
src/main.js
  ├─ createApp(App)
  ├─ app.use(ElementPlus)
  ├─ app.use(router)
  └─ app.mount('#app')
        ↓
src/App.vue
  ├─ <TabHeader />
  └─ <RouterView />
        ↓
路由匹配 → views/ 下的页面组件
```

### 1.1 `index.html`

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <link rel="icon" href="/jd.ico">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="theme-color" content="#e1251b">
    <title>京东商城</title>
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.js"></script>
  </body>
</html>
```

几个值得注意的点：

- `lang="zh-CN"`：声明中文页面，利于屏幕阅读器和搜索引擎。
- `theme-color="#e1251b"`：移动端浏览器地址栏主题色，与京东红一致。
- 页面本身只有空的 `#app`，所有内容由 Vue 渲染。

### 1.2 `main.js`

```js
import { createApp } from 'vue'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import App from './App.vue'
import './style.css'
import router from './router'

const app = createApp(App)

app.use(ElementPlus)
app.use(router)

app.mount('#app')
```

四步：

1. **`createApp(App)`**：创建 Vue 应用实例，`App.vue` 是根组件。
2. **`app.use(ElementPlus)`**：注册 Element Plus 全部组件，并引入它的完整 CSS。
3. **`app.use(router)`**：安装路由，之后组件里才能使用 `useRouter()`、`useRoute()` 和 `<RouterView />`。
4. **`app.mount('#app')`**：把应用挂载到 `index.html` 的 `#app` 节点。

> [!warning] 全量引入的代价
> `app.use(ElementPlus)` 会注册所有 Element Plus 组件，`element-plus/dist/index.css` 也会整体打包。项目实际只用了消息框、确认框和 4 个图标，因此构建出来的 CSS 约 385 kB、JS 约 1.9 MB。按需引入的改法见 [[代码质量与改进]]。

### 1.3 全局样式

`main.js` 引入了两个样式文件：

```js
import 'element-plus/dist/index.css'   // 组件库样式
import './style.css'                  // 项目全局样式与 CSS 变量
```

`style.css` 中定义了：

```css
:root {
  --jd-red: #e1251b;
  --text-primary: #1f2329;
  --text-secondary: #4e5969;
  --text-muted: #86909c;
  --surface: #fff;
  --border-light: #f0f0f0;
  --radius-md: 10px;
  --shadow-card: 0 8px 24px rgba(31, 35, 41, 0.05);
}
```

这些变量被各组件复用，形成统一的视觉语言，详见 [[布局与响应式]]。

## 二、根组件 `App.vue`

```vue
<script setup>
import TabHeader from './components/tab-header.vue'
import { useRoute } from 'vue-router'

const route = useRoute()
</script>

<template>
  <div class="app-shell">
    <TabHeader />
    <main class="page" :class="{ 'page--full-width': route.name === 'cart' }">
      <RouterView />
    </main>
  </div>
</template>
```

`App.vue` 只做两件事：

1. 无论当前路由是什么，都显示 `<TabHeader />`，所以搜索框和购物车入口不会随页面切换消失。
2. 用 `<RouterView />` 渲染当前路由匹配到的页面。

### 2.1 为什么购物车页要「全宽」

普通页面使用：

```css
.page {
  max-width: 1400px;
  margin: 0 auto;
  padding: 80px 16px 24px;
}
```

但购物车页希望内容占满视口宽度，所以 `App.vue` 根据路由名动态加类：

```vue
:class="{ 'page--full-width': route.name === 'cart' }"
```

对应样式：

```css
.page--full-width {
  max-width: none;
  width: 100vw;
  margin-left: calc(50% - 50vw);
  padding: 0;
}
```

`calc(50% - 50vw)` 的作用是抵消父容器的居中约束，让元素从视口最左侧开始。

> [!note] 这是一种常见的「突破父容器宽度」技巧
> 它简单有效，但 `100vw` 包含滚动条宽度，在某些浏览器里可能产生轻微横向滚动。更稳妥的写法是 `width: 100%` 配合把外层约束去掉，或用 `margin-inline: calc(50% - 50vw)`。

### 2.2 `route.name` 的使用

`useRoute()` 返回当前路由的响应式对象。这里用 `route.name === 'cart'` 判断是否在购物车页。路由名在 `router/index.js` 中定义：

```js
{ path: '/cart', name: 'cart', component: Cart }
```

## 三、路由表

`src/router/index.js`：

```js
import { createRouter, createWebHistory } from 'vue-router'
import GoodsList from '@/views/goods-list.vue'
import GoodsDetail from '@/views/goods-detail.vue'
import Cart from '@/views/cart.vue'

const routes = [
  { path: '/', redirect: '/goods' },
  { path: '/goods', name: 'goods-list', component: GoodsList },
  { path: '/goods/:skuId', name: 'goods-detail', component: GoodsDetail, props: true },
  { path: '/cart', name: 'cart', component: Cart },
  { path: '/:pathMatch(.*)*', redirect: '/goods' },
]

export default createRouter({
  history: createWebHistory(),
  routes,
  scrollBehavior: () => ({ top: 0 }),
})
```

| 路径 | 名称 | 页面 | 作用 |
| --- | --- | --- | --- |
| `/` | — | 重定向 | 自动跳到 `/goods` |
| `/goods` | `goods-list` | `goods-list.vue` | 商品列表、搜索、分页 |
| `/goods/:skuId` | `goods-detail` | `goods-detail.vue` | 商品详情 |
| `/cart` | `cart` | `cart.vue` | 购物车 |
| `/:pathMatch(.*)*` | — | 重定向 | 未知路径回到商品列表 |

### 3.1 动态路由参数

```js
{
  path: '/goods/:skuId',
  name: 'goods-detail',
  component: GoodsDetail,
  props: true,
}
```

`:skuId` 是动态段。访问 `/goods/100288035468` 时，`skuId` 的值就是 `"100288035468"`。

`props: true` 会把路由参数自动作为 prop 传给组件：

```js
// goods-detail.vue
const props = defineProps({
  skuId: { type: String, required: true },
})
```

等价于：

```vue
<GoodsDetail sku-id="100288035468" />
```

好处：组件不直接依赖 `$route`，更容易测试和复用。

> [!warning] 同一个组件复用时不会重新挂载
> 从 `/goods/A` 跳到 `/goods/B` 时，Vue Router 会复用同一个 `GoodsDetail` 实例，`onMounted` 不会再次执行。本项目详情页只在 `onMounted(loadProduct)` 中加载数据，因此如果将来出现「详情页内跳到另一个详情页」的入口，需要额外 `watch(() => props.skuId, loadProduct)`。详见 [[商品详情组件]]。

### 3.2 History 模式

```js
history: createWebHistory()
```

地址形如：

```text
http://localhost:5173/goods
http://localhost:5173/goods/100288035468
http://localhost:5173/cart
```

另一种是 Hash 模式：

```text
http://localhost:5173/#/goods
```

History 模式更自然，但部署到静态服务器时需要配置 **SPA fallback**：把所有未知路径回退到 `index.html`，否则直接刷新 `/goods/123` 会 404。

### 3.3 滚动行为

```js
scrollBehavior: () => ({ top: 0 })
```

每次路由跳转后自动回到页面顶部。这对商品列表翻页和详情页切换很重要，否则会保留上一页的滚动位置。

### 3.4 404 兜底

```js
{ path: '/:pathMatch(.*)*', redirect: '/goods' }
```

任何未匹配的路径都会回到商品列表，避免出现空白页。

## 四、页面内的导航方式

项目里出现了三种导航：

### 4.1 按路径跳转

```js
router.push('/cart')
router.push('/goods')
router.push(`/goods/${props.product.skuId}`)
```

用于购物车入口、首页入口、商品卡片、购物车商品封面。

### 4.2 按 query 跳转

`tab-header.vue` 的搜索：

```js
function onSearch() {
  const value = keyword.value.trim()
  router.push({
    path: '/goods',
    query: value ? { keyword: value } : {},
  })
}
```

搜索后 URL 变成：

```text
/goods?keyword=手机
```

列表页通过 `route.query.keyword` 读取搜索词，并 `watch` 它的变化：

```js
watch(
  () => route.query.keyword,
  () => {
    currentPage.value = 1
    loadGoods()
  },
)
```

> [!tip] 为什么用 query 而不是把搜索词存在组件里
> 写进 URL 后，搜索状态可以分享、刷新保留、前进后退恢复。这是「URL 即状态」的典型做法。分页页码目前没有写进 URL，是一个可改进点，见 [[代码质量与改进]]。

### 4.3 锚点跳转

详情页的快速导航使用原生锚点：

```html
<a href="#detail-top">商品信息</a>
<a href="#detail-images">商品图片</a>
<a href="#detail-comments">用户评价</a>
```

配合页面内的 `id`：

```html
<div id="detail-top">...</div>
<div id="detail-images">...</div>
<div id="detail-comments">...</div>
```

以及 `scroll-behavior: smooth` 和 `scroll-margin-top`，实现平滑滚动和遮挡补偿。

## 五、启动与路由小结

```text
浏览器加载 index.html
  ↓
main.js 创建应用并安装 Element Plus、Router
  ↓
App.vue 渲染 TabHeader + RouterView
  ↓
Router 根据 URL 选择页面：
  /goods        → GoodsList
  /goods/:skuId → GoodsDetail（skuId 作为 prop）
  /cart         → Cart
  /             → 重定向到 /goods
  其它          → 重定向到 /goods
```

需要记住的三个点：

1. **`app.use(router)` 之后才拥有路由能力。**
2. **`<RouterView />` 是页面出口，导航栏放在它外面才能常驻。**
3. **URL 是重要的状态载体：搜索词进 query，商品 ID 进动态段。**
