## 一、本关目标

上一关只能改地址栏，这一关解决两个问题：

1. 怎样在页面里**声明式**跳转（`<router-link>`）；
2. 怎样在代码里**编程式**跳转（`useRouter().push()`）。

同时回答一个常见疑问：**为什么不能用普通 `<a href>` 做站内跳转？**

答案藏在 `App.vue` 的计数器里：计数器放在 `<router-view />` 外面，属于根组件。`router-link` / `push` 只替换出口内容，计数器不归零；`<a href>` 触发整页刷新，Vue 应用被销毁重建，计数器回到 0。

### 路由表（与上一关完全相同）

```js
const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', component: Home },
    { path: '/about', component: About },
  ],
})
```

### `src/App.vue`

- **作用**：根组件；本关新增导航栏与计数器。
- **脚本**：

```js
import { ref } from 'vue'

// 计数器放在 App.vue 里 —— 也就是 <router-view> 外面。
// 这样切换页面时它不会被销毁，才能真正用来对比「路由切换」和「整页刷新」。
const clicks = ref(0)
```

- **模板结构**：
  1. 顶栏（`第 2 关` / `用链接跳转` / 「关卡地图」普通链接）；
  2. `<nav class="nav">`：两个 `<router-link to>`；
  3. 一行计数器按钮 + 提示文字；
  4. `<router-view />`；
  5. 「本步新增」说明块。

```vue
<nav class="nav">
  <router-link to="/">首页</router-link>
  <router-link to="/about">关于</router-link>
</nav>

<div class="row" style="margin-bottom: 16px">
  <button class="btn" type="button" @click="clicks++">计数 +1（当前 {{ clicks }}）</button>
  <span class="muted">切页面它不会归零，整页刷新才会</span>
</div>

<router-view />
```

- **说明**：
  - `<router-link>` 由插件全局注册，不需要 import。
  - 当前地址对应的链接会自动获得 `router-link-active` 类；`.nav a.router-link-active` 的样式早已写在 `style.css` 里。
  - 在 `/` 时「首页」高亮；跳到 `/about` 后「关于」高亮。
  - 计数器是 ref，切换路由时根组件不重建，所以值保留。

### `src/pages/Home.vue`

- **作用**：演示三种导航方式并让读者做对照实验。
- **脚本**：

```js
import { useRouter } from 'vue-router'
const router = useRouter()
```

- **模板要点**：

```vue
<router-link class="btn btn--primary" to="/about">router-link 跳转</router-link>
<a class="btn" href="/about">普通 a 标签跳转</a>
<button class="btn" type="button" @click="router.push('/about')">代码里 push</button>
```

- **说明**：
  - `useRouter()` 拿到**路由器实例**（可写），用于 `push` / `replace` / `back`；与只读的 `useRoute()` 区分。
  - `router.push('/about')` 等同于点击 `router-link`，只做客户端跳转。
  - 普通 `<a href="/about">` 会让浏览器重新请求文档，Vue 应用重新初始化，于是计数器归零。
  - 页面底部用 `<pre class="code">` 对比两种写法，并注明「整页刷新：别用在站内」。
  - 模板里的 `<router-link>` 内容如果是纯文本，`class="btn"` 会直接作用在渲染出的 `<a>` 上。

### `src/pages/About.vue`

- **作用**：说明「页面切换了但没刷新」该怎么验证。
- **说明**：
  - 提示打开开发者工具的 **Network** 面板：`router-link` 只请求一个很小的模块，`<a>` 会重新请求整份 HTML。

## 三、本关要点

- 声明式导航用 `<router-link to>`，编程式导航用 `router.push(...)`；两者都不刷新页面。
- 普通 `<a href>` 会整页刷新，SPA 里只应用于站外链接或确实需要重载的场景。
- `useRoute()` 读当前路由（只读），`useRouter()` 执行导航（可写）。
- 激活样式：默认类名是 `router-link-active`（前缀匹配），需要「完全相等」时用 `router-link-exact-active`，或给 `<router-link>` 加 `exact` 相关配置（后续关卡会在嵌套场景里用到精确版）。
- `router-link` 仍渲染成真实 `<a>`，保留了新标签页、复制链接等原生能力。
