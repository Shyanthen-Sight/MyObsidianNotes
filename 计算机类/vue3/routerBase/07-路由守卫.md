# 第 7 关 · 路由守卫

> 一句话：路由记录上用 `meta` 打「需要登录」的标记，`router.beforeEach` 在每次跳转前检查；未登录就改道登录页，并把原地址塞进 `?redirect=`，登录后再送回去。

## 一、本关目标

1. 用 `meta` 给路由附加自定义元信息（本关是 `requiresAuth`）；
2. 用全局前置守卫 `router.beforeEach` 做统一拦截；
3. 用 `query.redirect` 保存「本来想去哪」，登录后 `router.replace` 回去；
4. 认识一个细节：**守卫只在导航时执行**，退出登录不会自动把用户踢出当前页。

### 路由表与守卫新增

```js
// 需要登录才能进的页面，用 meta 打个标记
{ path: '/admin', name: 'admin', component: Admin, meta: { requiresAuth: true } },
{ path: '/login', name: 'login', component: Login },

// ...

router.beforeEach((to) => {
  if (to.meta.requiresAuth && !auth.user) {
    // 返回一个地址 = 改道。顺便把「本来想去哪」放进 query
    return { name: 'login', query: { redirect: to.fullPath } }
  }
  // 什么都不返回 = 放行
})
```

### `src/auth.js`

- **作用**：最小的登录态实现，替代 Pinia 等状态库。
- **完整内容**：

```js
import { reactive } from 'vue'

// 一个最小的登录态。放模块作用域里，谁 import 拿到的都是同一个对象。
// 真实项目里通常换成 Pinia，但演示守卫不需要那么重。
export const auth = reactive({
  user: null,
})

export function login(name = '小明') {
  auth.user = { name }
}

export function logout() {
  auth.user = null
}
```

- **说明**：
  - 模块只执行一次，`auth` 是模块级单例；各组件 `import` 到的是同一个响应式对象，因此 `Admin.vue`、`App.vue`、`Login.vue` 看到的状态一致。
  - `reactive` 让模板在 `auth.user` 变化时自动更新。
  - `login` / `logout` 封装写操作，避免各页面直接改字段。
  - 没做持久化：刷新页面登录态丢失，正常现象。
  - 真实项目里应换成 Pinia，并在路由守卫中处理 token 过期、权限角色等。

### `src/main.js`

- **作用**：路由表加入受保护页面，并注册全局前置守卫。
- **完整路由表**：

```js
routes: [
  { path: '/', name: 'home', component: Home },
  { path: '/about', name: 'about', component: About },
  { path: '/old-about', redirect: '/about' },
  { path: '/users', name: 'users', component: Users },
  { path: '/users/:id', name: 'user', component: UserDetail, props: true },

  {
    path: '/settings',
    component: SettingsLayout,
    children: [
      { path: '', name: 'settings', component: SettingsProfile },
      { path: 'security', name: 'settings-security', component: SettingsSecurity },
    ],
  },

  // 新增：需要登录才能进的页面，用 meta 打个标记
  { path: '/admin', name: 'admin', component: Admin, meta: { requiresAuth: true } },
  { path: '/login', name: 'login', component: Login },

  { path: '/:pathMatch(.*)*', name: 'not-found', component: NotFound },
]
```

- **守卫**：

```js
router.beforeEach((to) => {
  if (to.meta.requiresAuth && !auth.user) {
    return { name: 'login', query: { redirect: to.fullPath } }
  }
})
```

- **说明**：
  - 新增导入 `Admin`、`Login` 与 `auth`。
  - `meta` 是路由记录上的任意自定义字段，Vue Router 不解释它的内容；`requiresAuth` 是作者约定的名字，换成 `needLogin` 等也可以，只要路由表与守卫保持一致。
  - 没写 `meta` 的路由，`to.meta.requiresAuth` 为 `undefined`（falsy），直接放行。
  - `to.fullPath` 带查询串与 hash，例如 `/admin?tab=1`，保存后能精确返回。
  - 守卫返回一个**路由地址对象**表示重定向；`return false` 取消导航；`return true` 或什么都不返回则放行。
  - 初始导航（首次进入应用）也会触发 `beforeEach`。
  - `/login` 自身不能带 `requiresAuth`，否则会「重定向到登录页 → 又被拦截」形成死循环。
- **文件末尾的 `/*PS ... */` 注释**：
  - 解释 `meta` 是自定义元信息字段、`requiresAuth` 是自己起的名字；
  - 解释 `/:pathMatch(.*)*` 各部分的含义；
  - 给出「登录后 `router.push(route.query.redirect || '/')`」的写法；
  - 这些是教学注释，不参与运行；其中「`pathMatch` 是字符串」的说法在带末尾 `*` 时并不准确（见第 6 关笔记的易错点）。

### `src/pages/Login.vue`

- **作用**：模拟登录页，并负责登录后回跳。
- **脚本全文**：

```js
import { useRoute, useRouter } from 'vue-router'
import { auth, login } from '../auth'

const route = useRoute()
const router = useRouter()

function signIn() {
  login('小明')

  // 守卫把原本想去的地址放在 ?redirect= 里，登录成功后送回去
  const redirect = String(route.query.redirect || '/')
  router.replace(redirect)
}
```

- **说明**：
  - `route.query.redirect` 的类型是 `string | null | Array<string | null>`；用 `String(...)` 统一成字符串，缺省回首页 `/`。
  - 用 `router.replace` 而不是 `push`：登录页不应留在历史记录里，否则用户点「后退」会回到登录页。
  - `login('小明')` 是同步的假登录；真实项目里这里会是异步请求 + token 存储。
  - 模板会根据 `auth.user` 显示「你已经是 小明 了」或「这里是模拟登录」。
  - 如果直接访问 `/login`（没有 `redirect`），登录后回首页。

## 三、本关要点与易错点

1. **守卫返回值**：返回路由地址 = 重定向；返回 `false` = 取消；返回 `true` / `undefined` = 放行。异步守卫需 `async` 并 `return`。
2. **登录页不能自保护**：`/login` 加 `requiresAuth` 会导致无限重定向。
3. **`to.fullPath` 带查询串**：比 `to.path` 更适合做回跳目标。
4. **守卫只在导航时运行**：登录态变化本身不会触发守卫；退出后要主动导航。
5. **`meta` 是约定，不是内置权限系统**：它只是挂在路由记录上的普通对象，真正的权限判断要自己写；`meta` 也可用于标题、面包屑、页面缓存标记等。
6. **服务端也要校验**：前端守卫只能改善体验，不能作为安全边界；受保护数据必须由后端鉴权。
7. **`router.replace` 用于登录后回跳**：避免历史栈里留下登录页。
