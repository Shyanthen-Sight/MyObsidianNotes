# 第 8 关 · 路由懒加载

> 一句话：把 `component` 从「组件对象」换成「返回 `import()` 的函数」，构建时这一页就会被拆成独立 chunk，首屏不下载，第一次访问才请求。

## 一、本关目标

1. 用动态 `import()` 实现**路由级代码分割**；
2. 验证方式：构建后看 `dist/assets/` 是否多出独立的 `Report-xxxx.js`；
3. 理解「静态引入」与「懒加载」的取舍：不是所有页面都值得拆。

### 路由表唯一变化

```js
// 新增：只写一个函数，不直接 import。
// 打包时这一页会被拆成独立文件，第一次访问才下载。
{ path: '/report', name: 'report', component: () => import('./pages/Report.vue') },
```

其余路由、守卫、重定向、通配兜底都与第 7 关一致。

### `src/main.js`

- **作用**：路由表加入懒加载的「报表」页；顶部仍保留所有静态 import。
- **关键代码**：

```js
// 顶部：没有 import Report —— 本关刻意不静态引入这一页
// 上面这些 import 是「静态引入」：打包时全部进入首屏 bundle。
// 只有一个页面的体积明显偏大，才值得用下面那种写法拆出去。

// 路由表里只写一个返回 import() 的函数
{ path: '/report', name: 'report', component: () => import('./pages/Report.vue') },
```

- **完整要点**：

```js
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import Users from './pages/Users.vue'
import UserDetail from './pages/UserDetail.vue'
import SettingsLayout from './pages/SettingsLayout.vue'
import SettingsProfile from './pages/SettingsProfile.vue'
import SettingsSecurity from './pages/SettingsSecurity.vue'
import NotFound from './pages/NotFound.vue'
import Admin from './pages/Admin.vue'
import Login from './pages/Login.vue'
import { auth } from './auth'
import './style.css'
```

- **说明**：
  - 除了 `Report.vue`，其它页面仍是静态引入：它们会被打进同一个首屏 bundle。这正是作者想强调的取舍——**只为真正「重」的页面拆包**，过度拆分会产生大量小请求，反而降低首屏效率。
  - `component: () => import(...)` 是一个返回 Promise 的函数；导航到 `/report` 时，Vue Router 会等待这个 Promise 解析后再渲染。
  - 动态 import 的路径必须是**静态可分析的字面量**，Vite 才能在构建时找到对应模块并拆包；`import('./pages/' + name + '.vue')` 这类拼接路径无法可靠拆分。
  - 守卫部分与第 7 关完全相同：

```js
router.beforeEach((to) => {
  if (to.meta.requiresAuth && !auth.user) {
    return { name: 'login', query: { redirect: to.fullPath } }
  }
})
```

  - Vue Router 也支持在路由级别写 `component: () => import(...)` 的同时保留 `props`、`meta`、`children` 等字段，本关的 `/report` 没有额外字段。

## 三、本关要点与易错点

1. **写法对比**：

   ```js
   // 静态引入：进入首屏 bundle
   import Report from './pages/Report.vue'
   { path: '/report', component: Report }

   // 懒加载：独立 chunk，访问时才下载
   { path: '/report', component: () => import('./pages/Report.vue') }
   ```

2. **何时值得拆**：页面体积明显偏大、访问频率低、或带有重量级第三方库时；首页与高频页面通常保持同步引入，避免首屏多一次往返。
3. **路径必须可静态分析**：Vite 在构建期分析 `import()` 的参数，拼接变量会导致拆包失败或匹配不到模块。
4. **第一次访问有等待**：动态 import 是异步的，网络慢时会出现短暂空白；需要更好体验可配合加载态、`Suspense`，或对 chunk 做预取。
5. **验证要看构建产物**：开发模式下所有模块本来按需加载，无法体现差异；执行 `npm run build` 后检查 `dist/assets/`。
6. **懒加载不影响路由其他能力**：命名、`meta`、`props`、嵌套、守卫在懒加载路由上照常工作。
