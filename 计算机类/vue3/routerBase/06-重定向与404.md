# 第 6 关 · 重定向与 404

> 一句话：`redirect` 把旧地址静默改道到新地址；`'/:pathMatch(.*)*'` 兜住所有匹配不到的路径，让「白屏」变成一个有内容的 404 页。

## 一、本关目标

1. 旧地址用 `redirect` 改道，用户感知不到中间过程；
2. 用通配路由捕获所有未命中的地址，渲染 404 页面；
3. 理解通配参数 `pathMatch` 的含义与类型。

### 路由表新增两条

```js
// 旧地址自动改道到新地址
{ path: '/old-about', redirect: '/about' },

// ...

// 兜底。必须写在最后，否则它会把上面所有路由都吃掉
{ path: '/:pathMatch(.*)*', name: 'not-found', component: NotFound },
```

### `src/main.js`

- **作用**：路由表新增重定向与通配兜底，并在文件末尾保留了两段较长的注释说明。
- **完整路由表**：

```js
routes: [
  { path: '/', name: 'home', component: Home },
  { path: '/about', name: 'about', component: About },

  // 新增：旧地址自动改道到新地址
  { path: '/old-about', redirect: '/about' },

  { path: '/users', name: 'users', component: Users },
  { path: '/users/:id', name: 'user', component: UserDetail, props: true },

  {
    path: '/settings',
    component: SettingsLayout,
    children: [
      { path: '', name: 'settings', component: SettingsProfile },
      { path: 'security', name: 'settings-security', component: SettingsSecurity },
    ],
  },

  // 新增：兜底。必须写在最后，否则它会把上面所有路由都吃掉
  { path: '/:pathMatch(.*)*', name: 'not-found', component: NotFound },
]
```

- **说明**：
  - 新增导入 `NotFound`。
  - `redirect` 可以直接写路径字符串，也可以写 `{ name: 'about' }`，或用函数动态决定；本关用最简单的字符串形式。
  - `redirect` 与 `alias` 不同：**重定向会改变地址栏**（`/old-about` → `/about`），别名则是两个地址都指向同一组件、地址不变。
  - 通配记录必须有 `name`（这里叫 `not-found`），否则用名字跳转/判断时不方便。
  - 关于「必须放最后」：Vue Router 会按路径评分排序，通配路由评分最低，通常仍会最后命中；但把它写在最后是明确的工程约定，能避免以后加入自定义正则路由时出现意料之外的顺序问题，也让路由表更易读。
  - 文件末尾的 `/*PS ... */` 块是作者对 `meta` 与 `/:pathMatch(.*)*` 的补充讲解，属于注释而非可执行代码；其中「`pathMatch` 拿到的是字符串」这一说法与 `*` 的实际行为有出入，见下文「易错点」。

## 三、本关要点与易错点

1. **404 不是 HTTP 状态码**：SPA 内部路由匹配失败时页面仍由服务器返回 200；真正的 404 语义要靠服务端或 SSR 处理。
2. **`redirect` 与 `alias`**：
   - `redirect`：访问旧地址时**替换**为新地址（地址栏变化）；
   - `alias`：旧地址与新地址指向同一组件，地址保持不变。
3. **通配写法拆解**：`/` + `:pathMatch`（参数名可自取） + `(.*)`（正则，匹配任意字符含 `/`） + `*`（可重复 0 次或多次）。
4. **`pathMatch` 的类型容易误判**：
   - 使用 `*`（可重复参数）时，`route.params.pathMatch` 是**字符串数组**，例如访问 `/a/b` 得到 `['a', 'b']`，直接用 `{{ }}` 插值会显示成 JSON；
   - 若希望得到 `"a/b"` 这样的字符串，可写成 `'/:pathMatch(.*)'`（不带末尾 `*`），或对数组做 `join('/')`。
   - 这是源码注释里「拿到的是字符串」的实际偏差，使用时以控制台输出为准。
5. **通配必须放最后**：即使路由器会按评分排序，把兜底写在最后仍是推荐做法。
6. **重定向目标也要存在**：`redirect` 指向的路径若没有对应记录，会继续落到 404，形成「跳过去还是 404」的现象。
