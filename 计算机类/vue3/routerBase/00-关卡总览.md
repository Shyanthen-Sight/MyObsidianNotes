# Vue Router 八关渐进式示例 · 总览

> 一句话：这组源码把 Vue Router 的核心用法拆成 8 个可独立运行的最小工程，每一关只在前一关的基础上增加一个概念，适合边跑边对比。

📁 源码根目录：`C:\Users\Shyanthen\Desktop\VueRouter`（本笔记只记录其结构与要点，不复制源码）

---

## 一、仓库定位

这不是一个完整的业务项目，而是一套**教学用的渐进式示例**：

- 8 个目录各自是**独立工程**，各有自己的 `package.json`、`vite.config.js`、`src/`，没有 monorepo、没有根级 `package.json`、没有共享依赖。
- 每一关都**可以直接单独运行**，互不依赖；同时运行也不会冲突，因为端口固定错开（5171–5178）。
- 后一关基本是复制前一关再改，路由表遵循「**只加不改**」的节奏，方便直接 diff 出本关新增了什么。
- 每关页面里都有一块「本步新增」说明区，`App.vue` 或首页也会提示验证方法。

每个关卡目录的标准骨架：

```text
0X-xxx/
├── .gitignore          # node_modules / dist / .DS_Store
├── index.html          # 唯一的 HTML 入口，挂载点 #app
├── package.json        # 依赖与脚本
├── package-lock.json   # npm 自动生成的锁文件
├── vite.config.js      # Vue 插件 + 固定端口
└── src/
    ├── main.js         # 创建应用、创建路由、注册插件
    ├── App.vue         # 根组件：顶栏 + 导航 + <router-view />

    ├── data/users.js   # 从第 3 关起出现的假数据
    └── pages/          # 每个路由对应的页面组件
```

## 三、运行方式

每个关卡**分别**安装和启动：

```bash
cd 01-minimal
npm install
npm run dev      # 默认 http://localhost:5171
```

| 关卡 | 端口 | 运行命令 |
| :--- | ---: | :--- |
| 01-minimal | 5171 | `npm run dev` |
| 02-link | 5172 | `npm run dev` |
| 03-params | 5173 | `npm run dev` |
| 04-named | 5174 | `npm run dev` |
| 05-nested | 5175 | `npm run dev` |
| 06-404 | 5176 | `npm run dev` |
| 07-guard | 5177 | `npm run dev` |

脚本统一为三个：`dev`（Vite 开发服务器）、`build`（生产构建）、`preview`（预览构建产物）。

## 六、重复与冗余说明

1. **`02-link/02-link/` 是一份完整的重复副本。**
   它与 `02-link/` 下的同名文件内容一致（`src` 目录、`index.html`、`package.json`、`vite.config.js` 经对比均无差异），看起来是复制目录时误嵌套造成的。阅读时**只看 `02-link/` 即可**，本套笔记不为副本重复成篇。

2. **`style.css` 有 8 份。**
   这是为了让每个关卡都能独立运行而刻意复制的；改样式时要意识到**不会**自动同步到其它关。

3. **`node_modules/` 出现在部分关卡里。**
   `03-params` 等工作区里能看到已安装的依赖，但已被 `.gitignore` 排除，不属于源码内容。

4. **`package-lock.json` 每个关卡都有。**
   它记录依赖树的精确版本和下载地址（本仓库使用 `registry.npmmirror.com` 镜像），属于生成文件。

## 八、几个容易踩的坑

1. **顶栏的「关卡地图」链接并不存在。**
   每关 `App.vue` 都写着 `<a class="back" href="/">关卡地图</a>`，但仓库根目录没有地图页；`href="/"` 实际会回到**当前关卡**的首页（Vite 以该关卡目录为根）。它同时是一个普通 `<a>`，点击会整页刷新。

2. **History 模式的直接访问问题。**
   `createWebHistory()` 依赖服务器把所有路径回退到 `index.html`。开发服务器没问题，生产部署要配置 fallback，否则刷新 `/users/1` 会 404。

3. **`route.params` 是字符串。**
   `/users/1` 拿到的是 `"1"`，不是 `1`；第 3 关的 `UserDetail.vue` 用 `String(user.id) === route.params.id` 处理。

4. **同一路由记录内切换参数，组件会被复用。**
   `/users/1` → `/users/2` 不会重新创建组件，`onMounted` 不会再次执行；要跟着参数变化就用 `computed` / `watch`（第 3 关用计数器演示了这一点）。

5. **通配路由必须放最后。**
   否则它会抢先匹配所有地址，前面所有页面都变成 404。

6. **守卫只在「跳转时」执行。**
   第 7 关退出登录后仍停留在 `/admin`，需要主动 `router.push('/')`。

7. **懒加载的 `import()` 路径必须静态可分析。**
   `() => import('./pages/Report.vue')` 可以拆包；拼字符串的动态路径不行。
