# 条件渲染与列表渲染

> `v-if` / `v-show` 决定某块内容是否显示，`v-for` 负责把数组或对象渲染成一组元素，两者共同构成页面最常见的动态结构。

## 一、核心概念

- **`v-if` 是真正的条件渲染**：条件为假时，元素及其子组件会被销毁；条件为真时重新创建。切换开销较大，但初始渲染可以省掉不需要的 DOM。
- **`v-show` 只切换 `display`**：元素始终留在 DOM 中，适合频繁显示/隐藏的场景，例如下拉菜单、折叠面板。
- **`v-else-if` / `v-else` 必须紧邻**：它们必须跟在前一个 `v-if` 或 `v-else-if` 元素后面，中间不能插入其他元素。
- **`<template v-if>`**：在不想额外包裹一层 DOM 时，可以把多个元素放进 `<template>`，它只承载指令，不参与最终渲染。
- **`v-for` 的遍历对象**：数组、对象、数字、字符串都可以遍历。数组最常用，遍历对象时第二个参数是键名，第三个参数是索引。
- **`key` 是列表的身份标识**：Vue 依靠 `key` 判断哪些节点可以复用。用稳定且唯一的业务 id，不要用数组索引。

## 二、基础语法

```vue
<script setup>
import { ref } from 'vue'

const score = ref(86)
const visible = ref(true)
const todos = ref([
  { id: 1, title: '写周报', done: true },
  { id: 2, title: '评审接口', done: false }
])
const profile = ref({ name: '林晓', city: '杭州' })
</script>

<template>
  <!-- 条件链 -->
  <p v-if="score >= 90">优秀</p>
  <p v-else-if="score >= 60">及格</p>
  <p v-else>不及格</p>

  <!-- 频繁切换用 v-show -->
  <div v-show="visible">这块内容会一直保留在 DOM 中</div>

  <!-- 多个元素共享条件 -->
  <template v-if="visible">
    <h2>账户信息</h2>
    <p>手机号已绑定</p>
  </template>

  <!-- 数组列表，key 使用业务 id -->
  <ul>
    <li v-for="todo in todos" :key="todo.id">
      {{ todo.title }} - {{ todo.done ? '已完成' : '进行中' }}
    </li>
  </ul>

  <!-- 对象遍历：value、key、index -->
  <p v-for="(value, key, index) in profile" :key="key">
    {{ index }}. {{ key }}：{{ value }}
  </p>

  <!-- 数字范围，从 1 开始 -->
  <span v-for="n in 5" :key="n">{{ n }}</span>
</template>
```

## 三、完整示例

下面是一个任务看板列表，包含状态筛选、空状态、批量完成和删除，覆盖条件渲染与列表渲染的常见组合：

```vue
<script setup>
import { computed, ref } from 'vue'

const filter = ref('all')

const tasks = ref([
  { id: 101, title: '完成登录页联调', priority: 'high', done: false },
  { id: 102, title: '补充订单接口文档', priority: 'medium', done: true },
  { id: 103, title: '修复移动端表格错位', priority: 'high', done: false },
  { id: 104, title: '整理本周发布清单', priority: 'low', done: true }
])

// 根据筛选条件派生列表，不直接修改原数组
const visibleTasks = computed(() => {
  if (filter.value === 'active') {
    return tasks.value.filter((task) => !task.done)
  }
  if (filter.value === 'done') {
    return tasks.value.filter((task) => task.done)
  }
  return tasks.value
})

const remaining = computed(() => {
  return tasks.value.filter((task) => !task.done).length
})

const priorityText = {
  high: '高',
  medium: '中',
  low: '低'
}

function toggleTask(id) {
  const task = tasks.value.find((item) => item.id === id)
  if (task) task.done = !task.done
}

function removeTask(id) {
  tasks.value = tasks.value.filter((item) => item.id !== id)
}

function finishAll() {
  tasks.value.forEach((task) => {
    task.done = true
  })
}
</script>

<template>
  <section class="task-board">
    <header>
      <div>
        <h1>本周任务</h1>
        <p>剩余 {{ remaining }} 项未完成</p>
      </div>
      <button type="button" :disabled="remaining === 0" @click="finishAll">
        全部完成
      </button>
    </header>

    <div class="filters">
      <button
        v-for="item in [
          { value: 'all', label: '全部' },
          { value: 'active', label: '进行中' },
          { value: 'done', label: '已完成' }
        ]"
        :key="item.value"
        type="button"
        :class="{ active: filter === item.value }"
        @click="filter = item.value"
      >
        {{ item.label }}
      </button>
    </div>

    <ul v-if="visibleTasks.length > 0" class="task-list">
      <li
        v-for="task in visibleTasks"
        :key="task.id"
        :class="{ done: task.done }"
      >
        <label>
          <input
            type="checkbox"
            :checked="task.done"
            @change="toggleTask(task.id)"
          />
          <span class="title">{{ task.title }}</span>
        </label>

        <span class="priority" :class="`priority-${task.priority}`">
          {{ priorityText[task.priority] }}优先级
        </span>

        <button type="button" class="remove" @click="removeTask(task.id)">
          删除
        </button>
      </li>
    </ul>

    <div v-else class="empty">
      <p>当前筛选条件下没有任务</p>
      <button type="button" @click="filter = 'all'">查看全部任务</button>
    </div>
  </section>
</template>
```

## 四、常见坑 / 注意事项

1. **`v-if` 和 `v-for` 不要写在同一元素上**：Vue 3 中 `v-if` 的优先级高于 `v-for`，此时 `v-if` 访问不到循环变量。应先用 `computed` 过滤数据，再对结果做 `v-for`。
2. **`key` 不要使用数组索引**：在列表头部插入或删除元素时，索引会变化，Vue 可能复用错误的 DOM，导致输入框内容错位。
3. **不要用 `v-if` 和 `v-show` 互相替代**：频繁切换的弹窗适合 `v-show`；权限控制、需要销毁组件状态的场景适合 `v-if`。
4. **`v-else` 前不能有其他兄弟元素**：注释、空白文本通常没问题，但插入一个真实的 `<div>` 会导致 `v-else` 找不到对应的 `v-if`。
5. **直接给数组重新赋值可以触发更新**：`tasks.value = tasks.value.filter(...)` 是响应式的；但 `tasks.value[index] = newItem` 在 Vue 3 中也可以触发，前提是数组本身是响应式代理。
6. **遍历对象时 `key` 用键名**：对象的键是稳定标识，比索引更可靠。
7. **空状态要单独处理**：列表为空时 `v-for` 不会渲染任何内容，应提供 `v-else` 空状态，避免页面看起来像加载失败。

## 六、速查表

| 语法              | 作用             | 示例                                       |
| ----------------- | ---------------- | ------------------------------------------ |
| `v-if`            | 条件为真时渲染   | `<p v-if="ok">内容</p>`                    |
| `v-else-if`       | 多条件分支       | `<p v-else-if="score > 60">及格</p>`       |
| `v-show`          | 切换 `display`   | `<div v-show="open">面板</div>`            |
| `v-for`           | 遍历数组或对象   | `<li v-for="item in list" :key="item.id">` |
| `<template v-if>` | 多个元素共享条件 | `<template v-if="ok"><h2/><p/></template>` |
