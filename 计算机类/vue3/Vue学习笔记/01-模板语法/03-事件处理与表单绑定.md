# 事件处理与表单绑定

> `v-on` 负责监听用户操作，`v-model` 负责把表单控件的值同步到组件状态，两者是交互页面的基础。

## 一、核心概念

- **内联处理器与方法处理器**：`@click="count++"` 是内联语句；`@click="submit"` 把方法引用交给 Vue，由 Vue 在事件触发时调用。
- **事件对象**：不写参数时，处理器会自动收到原生事件对象；需要同时传参时，用 `$event` 显式传入。
- **事件修饰符**：`.stop` 阻止冒泡，`.prevent` 阻止默认行为，`.self` 只响应元素自身，`.once` 只触发一次，`.capture` 使用捕获阶段，`.passive` 提升滚动性能。
- **按键修饰符**：`.enter`、`.esc`、`.tab`、`.delete`、`.space`、`.up`、`.down` 等用于键盘事件，也可以写 `.exact` 精确匹配组合键。
- **`v-model` 双向绑定**：本质是 `:value` 加 `@input` 的语法糖。Vue 会根据控件类型选择正确的属性和事件。
- **`v-model` 修饰符**：`.lazy` 改为 `change` 后同步，`.number` 自动转数字，`.trim` 去掉首尾空格。

## 二、基础语法

```vue
<script setup>
import { ref } from 'vue'

const keyword = ref('')
const agree = ref(false)
const city = ref('')
const tags = ref([])
const age = ref(18)

function submit() {
  console.log({ keyword: keyword.value, agree: agree.value })
}

function onEnter(event) {
  console.log('按下回车', event.key)
}
</script>

<template>
  <!-- 方法处理器 -->
  <button @click="submit">提交</button>

  <!-- 内联处理器，$event 是原生事件对象 -->
  <button @click="(event) => console.log(event.clientX)">坐标</button>

  <!-- 事件修饰符 -->
  <form @submit.prevent="submit">
    <input v-model.trim="keyword" @keyup.enter="onEnter" />
  </form>

  <!-- 复选框绑定布尔值 -->
  <label><input v-model="agree" type="checkbox" /> 同意协议</label>

  <!-- 多选框绑定数组 -->
  <label><input v-model="tags" type="checkbox" value="vue" /> Vue</label>
  <label><input v-model="tags" type="checkbox" value="react" /> React</label>

  <!-- 下拉选择 -->
  <select v-model="city">
    <option value="">请选择城市</option>
    <option value="hangzhou">杭州</option>
    <option value="shanghai">上海</option>
  </select>

  <!-- number 修饰符把输入转为数字 -->
  <input v-model.number="age" type="number" />
</template>
```

## 三、完整示例

下面是一个登录表单，包含表单校验、密码可见切换、提交状态和键盘事件，接近真实业务页面：

```vue
<script setup>
import { computed, ref } from 'vue'

const form = ref({
  account: '',
  password: '',
  remember: true
})

const showPassword = ref(false)
const submitting = ref(false)
const errorMessage = ref('')

// 简单校验：实际项目可替换为 VeeValidate 或后端校验
const canSubmit = computed(() => {
  return form.value.account.trim().length >= 3 && form.value.password.length >= 6
})

async function handleSubmit() {
  if (!canSubmit.value || submitting.value) return

  errorMessage.value = ''
  submitting.value = true

  try {
    // 用延时模拟登录接口，真实项目替换为 fetch 或 axios
    await new Promise((resolve) => setTimeout(resolve, 800))

    if (form.value.password === '123456') {
      errorMessage.value = '密码过于简单，请修改后重试'
      return
    }

    console.log('登录成功', {
      account: form.value.account,
      remember: form.value.remember
    })
  } catch (error) {
    errorMessage.value = '网络异常，请稍后重试'
  } finally {
    submitting.value = false
  }
}

function resetForm() {
  form.value.account = ''
  form.value.password = ''
  errorMessage.value = ''
}
</script>

<template>
  <section class="login-card">
    <header>
      <h1>账号登录</h1>
      <p>使用企业邮箱或手机号登录工作台</p>
    </header>

    <form @submit.prevent="handleSubmit">
      <label class="field">
        <span>账号</span>
        <input
          v-model.trim="form.account"
          type="text"
          autocomplete="username"
          placeholder="请输入邮箱或手机号"
          @keyup.enter="handleSubmit"
        />
      </label>

      <label class="field">
        <span>密码</span>
        <div class="password">
          <input
            v-model="form.password"
            :type="showPassword ? 'text' : 'password'"
            autocomplete="current-password"
            placeholder="至少 6 位"
          />
          <button
            type="button"
            class="toggle"
            @click="showPassword = !showPassword"
          >
            {{ showPassword ? '隐藏' : '显示' }}
          </button>
        </div>
      </label>

      <label class="remember">
        <input v-model="form.remember" type="checkbox" />
        <span>7 天内自动登录</span>
      </label>

      <p v-if="errorMessage" class="error">{{ errorMessage }}</p>

      <button class="submit" type="submit" :disabled="!canSubmit || submitting">
        {{ submitting ? '登录中...' : '登录' }}
      </button>

      <button class="reset" type="button" @click="resetForm">重置</button>
    </form>
  </section>
</template>
```

## 四、常见坑 / 注意事项

1. **`@click="handler()"` 会在渲染时立即执行**：如果 `handler` 返回函数，这种写法可能把返回值当作处理器；需要传参时用 `@click="handler(arg)"` 或 `@click="() => handler(arg)"`。
2. **`.prevent` 要加在表单的 `submit` 上**：只给按钮加 `.prevent` 不一定能阻止表单默认提交，尤其是用户按回车时。
3. **`v-model` 不能直接绑定 `props`**：子组件不能修改父组件传入的值，应使用 `defineModel` 或 `emit('update:xxx')`。
4. **复选框的 `value` 决定数组内容**：`v-model` 绑定数组时，选中项会把 `value` 推入数组；不写 `value` 则推入 `true`，容易得到 `[true, true]`。
5. **`.number` 不是万能的**：输入为空或无法转换时，值可能是空字符串；后端仍需要做类型校验。
6. **`.lazy` 只在 `change` 时同步**：输入过程中数据不会实时更新，适合搜索框、地址等不需要逐字响应的字段。
7. **事件名在模板中建议用 kebab-case**：子组件 `emit('update-user')`，父组件用 `@update-user` 监听；HTML 属性不区分大小写，驼峰事件名容易被误写。
8. **不要在事件处理器里忘记 `await`**：异步提交按钮应设置 `submitting` 状态，否则用户连续点击会发起多次请求。

## 六、速查表

| 语法              | 作用             | 示例                                         |
| ----------------- | ---------------- | -------------------------------------------- |
| `@click="fn"`     | 绑定点击事件     | `@click="submit"`                            |
| `@submit.prevent` | 阻止表单默认提交 | `<form @submit.prevent="save">`              |
| `@keyup.enter`    | 回车时触发       | `<input @keyup.enter="search">`              |
| `v-model`         | 双向绑定表单值   | `<input v-model="form.name">`                |
| `v-model.number`  | 自动转数字       | `<input v-model.number="age" type="number">` |
