# 模板插值与指令

> 模板语法负责把组件状态安全、直观地渲染到页面上，核心是“插值表达式”和“以 `v-` 开头的指令”。

## 一、核心概念

- **文本插值**：`{{ }}` 会把 JavaScript 表达式的值转换成字符串插入 DOM，表达式的结果变化时，插值位置会自动更新。
- **表达式而非语句**：插值里可以写三元表达式、函数调用、属性访问，但不能写 `if`、`for`、变量声明等语句。
- **指令**：`v-bind`、`v-on`、`v-if`、`v-for` 等特殊属性由 Vue 编译处理。指令的值是 JavaScript 表达式，不是普通字符串。
- **动态参数**：`v-bind:[attrName]`、`v-on:[eventName]` 允许属性名或事件名来自响应式数据，适合做通用组件。
- **缩写**：`v-bind:src` 可写成 `:src`，`v-on:click` 可写成 `@click`，实际项目几乎都使用缩写。
- **单向数据流**：模板只负责“读”状态。需要修改状态时，应通过事件调用方法，而不是在模板里直接给变量赋值。

## 二、基础语法

```vue
<script setup>
import { ref } from 'vue'

const userName = ref('林晓')
const avatar = ref('/images/avatar.png')
const isVip = ref(true)
const attrName = ref('title')
const eventName = ref('click')

function sayHello() {
  console.log('hello')
}
</script>

<template>
  <!-- 文本插值 -->
  <p>你好，{{ userName }}</p>

  <!-- 三元表达式 -->
  <span>{{ isVip ? '尊贵会员' : '普通用户' }}</span>

  <!-- v-bind 绑定普通属性，缩写为 : -->
  <img :src="avatar" :alt="userName" />

  <!-- 动态参数：最终绑定 title 属性 -->
  <div v-bind:[attrName]="userName"></div>

  <!-- v-on 绑定事件，缩写为 @ -->
  <button @click="sayHello">问好</button>

  <!-- 动态事件名 -->
  <button v-on:[eventName]="sayHello">动态事件</button>

  <!-- 一次性绑定多个属性 -->
  <a v-bind="{ href: '/profile', target: '_blank' }">个人主页</a>
</template>
```

## 三、完整示例

下面是一个订单确认卡片，展示插值、条件表达式、属性绑定、动态样式和事件处理的组合使用：

```vue
<script setup>
import { computed, ref } from 'vue'

const order = ref({
  id: 'SO20261109001',
  customer: '陈默',
  phone: '138****6621',
  address: '上海市浦东新区世纪大道 100 号',
  items: [
    { name: '机械键盘', price: 499, quantity: 1 },
    { name: '人体工学椅', price: 1299, quantity: 1 }
  ],
  status: 'pending'
})

const isUrgent = ref(true)
const note = ref('')

// 订单总价，模板中直接使用 total
const total = computed(() => {
  return order.value.items.reduce((sum, item) => {
    return sum + item.price * item.quantity
  }, 0)
})

// 状态文案通过普通对象映射，避免模板里堆叠三元表达式
const statusText = {
  pending: '待付款',
  paid: '已付款',
  shipped: '已发货',
  done: '已完成'
}

const statusClass = computed(() => `status-${order.value.status}`)

function confirmPay() {
  order.value.status = 'paid'
}

function copyOrderId() {
  navigator.clipboard?.writeText(order.value.id)
}
</script>

<template>
  <section class="order-card">
    <header>
      <div>
        <p class="label">订单号</p>
        <h2 @click="copyOrderId">{{ order.id }}</h2>
      </div>
      <span class="status" :class="statusClass">
        {{ statusText[order.status] }}
      </span>
    </header>

    <div class="customer">
      <p><strong>{{ order.customer }}</strong> {{ order.phone }}</p>
      <p class="address">{{ order.address }}</p>
    </div>

    <ul class="items">
      <li v-for="item in order.items" :key="item.name">
        <span>{{ item.name }} × {{ item.quantity }}</span>
        <span>¥{{ item.price * item.quantity }}</span>
      </li>
    </ul>

    <div class="summary">
      <p v-if="isUrgent" class="urgent">加急订单，预计 24 小时内送达</p>
      <p class="total">合计：<strong>¥{{ total }}</strong></p>
    </div>

    <label class="note">
      订单备注
      <input v-model="note" type="text" placeholder="选填，例如放门口" />
    </label>

    <button
      type="button"
      :disabled="order.status !== 'pending'"
      @click="confirmPay"
    >
      {{ order.status === 'pending' ? '确认支付' : '已支付' }}
    </button>
  </section>
</template>
```

## 四、常见坑 / 注意事项

1. **插值不能写在 HTML 属性里**：`<img src="{{ avatar }}">` 是错误写法，属性绑定必须用 `:src="avatar"`。
2. **插值表达式不要产生副作用**：不要在 `{{ list.push(item) }}` 里修改数据，模板会在每次渲染时执行，容易造成死循环或重复提交。
3. **`undefined` 和 `null` 不会显示**：插值结果为 `null`、`undefined` 时页面是空字符串，需要默认值时用 `??` 或 `||`。
4. **动态参数不能包含空格或引号**：`v-bind:['foo bar']` 是无效的，动态参数应是一个能求值为合法属性名的表达式。
5. **`v-html` 有 XSS 风险**：它渲染的是原始 HTML，绝不能把用户输入直接交给 `v-html`。
6. **模板编译有作用域限制**：模板只能访问组件顶层绑定和少量全局对象，不能直接访问 `window`、`Math` 之外的任意全局变量。
7. **`@click="handler()"` 与 `@click="handler"` 不同**：前者在渲染时立即调用，后者把函数作为事件处理器；需要传参时才写括号。

## 六、速查表

| 语法           | 作用           | 示例                        |
| -------------- | -------------- | --------------------------- |
| `{{ expr }}`   | 文本插值       | `{{ user.name }}`           |
| `:attr="expr"` | 绑定 HTML 属性 | `:src="avatar"`             |
| `v-bind="obj"` | 批量绑定属性   | `v-bind="{ id, title }"`    |
| `@event="fn"`  | 绑定事件       | `@click="submit"`           |
| `v-bind:[key]` | 动态属性名     | `v-bind:[attrName]="value"` |
