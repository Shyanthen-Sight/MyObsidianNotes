# 渲染优化与特殊指令

> Vue 默认已经足够快，但在静态内容多、列表巨大或需要跳过编译时，`v-once`、`v-memo`、`v-pre`、`v-cloak`、`v-text`、`v-html` 这些特殊指令可以减少不必要的开销。

## 一、核心概念

- **`v-once`**：只渲染一次，之后即使依赖的数据变化也不会更新。适合完全静态的版权信息、说明文字。
- **`v-memo`**：传入依赖数组，数组中的值不变时跳过该节点及其子树的更新。常配合 `v-for` 使用，但必须同时提供 `key`。
- **`v-pre`**：跳过元素及其子元素的模板编译，原样输出 `{{ }}`。适合展示 Vue 代码示例，或优化大量静态内容。
- **`v-cloak`**：在 Vue 实例挂载完成前隐藏元素，避免用户看到未编译的 `{{ }}`。使用构建工具时通常不需要。
- **`v-text`**：设置元素的 `textContent`，会覆盖原有内容，等价于插值但不会出现闪烁。
- **`v-html`**：设置元素的 `innerHTML`，可以渲染富文本，但必须确保内容可信，否则存在 XSS 风险。

## 二、基础语法

```vue
<script setup>
import { ref } from 'vue'

const copyright = '© 2026 示例科技'
const htmlContent = '<strong>加粗内容</strong>'
const items = ref([
  { id: 1, name: '商品 A', selected: false },
  { id: 2, name: '商品 B', selected: true }
])
const version = ref(1)
</script>

<template>
  <!-- 只渲染一次 -->
  <footer v-once>{{ copyright }}</footer>

  <!-- 跳过编译，原样显示模板语法 -->
  <pre v-pre>{{ message }}</pre>

  <!-- 未挂载前隐藏，需要配合 CSS -->
  <div v-cloak>{{ copyright }}</div>

  <!-- 设置文本内容 -->
  <p v-text="copyright"></p>

  <!-- 渲染可信 HTML -->
  <div v-html="htmlContent"></div>

  <!-- 依赖不变时跳过整行更新 -->
  <ul>
    <li
      v-for="item in items"
      :key="item.id"
      v-memo="[item.selected, version]"
    >
      {{ item.name }} - {{ item.selected ? '已选' : '未选' }}
    </li>
  </ul>
</template>

<style>
[v-cloak] {
  display: none;
}
</style>
```

## 三、完整示例

下面是一个商品对比列表：静态表头使用 `v-once`，大列表使用 `v-memo` 减少无关更新，富文本说明使用经过白名单处理的 `v-html`：

```vue
<script setup>
import { computed, ref } from 'vue'

const keyword = ref('')
const sortBy = ref('price')

const products = ref([
  { id: 1, name: '轻薄笔记本', price: 6299, stock: 12, tags: ['办公', '长续航'] },
  { id: 2, name: '电竞显示器', price: 1899, stock: 0, tags: ['高刷', '2K'] },
  { id: 3, name: '无线鼠标', price: 199, stock: 88, tags: ['静音', '蓝牙'] },
  { id: 4, name: '机械键盘', price: 499, stock: 35, tags: ['热插拔', 'RGB'] }
])

// 只有名称、价格、库存变化时才需要重新渲染对应行
const rows = computed(() => {
  const list = products.value.filter((item) => {
    return item.name.includes(keyword.value.trim())
  })

  return [...list].sort((a, b) => {
    if (sortBy.value === 'stock') return b.stock - a.stock
    return a.price - b.price
  })
})

// 模拟可信富文本，实际应由后端富文本编辑器生成并做 XSS 过滤
const description = computed(() => {
  if (!keyword.value) {
    return '<p>输入关键词筛选商品，支持<strong>名称模糊匹配</strong>。</p>'
  }
  return `<p>正在搜索：<em>${keyword.value}</em></p>`
})
</script>

<template>
  <section class="compare">
    <header>
      <h1>商品对比</h1>
      <input v-model="keyword" type="search" placeholder="搜索商品名称" />
    </header>

    <!-- 表头基本不变，只渲染一次 -->
    <div v-once class="table-head">
      <span>商品</span>
      <span>价格</span>
      <span>库存</span>
      <span>标签</span>
    </div>

    <div class="table-body">
      <div
        v-for="product in rows"
        :key="product.id"
        v-memo="[product.price, product.stock, product.tags.length]"
        class="table-row"
      >
        <span class="name">{{ product.name }}</span>
        <span>¥{{ product.price }}</span>
        <span :class="{ out: product.stock === 0 }">
          {{ product.stock === 0 ? '缺货' : product.stock }}
        </span>
        <span class="tags">
          <em v-for="tag in product.tags" :key="tag">{{ tag }}</em>
        </span>
      </div>
    </div>

    <p v-if="rows.length === 0" class="empty">没有匹配的商品</p>

    <!-- 富文本必须来自可信来源 -->
    <div class="description" v-html="description"></div>

    <footer v-once>
      <small>© 2026 示例商城 · 价格与库存以结算页为准</small>
    </footer>
  </section>
</template>

<style scoped>
.compare {

  font-family: system-ui, sans-serif;
}

header {

}

}

  gap: 12px;

}

.table-head {
  border-radius: 8px;
  background: #f3f4f6;
  color: #4b5563;
  font-size: 13px;
}

.table-row {
  border-bottom: 1px solid #f1f5f9;
  font-size: 14px;
}

.name {
  font-weight: 600;
}

.out {
  color: #dc2626;
}

.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 6px;
}

.tags em {
  padding: 2px 7px;
  border-radius: 999px;
  background: #ecfdf5;

  font-size: 12px;
  font-style: normal;
}

  color: #9ca3af;
```

## 四、常见坑 / 注意事项

1. **`v-once` 之后数据变化不会更新**：如果区块里包含用户相关数据，不要使用 `v-once`，否则切换用户后仍显示旧内容。
2. **`v-memo` 必须与 `v-for` 的 `key` 配合**：在 `v-for` 中使用时，`key` 要写在同一个元素上，否则 Vue 会给出警告，优化也可能失效。
3. **`v-memo` 的依赖数组要包含所有会影响渲染的值**：漏掉 `product.stock` 这类字段，会导致库存变化后界面不更新。
4. **`v-pre` 会跳过整棵子树**：里面不能再使用任何 Vue 指令，适合纯静态代码示例，不适合需要交互的区域。
5. **`v-cloak` 必须配合 CSS**：只写指令不写 `[v-cloak] { display: none }` 没有任何效果；使用 Vite 构建时模板已被编译，一般不需要它。
6. **`v-html` 不会编译 Vue 模板**：插入的 `{{ }}` 不会被解析，插入的 `<MyComponent>` 也不会变成组件。
7. **`v-html` 是 XSS 高风险入口**：用户昵称、评论、富文本都必须经过后端或 DOMPurify 等库过滤，不能直接拼接后渲染。
8. **不要为了优化而滥用 `v-memo`**：依赖数组比较本身有成本，小列表直接渲染通常更快，应先测量再优化。

## 六、速查表

| 语法      | 作用               | 示例                                                 |
| --------- | ------------------ | ---------------------------------------------------- |
| `v-once`  | 只渲染一次         | `<footer v-once>{{ year }}</footer>`                 |
| `v-memo`  | 依赖不变时跳过更新 | `<li v-for="i in list" :key="i.id" v-memo="[i.on]">` |
| `v-pre`   | 跳过模板编译       | `<pre v-pre>{{ raw }}</pre>`                         |
| `v-cloak` | 挂载前隐藏         | `<div v-cloak>{{ msg }}</div>`                       |
| `v-text`  | 设置文本内容       | `<p v-text="msg"></p>`                               |
