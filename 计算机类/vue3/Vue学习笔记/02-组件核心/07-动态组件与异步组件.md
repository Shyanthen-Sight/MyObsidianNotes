# 动态组件与异步组件

> 动态组件用 `<component :is>` 在同一个位置切换不同组件；异步组件把不急着用的代码拆成独立分包，按需加载，从而降低首屏体积。

## 一、核心概念

- **`<component :is>`**：根据表达式的值渲染不同组件。值可以是组件对象、全局注册的组件名字符串，或 `defineAsyncComponent` 返回的异步组件。
- **`<KeepAlive>`**：缓存动态切换的组件实例，避免反复销毁和重建。常与动态组件、路由组件一起使用。
- **缓存范围**：`include` / `exclude` 按组件名匹配，`max` 限制最多缓存多少个实例，超出后按 LRU 淘汰。
- **异步组件**：`defineAsyncComponent(() => import('./Chart.vue'))` 返回一个包装组件，首次渲染时才加载真实代码。
- **加载与错误状态**：异步组件支持 `loadingComponent`、`errorComponent`、`delay`、`timeout`，避免用户看到空白。
- **`<Suspense>`**：为异步依赖提供统一的等待状态和 `fallback` 内容，目前仍是实验性特性，生产项目要评估稳定性。

## 二、基础语法

动态组件：

```vue
<script setup>
import { ref } from 'vue'
import ProfileTab from './ProfileTab.vue'
import SecurityTab from './SecurityTab.vue'

const current = ref(ProfileTab)
</script>

<template>
  <button @click="current = ProfileTab">资料</button>
  <button @click="current = SecurityTab">安全</button>

  <KeepAlive>
    <component :is="current" />
  </KeepAlive>
</template>
```

异步组件：

```vue
<script setup>
import { defineAsyncComponent } from 'vue'

const RevenueChart = defineAsyncComponent({
  loader: () => import('./RevenueChart.vue'),
  loadingComponent: () => import('./ChartSkeleton.vue'),
  errorComponent: () => import('./ChartError.vue'),
  delay: 200,
  timeout: 5000
})
</script>

<template>
  <RevenueChart />
</template>
```

带 Suspense 的异步组件：

```vue
<template>
  <Suspense>
    <template #default>
      <AsyncOrderList />
    </template>
    <template #fallback>
      <p>订单加载中...</p>
    </template>
  </Suspense>
</template>
```

## 三、完整示例

下面是一个数据看板，使用动态组件切换“概览 / 订单 / 设置”，用 KeepAlive 保留各标签页状态，并异步加载体积较大的图表组件：

```vue
<script setup>
import { computed, defineAsyncComponent, ref } from 'vue'
import OverviewPanel from './panels/OverviewPanel.vue'
import OrdersPanel from './panels/OrdersPanel.vue'
import SettingsPanel from './panels/SettingsPanel.vue'

// 图表库体积较大，拆成异步组件，首屏不加载
const RevenueChart = defineAsyncComponent({
  loader: () => import('./panels/RevenueChart.vue'),
  loadingComponent: () => import('./panels/ChartSkeleton.vue'),
  errorComponent: () => import('./panels/ChartError.vue'),
  delay: 200,
  timeout: 8000
})

const tabs = [
  { key: 'overview', label: '概览', component: OverviewPanel },
  { key: 'orders', label: '订单', component: OrdersPanel },
  { key: 'settings', label: '设置', component: SettingsPanel }
]

const activeKey = ref('overview')

const activeComponent = computed(() => {
  return tabs.find((tab) => tab.key === activeKey.value)?.component
})

// 只缓存概览和订单，设置页每次都重新创建
const cachedTabs = ['OverviewPanel', 'OrdersPanel']

const showChart = ref(false)
</script>

<template>
  <section class="dashboard">
    <nav class="tabs">
      <button
        v-for="tab in tabs"
        :key="tab.key"
        type="button"
        :class="{ active: activeKey === tab.key }"
        @click="activeKey = tab.key"
      >
        {{ tab.label }}
      </button>
    </nav>

    <!-- KeepAlive 只缓存指定组件，max 控制缓存上限 -->
    <KeepAlive :include="cachedTabs" :max="5">
      <component :is="activeComponent" />
    </KeepAlive>

    <section class="chart-section">
      <button type="button" @click="showChart = !showChart">
        {{ showChart ? '收起趋势图' : '查看营收趋势' }}
      </button>

      <!-- 首次点击才加载异步组件 -->
      <Suspense v-if="showChart">
        <template #default>
          <RevenueChart :year="2026" />
        </template>
        <template #fallback>
          <div class="chart-loading">图表加载中...</div>
        </template>
      </Suspense>
    </section>
  </section>
</template>

<style scoped>
.dashboard {
  max-width: 860px;
  margin: 32px auto;
  padding: 24px;
  font-family: system-ui, sans-serif;
}

.tabs {
  display: flex;
  gap: 8px;
  border-bottom: 1px solid #e5e7eb;
}

.tabs button {
  padding: 10px 16px;
  border: 0;
  border-bottom: 2px solid transparent;
  background: transparent;
  color: #6b7280;
  cursor: pointer;
}

.tabs button.active {
  border-bottom-color: #111827;
  color: #111827;
  font-weight: 600;
}

.chart-section {
  margin-top: 24px;
}

.chart-section > button {
  padding: 9px 16px;
  border: 1px solid #d1d5db;
  border-radius: 8px;
  background: #ffffff;
  cursor: pointer;
}

.chart-loading {
  display: grid;
  height: 220px;
  margin-top: 16px;
  place-items: center;
  border-radius: 12px;
  background: #f9fafb;
  color: #9ca3af;
}
</style>
```

被缓存的标签页可以利用激活钩子暂停和恢复轮询：

```vue
<!-- panels/OrdersPanel.vue -->
<script setup>
import { onActivated, onDeactivated, ref } from 'vue'

const orders = ref([])
let timer = null

function refresh() {
  // 实际项目替换为接口请求
  orders.value = [{ id: 1, title: '订单 A' }]
}

onActivated(() => {
  refresh()
  timer = window.setInterval(refresh, 10000)
})

onDeactivated(() => {
  if (timer) window.clearInterval(timer)
  timer = null
})
</script>
```

## 四、常见坑 / 注意事项

1. **`<KeepAlive>` 只能有一个直接子组件**：`<KeepAlive>` 内部放多个并列组件时只缓存第一个，切换逻辑应交给 `<component :is>`。
2. **`include` / `exclude` 匹配的是组件名**：`<script setup>` 组件默认根据文件名推断名称；文件名与 `include` 不一致时缓存不会生效，可用 `defineOptions({ name: 'OverviewPanel' })` 显式命名。
3. **`<component :is>` 传字符串需要组件已全局注册**：传局部导入的组件对象更可靠；传字符串时找不到组件会渲染成原生未知标签。
4. **不要把异步组件定义写在渲染函数或模板里**：每次渲染都会创建新的异步组件包装器，导致重复加载和状态丢失，应在模块顶层定义一次。
5. **异步组件的 `loadingComponent` 在 `delay` 之后才显示**：`delay` 默认 200ms，加载很快时不会闪烁；`timeout` 超时后显示错误组件。
6. **`<Suspense>` 仍是实验性 API**：未来可能调整，生产项目应关注官方更新，并准备好错误边界和降级方案。
7. **KeepAlive 缓存的组件不会触发 `onUnmounted`**：清理逻辑要放在 `onDeactivated`，否则定时器会在后台继续运行。
8. **异步组件加载失败要有兜底**：网络异常、分包 404 都可能发生，`errorComponent` 或 `onError` 应提供重试入口。

## 六、速查表

| 语法                       | 作用           | 示例                                                |
| -------------------------- | -------------- | --------------------------------------------------- |
| `<component :is="Comp" />` | 动态渲染组件   | `<component :is="current" />`                       |
| `<KeepAlive>`              | 缓存组件实例   | `<KeepAlive><component :is="tab" /></KeepAlive>`    |
| `include`                  | 只缓存指定组件 | `<KeepAlive include="A,B">`                         |
| `defineAsyncComponent`     | 异步加载组件   | `defineAsyncComponent(() => import('./Chart.vue'))` |
| `loadingComponent`         | 加载中占位     | `loadingComponent: ChartSkeleton`                   |
