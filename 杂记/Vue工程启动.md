	![[Pasted image 20261104214136.png|393]]

2. 打开新建的文件夹，在文件下的地址栏输入cmd，并且回车，后显示命令窗口

	![[Pasted image 20261104215441.png]]

	接下来的步骤我们**全部回车**直到显示如下界面，然后我们**关闭命令行窗口**，这样我们的工程文件就创建好了，需要的**Router（路由）也安装好了**

# 三.启动Vue工程项目并运行

1. 把新建文件夹里面的vue-project文件**拖出到桌面**，然后用再把vue-project文件直接拖入VSCode的桌面图标上，打开文件夹
	
	![[Pasted image 20261104220437.png]]

2.	我们打开vscode的终端，在终端数值指令**npm install**来安装项目所需依赖文件，回车，等待结束即可
	![[Pasted image 20261104221033.png]]

3. 依赖下载完毕后，我们开始启动项目，在终端输入指令**npm run dev**，然后回车。等加载完毕后，我们会注意到有一个链接，我们**按住ctrl不放手**，鼠标移动到该链接上，然后**鼠标左键点**击这个链接启动项目
	![[Pasted image 20261104221320.png]]

4. 随后我们会看到这个页面，这样项目启动成功了！！
	![[Pasted image 20261104221639.png]]
