# 封装函数实现简易计算器：一个 `type` 参数分出四种运算

> [!info] 原题
> 蓝桥云课 · 封装函数实现简易计算器（题目 1454）
> 2021 蓝桥云课「Web 前端挑战赛」· 楼赛第 27 期
> [题目链接](https://www.lanqiao.cn/problems/1454/learning/?page=1&first_category_id=2&tags=JavaScript,%E5%BC%82%E6%AD%A5&tag_relation=union)
>
> 备注：题目页需登录才能看全，本题面依据题目截图与公开题解整理。

> [!summary] 速记版
> ```js
> function cal(num1, num2, type) {
>   switch (type) {
>     case 0: return num1 + num2;   // 加
>     case 1: return num1 - num2;   // 减
>     case 2: return num1 * num2;   // 乘
>     case 3: return num1 / num2;   // 除
>   }
> }
> ```
> - **函数只做一件事**：`type` 为 0/1/2/3，分别对应 `+ - * /`，算完 `return`。
> - **页面只做三件事**：取两个输入框的值 → 转成数字 → 取 `<select>` 的值当 `type`，调用 `cal`，把返回值写进结果元素。
> - 题面写明「暂不考虑浮点数」，所以不用处理小数精度；除零、非数字也属于题面之外的边界。
> - `input.value` 永远是**字符串**，直接 `+` 会拼接（`"5" + "2" = "52"`），必须先 `Number()` 转换。
> - `select.value` 同样是字符串 `"0"`：`switch` 前要转数字，或者用 `==` 比较；用 `===` 会一个分支都进不去。

## 考察内容

- **函数封装**：把「根据运算符选择算法」收进一个函数，输入参数、输出结果，不碰页面。
- **多分支分派**：`if…else` / `switch` / 对象映射表三种写法的取舍。
- **参数编码约定**：`type` 是数字枚举（0–3），不是运算符字符，需要按约定映射。
- **DOM 取值**：`input.value`、`select.value` 的读取方式与字符串本质。
- **显式类型转换**：`Number()` / `parseInt()`，以及 `+` 的双重语义（加法 vs 字符串拼接）。
- **DOM 渲染**：把函数返回值写回页面（`textContent` 优于 `innerHTML`）。
- **事件绑定**：点击「计算」按钮触发整套流程。

## 一、题目要求

题面原文（截图）：

> 基于挑战提供的基础代码，完善计算器结构，实现当用户在文本框中输入两个操作数（暂不考虑浮点数）和选择运算符后，单击计算按钮后，即可将运算的结果显示到页面中。
>
> 例如，输入数字 5 和数字 2，选择加法运算后，页面效果如下：

页面效果：

```
┌─────────────────────────────┐
│  计算器                      │
│                             │
│  [ 5 ]  [+ ▼]  [ 2 ]  [计算] │
│                             │
│  7                          │
└─────────────────────────────┘
```

把这段话拆成可验收的点：

| 验收点 | 具体要求 |
| --- | --- |
| 两个操作数 | 两个文本框，分别输入 `num1`、`num2` |
| 运算符 | 一个下拉框，选项为加、减、乘、除 |
| 触发方式 | 单击「计算」按钮 |
| 计算逻辑 | 按所选运算符对两个操作数做四则运算 |
| 结果显示 | 把结果渲染到页面上（截图里显示在按钮下方） |
| 数据范围 | 暂不考虑浮点数（输入按整数处理，不要求精度处理） |

## 二、基础代码给了什么

官方给的是「页面骨架 + 一个待补全的 `cal` 函数」。公开题解里出现的函数签名是：

```js
function cal(num1, num2, type) {
  // TODO: 在此处补充代码
}
```

也就是说，**这题真正要写的只有函数体**：页面元素、事件绑定、取值和渲染都已经在基础代码里搭好了。

按题面截图还原，页面结构大致是：

```html
<h2>计算器</h2>

<input id="num1" type="text" />
<select id="operator">
  <option value="0">+</option>
  <option value="1">-</option>
  <option value="2">×</option>
  <option value="3">÷</option>
</select>
<input id="num2" type="text" />

<button id="calcBtn">计算</button>

<div id="result"></div>
```

> [!note] 结构是示意
> 实际基础代码里的 `id`、标签顺序可能不同，以题目给的为准；但核心入参一定是 `num1`、`num2`、`type` 三样，`type` 的编码是 0=加、1=减、2=乘、3=除。

## 三、解法拆解

### 1. 函数层：只负责「算」

`cal` 是纯函数，输入两个数和一个类型，输出一个数。它不需要知道 DOM 长什么样：

```js
function cal(num1, num2, type) {
  switch (type) {
    case 0: return num1 + num2;
    case 1: return num1 - num2;
    case 2: return num1 * num2;
    case 3: return num1 / num2;
  }
}
```

这里用 `switch` 比 `if…else` 更贴合「枚举值分派」的语义；如果类型很多，还可以改成映射表（见第五节）。

### 2. 页面层：取值 → 转换 → 调用 → 渲染

```js
const num1El  = document.getElementById('num1');
const num2El  = document.getElementById('num2');
const opEl    = document.getElementById('operator');
const resultEl = document.getElementById('result');

document.getElementById('calcBtn').onclick = function () {
  const num1 = Number(num1El.value);   // "5"  -> 5
  const num2 = Number(num2El.value);   // "2"  -> 2
  const type = Number(opEl.value);     // "0"  -> 0

  resultEl.textContent = cal(num1, num2, type);  // 把返回值写到页面
};
```

四步可以记成一条链：

```
输入框/下拉框  →  Number()  →  cal(num1, num2, type)  →  textContent
   字符串          数字              纯计算                字符串
```

### 3. `type` 到底从哪来

两种常见的基础代码写法，处理方式不同：

| 基础代码写法 | `type` 的取值 | 注意事项 |
| --- | --- | --- |
| `<option value="0">+</option>` | `select.value` 是字符串 `"0"` | `Number()` 后传参，或用 `==` 比较 |
| 用 `select.selectedIndex` | 数字下标，天然是 `0–3` | 前提是选项顺序恰好是加、减、乘、除 |

如果基础代码直接以运算符字符为 `value`（`+`、`-`、`*`、`/`），那 `cal` 的第三个参数就应按字符分支，不要生搬 0–3。**先看基础代码，再决定编码**。

## 五、三种分派写法对比

### 写法 A：`if…else`

```js
function cal(num1, num2, type) {
  if (type === 0) return num1 + num2;
  else if (type === 1) return num1 - num2;
  else if (type === 2) return num1 * num2;
  else if (type === 3) return num1 / num2;
}
```

最直白，但每条判断都要写一遍 `type`，分支多了会啰嗦。

### 写法 B：`switch`（推荐）

```js
function cal(num1, num2, type) {
  switch (type) {
    case 0: return num1 + num2;
    case 1: return num1 - num2;
    case 2: return num1 * num2;
    case 3: return num1 / num2;
  }
}
```

一次判定、多路分发，语义最清楚；每个 `case` 直接 `return`，不写 `break` 也不会穿透。

### 写法 C：映射表

```js
const operations = {
  0: (a, b) => a + b,
  1: (a, b) => a - b,
  2: (a, b) => a * b,
  3: (a, b) => a / b,
};

function cal(num1, num2, type) {
  return operations[type](num1, num2);
}
```

扩展性最好：加一种运算只需加一行表项，函数体不用动。缺点是初学者一眼看不出四个分支。如果基础代码的 `type` 是运算符字符，也可以直接拿字符当 key：

```js
const operations = {
  '+': (a, b) => a + b,
  '-': (a, b) => a - b,
  '*': (a, b) => a * b,
  '/': (a, b) => a / b,
};
```

> [!tip] 怎么选
> 考试里写 `switch` 最稳：行数可控、不依赖隐式转换、阅卷/评测都认。映射表适合在真实项目里用。

## 六、易错点

> [!warning] 这几个坑，题目越简单越容易踩

1. **字符串相加**
   `input.value` 是字符串，`"5" + "2"` 得到 `"52"` 而不是 `7`。两个操作数都要先 `Number()` / `parseInt()`。

2. **`num1 == NaN` 永远是 `false`**
   `NaN` 不等于任何值，包括它自己。网上有些题解写 `if (num1 == NaN || num2 == NaN) return`，这个判断永远不成立，等于没写。真要判空/判非数字，用：

   ```js
   if (Number.isNaN(num1) || Number.isNaN(num2)) return;
   // 或者：if (num1El.value === '' || num2El.value === '') return;
   ```

   不过本题「暂不考虑浮点数」，基础用例都会给合法整数，校验不是得分点。

3. **`select.value` 是字符串**
   `"0" === 0` 为 `false`。`switch` 的 `case 0` 用的是严格相等，所以传参前要 `Number()`；用 `==` 比较则 `"0" == 0` 成立。**别在同一个函数里混用两种约定。**

4. **`type` 的编码方向**
   先确认基础代码里 0 对应的是加还是别的运算。题目约定是 `0 加、1 减、2 乘、3 除`，不要凭直觉写。

5. **函数返回值 vs 页面渲染**
   `cal` 只 `return`，不负责显示；`resultEl.textContent = ...` 才是显示。只写一个都不算完成。

6. **除零**
   JS 里 `5 / 0` 得到 `Infinity`，不会报错。题面没有要求处理，但如果想更严谨，可以在 `type === 3 && num2 === 0` 时给出提示。

7. **浮点精度**
   `0.1 + 0.2` 得到 `0.30000000000000004`。题面明确「暂不考虑浮点数」，所以不用处理；知道这个限制即可。

8. **用 `innerHTML` 渲染结果**
   结果只是数字，`textContent` 足够且更安全；`innerHTML` 没必要，还会带来解析开销。

## 七、评测怎么过

- 只修改题目标注的 `TODO` 区域，别改函数名 `cal`、参数顺序和基础代码里的元素绑定。
- 结果直接写数字即可，不需要拼接 `5 + 2 = 7` 这种文案——除非题面明确要求。
- 注意「暂不考虑浮点数」：输入按整数给，除法结果照常输出（`5 / 2` 显示 `2.5`）。
- 手动把六种自测用例点一遍，确认加法不是字符串拼接。

## 八、一句话总结

> **`cal` 负责按 `type` 分派四则运算并 `return`；页面负责把字符串输入转成数字、调用 `cal`、把结果写回 DOM。** 剩下的都是类型转换的细节。
