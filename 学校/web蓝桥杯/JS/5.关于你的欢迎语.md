# 关于你的欢迎语：三段取值 + 一个模板字符串

> [!info] 原题
> 蓝桥云课 · 关于你的欢迎语（题目 1764）
> 2022 蓝桥杯 Web 前端 · 省模拟赛 · 代码改错（10 分）
> [题目链接](https://www.lanqiao.cn/problems/1764/learning/)
>
> 备注：题目页需登录才能看全，本题面依据公开题解与题目说明整理；初始代码以公开题解保留的骨架为准。

> [!summary] 速记版
> ```js
> function generate() {
>   const subject = document.getElementById("subject").value; // 用户
>   const event1  = document.getElementById("event1").value;  // 课程
>   const event2  = document.getElementById("event2").value;  // 平台
>   if (subject === "" || event1 === "" || event2 === "") return;
>
>   const result = `欢迎用户${subject}在${event2}学习${event1}课程！`;
>   document.getElementById("result").value = result;
> }
> ```
> - **三个 bug**：① 只拿到元素没取 `.value`；② 判空写成「三个全空才返回」；③ 拼接语序反了（应在**平台**学习**课程**）。
> - **一个考点**：用 ES6 模板字符串把三个变量插进固定话术。
> - 变量名 `event1` / `event2` 是陷阱：`event1` 是**课程**，`event2` 是**平台**，别按名字顺序想当然。
> - 判空先用 `||` 挡掉任意一个空值，再生成文案；`input.value` 永远是字符串。
> - 结果写回 `textarea` 用 `.value`，不是 `innerHTML`。

## 考察内容

- **DOM 取值**：`getElementById()` 拿到的是**元素对象**，输入内容在 `.value` 里。
- **ES6 模板字符串**：反引号 + `${}`，替代 `+` 拼接。
- **逻辑运算符**：`&&` 与 `||` 的短路语义，判空该用哪个。
- **表单交互**：点击「生成」按钮触发函数，把结果写回页面。
- **字符串插值顺序**：同一个句子，「在…学习…」两个空位对应哪两个变量。

## 二、原始代码里的三个 bug

`js/index.js` 的初始代码（据公开题解整理）：

```js
// js/index.js
function generate() {
    subject = document.getElementById("subject");   // ① 元素，不是值
    event1 = document.getElementById("event1");
    event2 = document.getElementById("event2");

    if (subject.length == 0 && event1.length == 0 && event2.length == 0) {
        return;                                     // ② 三个全空才返回
    }

    result = "欢迎用户" + subject + "在" + event1 + "学习" + event2 + "课程！";
    //                       ↑ 元素对象转字符串        ↑ 课程/平台语序反了
    document.getElementById("result").value = result;
}
```

| # | 现象 | 原因 | 修法 |
| --- | --- | --- | --- |
| ① | 文案里出现 `[object HTMLInputElement]` | `getElementById()` 返回 DOM 元素，直接参与字符串拼接会调用 `toString()` | 每个都补 `.value` |
| ② | 只填一个框也会生成残缺文案 | `&&` 要求三个**全为空**才 `return`，语义正好相反；且元素上的 `.length` 是 `undefined`，`undefined == 0` 为 `false`，判断根本不生效 | 先取值，再用 `\|\|`：任一为空就返回 |
| ③ | 平台和课程的位置互换，如「在 Python 学习蓝桥云课课程」 | `event1` 是**课程**、`event2` 是**平台**，但拼接时按变量序号写成了「在 event1 学习 event2」 | 句式为「在 `${event2}` 学习 `${event1}` 课程」 |

> [!warning] 顺序是本題唯一的「隐形坑」
> 页面里 `id="event1"` 对应**课程**，`id="event2"` 对应**平台**。中文句式是「在**平台**学习**课程**」，所以模板里 `event2` 在前、`event1` 在后。变量名和中文语序不一致，凭直觉写必错。

## 三、解法拆解

### 1. 取值：元素 → 值

```js
const subject = document.getElementById("subject").value;
const event1  = document.getElementById("event1").value;
const event2  = document.getElementById("event2").value;
```

`.value` 一定存在（`input` / `textarea` 都有），读出来是**字符串**。`id` 拼错时 `getElementById` 返回 `null`，再取 `.value` 会抛 `Cannot read properties of null` —— 这类报错先去核对 `id`。

### 2. 判空：任一为空就退出

```js
if (subject === "" || event1 === "" || event2 === "") {
    return;
}
```

`||` 的短路语义正好对应「三个都得填」：任何一项为空就中止。等价的简写：

```js
if (!subject || !event1 || !event2) return;   // 空字符串为假值
```

也可以保留 `.length` 的写法，但必须建立在**已经取到值**的前提上：

```js
if (subject.length === 0 || event1.length === 0 || event2.length === 0) return;
```

> [!warning] 别在元素上判 `.length`
> 元素没有 `length` 属性，`undefined == 0` 为 `false`，`undefined === 0` 也是 `false`。所以「先取元素、再判 `length`」这种写法无论用 `&&` 还是 `||` 都不会生效。

### 3. 拼接：模板字符串

```js
const result = `欢迎用户${subject}在${event2}学习${event1}课程！`;
```

固定话术 + 三个空位，模板字符串是最贴近题意的写法，也是本题标注的考点。

### 4. 渲染：写回 `textarea`

```js
document.getElementById("result").value = result;
```

`textarea` 的内容在 `.value` 里，`innerHTML` / `textContent` 虽然也能改，但 `.value` 才是表单控件的标准读写入口。

四步连成一条链：

```
三个 input  →  .value  →  判空(||)  →  模板字符串  →  textarea.value
   DOM 元素      字符串      守卫         插值            显示
```

## 五、几种等价写法

### 写法 A：模板字符串（推荐）

```js
const result = `欢迎用户${subject}在${event2}学习${event1}课程！`;
```

一眼能对上中文句式，变量边界清楚，是本题的标准答案。

### 写法 B：`+` 拼接

```js
const result = "欢迎用户" + subject + "在" + event2 + "学习" + event1 + "课程！";
```

同样正确，但引号和 `+` 一多就容易少空格、错顺序。考试里除非要求兼容老环境，否则用模板字符串。

### 写法 C：数组 `join`

```js
const result = ["欢迎用户", subject, "在", event2, "学习", event1, "课程！"].join("");
```

能跑，但可读性最差，不推荐。

### 判空的三种写法

| 写法 | 是否可行 | 说明 |
| --- | --- | --- |
| `subject === ""` | ✅ | 最明确，只挡空串 |
| `!subject` | ✅ | 空串、`null`、`undefined` 都挡，本题够用 |
| `subject.length === 0` | ✅（取值后） | 语义稍绕，且没挡 `null` |
| `subject.length == 0`（元素） | ❌ | `undefined == 0` 为 `false`，永不生效 |

## 六、易错点

> [!warning] 送分题之所以送分，是因为坑都在细节里

1. **忘记 `.value`**
   这是本题的主 bug。`document.getElementById("subject")` 拿到的是元素，拼进字符串会变成 `[object HTMLInputElement]`。

2. **`&&` 与 `||` 用反**
   「三个都得填」= 任一为空就退出 = `||`。「三个全空才退出」= `&&`，语义完全相反。判断条件读出来应该是「如果用户为空，**或者**课程为空，**或者**平台为空，就返回」。

3. **在元素上判 `.length`**
   `element.length` 是 `undefined`，`undefined == 0` 为 `false`。先取 `.value`，再判长度。

4. **平台 / 课程顺序颠倒**
   `event1` = 课程，`event2` = 平台；句式是「在**平台**学习**课程**」。提交前拿占位符默念一遍：`小蓝 / 蓝桥云课 / Python`。

5. **用 `innerHTML` 写 `textarea`**
   `textarea` 的显示内容是它的值，不是子节点。用 `.value` 赋值。

6. **改了不该改的文件**
   题面明确「切勿修改文件名、文件夹路径」。只动 `js/index.js` 里的 `generate`，别重命名、别删 Bootstrap。

7. **表单提交刷新页面**
   `form` 上已有 `action="javascript:void(0);"`，按钮也是 `submit` 类型。若自己重写页面，记得阻止默认提交，否则结果一闪而过。

8. **中英文标点**
   文案末尾是中文感叹号 `！`，`在`、`学习` 之间没有空格。判分若做字符串比对，多一个空格都会挂。

## 七、评测怎么过

- 只改 `js/index.js`，保持 `generate()` 的函数名和调用方式不变。
- 三个输入框都填上再点「生成」，`textarea` 里应出现完整的一句话。
- 手动测一遍空值：任意一个框留空，点「生成」不应产生 `欢迎用户在…` 这种残缺文案。
- 保持 Web Server 运行，再点「提交检测」——服务停了系统访问不到页面，会判失败。
- 本题通过率约 94%，属于「会取 `.value` 就过」的题，扣分基本都扣在语序和判空上。

## 八、一句话总结

> **三个 `.value` 取出字符串，`||` 挡住空值，再用模板字符串按「用户 / 平台 / 课程」的顺序拼成一句话写回 `textarea`。** 难点不在代码，在别把 `event1`、`event2` 的顺序写反。
