# 画一只考拉案例：Grid 六列四行把五官摆到位

> [!info] 原题
> 蓝桥云课 · 画一只考拉（题目 2341）· Web 前端「CSS3 页面布局」
> [题目链接](https://www.lanqiao.cn/problems/2341/learning/?page=1&first_category_id=2&tags=CSS3&tag_relation=union)

> [!summary] 速记版
> 初始文件只差这十来行声明，全部写在 `.face` 和它的子元素上：
> ```css
> .face {
>   display: grid;
>   grid-template-columns: 1fr 25px 25px 25px 25px 1fr; /* 6 列 */
>   grid-template-rows: 50px 1fr 1fr 50px;              /* 4 行 */
> }
>
> .eye { justify-self: center; align-self: center; }
> .eye.left    { grid-area: 2 / 2 / 3 / 3; }
> .eye.right   { grid-area: 2 / 5 / 3 / 6; }
> .nose        { grid-area: 3 / 2 / 4 / 6; }
> .blush.left  { grid-area: 2 / 1 / 3 / 2; justify-self: end;   align-self: end; }
> .blush.right { grid-area: 2 / 6 / 3 / 7; justify-self: start; align-self: end; }
> ```
> - 判分：**完全实现得满分，否则 0 分**，没有部分分。
> - 网格本身不画任何东西，它只是一张"坐标纸"，五官靠 `grid-area` 落格。
> - `grid-area` 的四个数字是**网格线编号**（从 1 开始、末线不含），不是格子序号。
> - 眼睛落第 2、5 列（中间四列的两端），鼻子横跨第 2~6 列线（正好 4 个 25px 列），腮红贴在第 1、6 列的右下角。

## 考察内容

- **CSS Grid 布局**：`display: grid`、`grid-template-columns`、`grid-template-rows`。
- **`fr` 单位**：剩余空间的份数，`1fr` 表示"分到一份"；本题两端各 1fr，中间固定 25px。
- **`grid-area` 四值语法**：`行始线 / 列始线 / 行终线 / 列终线`。
- **网格项对齐**：`justify-self`（列方向 / 主轴）与 `align-self`（行方向 / 交叉轴）。
- **Flex 与 Grid 混用**：外层 `.container`、`.ears`、`.ear` 用 Flex 排布，只有 `.face` 内部换 Grid。
- **层叠与 `z-index`**：`.face` 盖在 `.ears` 上；`.face` 是 flex item，所以不写 `position` 也能用 `z-index`。
- **相对定位微调**：`.ears` 用 `position: relative; top: 240px` 下移，让脸压住耳朵下半部分。
- **不能改结构**：文件名、路径、`class` 名都不能动，否则判分直接失败。

## 一、题目与初始代码

### 题目要求

> CSS3 的 Flex 弹性布局和 Grid 网格布局已经成为前端页面排版的主流选择。
> 本次挑战将使用这两种布局方式来画一只考拉。

请根据 `styles.css` 文件中的提示和要求添加所需的 CSS 代码，完整地画出考拉：

1. 创造一个网格布局，**6 个纵列**：前后两列两等分（可用 `fr` 代表一份），中间 4 列均为 `25px` 宽度；**4 个横行**：上下均为 `50px`，中间两等分。
2. **绘制眼睛**：长为 `30px`，高为 `30px`，颜色为 `#090b0e`，圆角为 `50%`，位置居中。
3. **绘制鼻子**：高为 `100%`，颜色为 `#3b464f`，上方圆角为 `50%`，下方圆角为 `40%`，按图示选取 `grid-area`。
4. **绘制腮红**：长为 `40px`，高为 `30px`，颜色为 `#f6b9bf`，圆角为 `50%`。

限制：

- 不要修改默认提供的文件名称、文件夹路径、函数名等。
- 保持 Web 服务可正常访问，再点「提交检测」自动判分。

## 三、6 × 4 网格怎么切

把 `.face`（430 × 380）想象成一张坐标纸：

```text
        列线1   列线2   列线3   列线4   列线5   列线6   列线7
          │      │       │       │       │       │       │
          │ 1fr  │ 25px  │ 25px  │ 25px  │ 25px  │ 1fr   │
        0px    165px   190px   215px   240px   265px   430px

行线1  0px   ┌───────┬──┬──┬──┬──┬───────┐
             │       │  │  │  │  │       │  50px
行线2  50px  ├───────┼──┼──┼──┼──┼───────┤
             │ 腮红左 │眼│  │  │眼│ 腮红右 │  1fr = 140px
行线3  190px ├───────┼──┴──┴──┴──┼───────┤
             │       │   鼻子     │       │  1fr = 140px
行线4  330px ├───────┴───────────┴───────┤
             │                           │  50px
行线5  380px └───────────────────────────┘
```

| 元素 | `grid-area` | 实际落点 |
| --- | --- | --- |
| 左眼 | `2 / 2 / 3 / 3` | 第 2 行、第 2 列（最左那个 25px 列） |
| 右眼 | `2 / 5 / 3 / 6` | 第 2 行、第 5 列（最右那个 25px 列） |
| 鼻子 | `3 / 2 / 4 / 6` | 第 3 行、第 2~6 列线之间（4×25 = 100px 宽） |
| 左腮红 | `2 / 1 / 3 / 2` | 第 2 行、第 1 列（左边 1fr），靠右下角 |
| 右腮红 | `2 / 6 / 3 / 7` | 第 2 行、第 6 列（右边 1fr），靠左下角 |

- 眼睛所在的第 2、5 列**恰好对称**：左眼在"中间四列的第一个"，右眼在"中间四列的最后一个"。
- 鼻子跨的是 4 个 25px 列，正好 100px，且没有写 `width`，靠默认 `justify-self: stretch` 撑满。
- 腮红各自独占一个 165px 的 1fr 列，但本身只有 40px 宽，所以要用 `justify-self` 把它推到靠近眼睛的那一侧。

## 四、逐条对照题目要求

### 1. 网格：6 列 4 行

```css
.face {
  display: grid;
  grid-template-columns: 1fr 25px 25px 25px 25px 1fr;
  grid-template-rows: 50px 1fr 1fr 50px;
}
```

- `display: grid` 让 `.face` 从普通块级容器变成网格容器，子元素不再按文档流堆叠，而是自动落进格子。
- 列模板里 `1fr` 在两端、`25px` 在中间 4 个，正是题干"前后两列两等分，中间 4 列均 25px"。
- 行模板 `50px 1fr 1fr 50px`：上下固定，中间两行平分剩余高度。
- `fr` 只分**剩余空间**：先扣掉固定的 25px×4 或 50px×2，再按份数分。

### 2. 眼睛：30×30、圆角 50%、居中

```css
.eye {
  width: 30px;
  height: 30px;
  background-color: #090b0e;
  border-radius: 50%;
  justify-self: center;
  align-self: center;
}
```

- `border-radius: 50%` 让 30×30 的方块变成正圆。
- 网格项的默认对齐是 `stretch`（撑满格子），而眼睛固定 30px，默认会**贴在格子左上角**，所以必须 `justify-self: center`。
- 垂直方向其实 `.face` 上原本就有 `align-items: center`，Grid 容器同样认这个属性，所以 `align-self: center` 是"保险写法"；只写 `justify-self` 也能过。
- 眼睛所在列只有 25px，比眼睛的 30px 还窄，居中后左右各溢出 2.5px——这是预期的，别以为是错位。

### 3. 鼻子：高 100%、上圆 50% 下圆 40%

```css
.nose {
  height: 100%;
  background-color: #3b464f;
  border-top-left-radius: 50%;
  border-top-right-radius: 50%;
  border-bottom-left-radius: 40%;
  border-bottom-right-radius: 40%;
  grid-area: 3 / 2 / 4 / 6;
}
```

- 只写 `height`，不写 `width`：默认 `justify-self: stretch` 让它撑满 4 个 25px 列，宽度自然是 100px。
- `height: 100%` 相对的是**所在网格区域**的高度（第 3 行 = 140px）。
- 四个角分开写，才能做到"上 50%、下 40%"；写一个 `border-radius: 50%` 会变成椭圆，不符合要求。
- `border-radius` 的百分比是**按盒子自身宽高分别计算**的：上左 50% = 水平 50px、垂直 70px。

### 4. 腮红：40×30、圆角 50%

```css
.blush {
  width: 40px;
  height: 30px;
  background-color: #f6b9bf;
  border-radius: 50%;
}

.blush.left  { grid-area: 2 / 1 / 3 / 2; justify-self: end;   align-self: end; }
.blush.right { grid-area: 2 / 6 / 3 / 7; justify-self: start; align-self: end; }
```

- 腮红落在第 1、6 列（两端 1fr 列），但要求它"贴着靠眼睛的一侧、且靠下"。
- `justify-self: end` → 靠该格子的**右边缘**；`start` → 靠**左边缘**。
- `align-self: end` → 靠格子**底边**，这样腮红和眼睛的下沿大致齐平。
- 40×30 加 50% 圆角，是一个横向椭圆。

### 5. 耳朵与层级：为什么脸能盖住耳朵

```css
.ears {
  display: flex;
  justify-content: space-between;
  position: relative;
  top: 240px;
  width: 550px;
}

.face {
  z-index: 1;
}
```

- `.container` 是 `flex-direction: column`，`.ears` 和 `.face` 依次竖排、水平居中。
- `.ears` 宽 550px、两个耳朵各 250px，`space-between` 把它们顶到左右两端，中间留 50px。
- `position: relative; top: 240px` 只做**视觉位移**，元素原本占的 250px 高度还在，所以脸会被顶到耳朵下方，然后耳朵再整体下移 240px，与脸的上半部分重叠。
- `.face` 的 `z-index: 1` 让它盖在耳朵上。注意：`.face` **没有写 `position`**，`z-index` 之所以生效，是因为它是 `.container`（flex 容器）的 **flex item**——flex item 和 grid item 都允许直接使用 `z-index`。

## 五、`grid-area` 四个值到底怎么数

语法：

```css
grid-area: <行始线> / <列始线> / <行终线> / <列终线>;
```

两个关键规则：

1. **网格线从 1 开始编号**，不是从 0；`n` 条轨道有 `n + 1` 条线。
2. **终线不包含**：`2 / 4` 表示"从第 2 条线到第 4 条线"，跨的是第 2、3 两条轨道。

以 `1fr 25px 25px 25px 25px 1fr` 为例：

```text
列轨道：   [ 1fr ][ 25px ][ 25px ][ 25px ][ 25px ][ 1fr ]
列线：     1      2       3       4       5       6      7
```

- 左眼 `2/2/3/3`：行线 2→3（第 2 行），列线 2→3（第 2 列）。
- 右眼 `2/5/3/6`：列线 5→6（第 5 列）。
- 鼻子 `3/2/4/6`：行 3，列线 2→6，跨 4 列。
- 左腮红 `2/1/3/2`：第 1 列；右腮红 `2/6/3/7`：第 6 列。

> [!warning] 最容易错的地方
> 把 `grid-area` 的 `2/2/3/3` 当成"第 2 行第 2 列、宽 3 高 3"。它其实是**四条线的坐标**，最后一个数不是跨度。

## 六、容易踩的坑

| 坑 | 后果 | 正确做法 |
| --- | --- | --- |
| 忘了 `display: grid` | 子元素全按普通流堆在左上角，鼻子撑满整张脸 | 先开网格 |
| `grid-template-columns` 写成 `1fr 1fr 25px 25px 25px 25px` | 两端不相等，眼睛偏左 | 两端各 `1fr`，或直接按题目顺序写 |
| 只写 `justify-self: center` 没写 `align-self` | 本题仍能过（`.face` 有 `align-items: center` 兜底） | 两个都写更稳 |
| 鼻子写了 `width: 40px` 之类 | 鼻子变窄，不跨 4 列 | 只写 `height: 100%`，靠默认 stretch |
| `border-radius` 只写一个 50% | 鼻子变成椭圆，不是上平下圆 | 四角分开写 |
| 把 `top: 240px` 改成 `margin-top: 240px` | 会额外撑高布局，脸被推得更低 | 保留 `position: relative` |
| 改了 `class` 名或文件路径 | 判分脚本找不到元素，直接 0 分 | 一个字都别动 |
| 提交时 Web Server 没开 | 检测端拿不到页面 | 先确认预览可访问 |

## 八、记忆口诀

> **列「一、四、一」——1fr、四个 25、1fr；行「五十、两等分、五十」。**
> **眼站 2 和 5，鼻子跨 2 到 6；腮红蹲 1、6 列，右下角里挤。**
