# 景深效果案例：用 JS 给 6 张叠图分别设置 `filter: blur()`

> [!info] 原题
> 蓝桥云课 · 为图片添加景深效果（题目 2161）· Web 前端「HTML + JS 功能实现」
> [题目链接](https://www.lanqiao.cn/problems/2161/learning/?page=1&first_category_id=2&tags=CSS3&tag_relation=union)

> [!summary] 速记版
> ```js
> document.querySelectorAll('img').forEach((img) => {
>   const isClear =
>     img.classList.contains('img1') || img.classList.contains('img2');
>   img.style.filter = isClear ? 'blur(0px)' : 'blur(2px)';
> });
> ```
> - 6 张 1920px 宽的 PNG 绝对定位叠成一张秋景：`img1` 枫叶林（底图）、`img2` 人物、`img3`~`img6` 前景枝叶。
> - `style06.css` 默认给所有 `img` 写了 `filter: blur(2px)`，所以页面一打开全是糊的。
> - 景深目标：**人物 + 身后枫叶林清晰，前景枝叶保持模糊**。
> - 必须用 JS 动态写 `element.style.filter`，**不能只写静态 CSS**。
> - `blur()` 的值是长度，非零时必须带单位：`blur(2px)`；写 `blur(2)` 是无效值。

## 考察内容

- **CSS 滤镜 `filter`**：`blur()` 模糊函数，值越大越模糊。
- **题干的两个提示属性**：`transform`（平移/旋转/缩放/倾斜）与 `filter`（模糊/颜色偏移）；本题真正用到的是 `filter`，`transform` 是干扰项。
- **JS DOM 操作**：`querySelectorAll` 选取、`forEach` 遍历、`classList.contains` 判断。
- **动态样式**：`element.style.filter = 'blur(0px)'` 写内联样式，覆盖外部样式表。
- **行内样式与样式表优先级**：行内样式 > 类选择器；带 `!important` 时例外。
- **CSS 值的合法性**：`blur()` 接受长度，`blur(2)` 不合法，`blur(2px)` 才生效。
- **绝对定位叠层**：6 个满屏 `div` 按 DOM 顺序绘制，后出现的盖在上面。
- **滤镜的副作用**：`filter ≠ none` 会创建层叠上下文和包含块。
- **动态效果 vs 静态 CSS**：题目明确禁止只改 CSS，判分可能检查 JS 写入的样式。

## 一、题目与初始代码

### 题目要求

## 二、答案

### 主答案：6 张图都显式设置

```js
// 获取所有图片
document.querySelectorAll('img').forEach((img) => {
  // img1 是枫叶林，img2 是人物：保持清晰
  // img3 ~ img6 是前景枝叶：保持模糊
  const isClear =
    img.classList.contains('img1') || img.classList.contains('img2');

  img.style.filter = isClear ? 'blur(0px)' : 'blur(2px)';
});
```

### 更短的写法：只处理需要变清晰的两张

```js
document.querySelectorAll('.img1, .img2').forEach((img) => {
  img.style.filter = 'blur(0px)';
});
```

这样写也能出效果，因为样式表已经把其余图片设成 `blur(2px)` 了。

> [!tip] 为什么建议把 `img3`~`img6` 也显式写一遍
> 题目强调「通过 JS 动态添加」。如果判分脚本读取的是 `img.style.filter`（**内联样式**），没赋值过的 `img3`~`img6` 会得到空字符串；显式写 `blur(2px)` 能让 6 张图都有内联值，既满足“动态”，又和原样式视觉一致。
>
> 如果判分读取 `getComputedStyle(img).filter`（**计算样式**），两种写法都能过。

| 判分方式 | 只写 `.img1, .img2` | 6 张都写 |
| --- | --- | --- |
| 读 `getComputedStyle().filter` | ✅ | ✅ |
| 读 `img.style.filter`（内联） | ❌ `img3`~`img6` 为空 | ✅ |
| 看截图 / 视觉效果 | ✅ | ✅ |

### 关于模糊值取多少

- 原样式就是 `blur(2px)`，前景继续用 `2px` 最贴近题目设计。
- 有些题解把前景写成 `blur(5px)`，视觉上更糊，但通常也能通过“清晰 / 模糊”的分组检测。
- 核心不是精确像素，而是 **`img1`、`img2` 的模糊值为 0，其余图片模糊值大于 0**。

## 三、逐行拆解

```js
const images = document.querySelectorAll('img');

images.forEach((image) => {
  if (image.classList.contains('img1') || image.classList.contains('img2')) {
    image.style.filter = 'blur(0px)';
  } else {
    image.style.filter = 'blur(2px)';
  }
});
```

| 代码 | 作用 | 细节 |
| --- | --- | --- |
| `document.querySelectorAll('img')` | 选中全部 6 张图 | 返回**静态 NodeList**，顺序就是 DOM 顺序 |
| `.forEach((image) => { … })` | 逐张处理 | `NodeList` 有 `forEach`；`HTMLCollection` 没有 |
| `image.classList.contains('img1')` | 判断类名 | 比 `className === 'img1'` 稳，允许多个类名 |
| `\|\|` | 两个类名满足一个即可 | `img1` 枫叶林、`img2` 人物 |
| `image.style.filter = 'blur(0px)'` | 动态写内联样式 | 覆盖外部样式表的 `blur(2px)` |
| `'blur(2px)'` | 其余图片保持模糊 | 与样式表默认值一致，视觉不变 |

### 为什么 `style.filter` 能覆盖样式表

```css
/* style06.css：类选择器，特异性 (0,1,0) */
header > div > img { filter: blur(2px); }
```

```js
// 行内样式，特异性最高（相当于 1,0,0,0）
img.style.filter = 'blur(2px)';
```

- 行内样式 > ID 选择器 > 类选择器 > 标签选择器。
- 唯一例外：样式表里写了 `!important`，而行内样式没写 `!important`。本题没有 `!important`，所以行内稳赢。
- `filter` 在 JS 里写成 **`style.filter`**（驼峰属性），不是 `style['filter']` 也行，但 `style.filter` 更常见。

## 四、页面为什么能叠成一张照片

```text
header（height: 160px; overflow: hidden）
┌──────────────────────────────────────┐
│ div（absolute, 满屏）                  │
│   img1  枫叶林（不透明底图）            │  ← DOM 最前，画在最底层
│   img2  人物（带透明通道）              │
│   img3  前景枝叶（带透明通道）          │
│   img4  前景枝叶                        │
│   img5  前景枝叶                        │
│   img6  前景枝叶                        │  ← DOM 最后，画在最顶层
└──────────────────────────────────────┘
```

- 6 个 `div` 都绝对定位、`width/height: 100%`，所以叠在同一个位置。
- 同层级、同 `z-index` 时，**后出现的元素盖在上面**，顺序就是 `img1 → img6`。
- `img1` 是不透明的完整底图；`img2`~`img6` 是带透明区域的切图，叠起来才是一张完整照片。
- 景深语义：`img1` 枫叶林在远处，`img2` 人物是主体，`img3`~`img6` 是靠近镜头的前景枝叶。
- 因此：**远处的底图和主体清晰，近处的前景模糊**，就是题目要的“景深”。

> [!warning] 不要把 `filter` 写在 `header` 或 `div` 上
> 给父级加 `filter: blur()` 会把里面的所有图片一起糊掉，无法只让部分图片清晰。
> 本题必须**逐张 `img` 分别设置**。

### CSS 里几个容易忽略的点

```css
header {
  height: 160px;
  position: relative;   /* 给绝对定位的 div 提供包含块 */
  overflow: hidden;     /* 裁掉超出 header 的部分 */
}

header > div {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  display: flex;            /* 用 flex 让图片在每层里居中 */
  justify-content: center;
  align-items: center;
}

header > div > img {
  width: 110%;              /* 略宽于容器，满幅裁切 */
  height: 100%;
  object-fit: cover;        /* 保持比例填满，多余部分裁掉 */
  transform: translatex(0); /* 无效果，干扰项 */
  filter: blur(2px);        /* 初始全模糊 */
}
```

- `position: relative` 让 `div` 的 `absolute` 相对 `header` 定位，而不是相对视口。
- `overflow: hidden` 把超出 `header` 的图片边缘裁掉；模糊会让边缘发虚，裁切后更干净。
- `object-fit: cover` 保证图片不变形地铺满层。
- `transform: translatex(0)` 只是“平移 0”，但它的存在说明题干提到的 `transform` 并不是本题答案。

## 五、`filter` 详解

### 5.1 语法

```css
filter: none;                          /* 默认，无滤镜 */
filter: blur(2px);                     /* 单个滤镜 */
filter: blur(2px) brightness(1.2);     /* 多个滤镜，空格分隔 */
```

- 多个滤镜**从左到右依次应用**，顺序会影响结果。
- `filter` 可以用于几乎所有元素，不只是图片。
- 可动画、可过渡（`transition: filter .3s`）。

### 5.2 `blur()`

```css
filter: blur(<length>);
```

| 写法 | 是否合法 | 说明 |
| --- | --- | --- |
| `blur(0px)` | ✅ | 不模糊，但仍是一个滤镜 |
| `blur(2px)` | ✅ | 轻微模糊 |
| `blur(10px)` | ✅ | 明显模糊 |
| `blur(0)` | ✅（浏览器容忍） | 0 可以省略单位，但判分字符串可能不认 |
| `blur(2)` | ❌ | 非零长度必须带单位 |
| `blur(-2px)` | ❌ | 不能为负 |
| `blur(50%)` | ❌ | 只接受长度，不接受百分比 |

- `blur()` 的半径本质是**高斯模糊的标准差**，值越大越糊。
- 建议统一写 `0px` / `2px`，不要写裸 `0`，避免和判分脚本的字符串比较对不上。

### 5.3 其他常用滤镜

| 函数 | 作用 | 示例 |
| --- | --- | --- |
| `blur()` | 高斯模糊 | `blur(4px)` |
| `brightness()` | 亮度 | `brightness(1.2)` |
| `contrast()` | 对比度 | `contrast(150%)` |
| `grayscale()` | 灰度 | `grayscale(100%)` |
| `sepia()` | 褐色怀旧 | `sepia(80%)` |
| `saturate()` | 饱和度 | `saturate(2)` |
| `hue-rotate()` | 色相旋转 | `hue-rotate(90deg)` |
| `invert()` | 反色 | `invert(1)` |
| `opacity()` | 透明度 | `opacity(0.5)` |
| `drop-shadow()` | 投影（跟随透明轮廓） | `drop-shadow(0 4px 6px #0008)` |

### 5.4 `filter` vs `backdrop-filter`

| 属性 | 作用对象 | 典型用途 |
| --- | --- | --- |
| `filter` | 元素**自身**（以及后代） | 图片模糊、变灰、调色 |
| `backdrop-filter` | 元素**背后**的内容 | 毛玻璃导航栏、磨砂弹窗 |

本题要模糊的是图片自己，所以用 `filter`，不是 `backdrop-filter`。

### 5.5 两个副作用

只要 `filter` 的计算值不是 `none`：

1. **创建层叠上下文（stacking context）**：即使写 `blur(0px)` 也会创建，影响 `z-index` 的比较范围。
2. **为绝对/固定定位的后代创建包含块**：后代元素的 `position: absolute/fixed` 会以它为参照。

本题每张 `img` 都是叶子节点，没有后代，所以这两个副作用不影响结果；但要知道它们存在。

### 5.6 性能

- `filter` 通常由 GPU 合成层处理，动画比改布局属性顺滑。
- 大面积实时模糊（尤其大图 + 大半径）仍可能掉帧。
- 静态景深只有 6 张图、`2px` 半径，开销可以忽略。

### 5.7 前缀

现代浏览器直接用 `filter`，不需要 `-webkit-filter`。老项目里看到的 `-webkit-filter` 是历史兼容写法。

## 六、JS 部分详解

### 6.1 `querySelectorAll`

```js
const images = document.querySelectorAll('img');          // 全部 img
const clear = document.querySelectorAll('.img1, .img2');  // 指定类名，逗号分隔
```

- 参数是 CSS 选择器字符串。
- 返回 `NodeList`，**静态快照**：之后 DOM 新增/删除元素，这个集合不会自动更新。

### 6.2 `NodeList` vs `HTMLCollection`

| 特性 | `NodeList`（`querySelectorAll`） | `HTMLCollection`（`getElementsByTagName`） |
| --- | --- | --- |
| 是否静态 | 静态 | 动态（live） |
| 有 `forEach` | ✅ | ❌ |
| 可用 `for...of` | ✅ | ✅（可迭代） |
| 转数组 | `Array.from(list)` / `[...list]` | 同上 |

所以：

```js
// ❌ 报错：HTMLCollection 没有 forEach
document.getElementsByTagName('img').forEach(...);

// ✅ 用 NodeList
document.querySelectorAll('img').forEach(...);
```

### 6.3 `forEach` 与箭头函数

```js
document.querySelectorAll('img').forEach((img) => {
  // ...
});
```

- 等价于 `for...of`：

```js
for (const img of document.querySelectorAll('img')) {
  // ...
}
```

- 箭头函数里 `this` 不绑定，本题不需要 `this`，无所谓。

### 6.4 `classList`

```js
img.classList.contains('img1');  // true / false
img.classList.add('clear');
img.classList.remove('clear');
img.classList.toggle('clear');
```

- `classList` 是类名集合，操作单个类名最安全。
- 不要写 `img.className.contains('img1')`：`className` 是字符串，字符串没有 `contains`（有 `includes`）。
- 用 `img.className === 'img1'` 也能判，但一旦元素有多个类名就失效。

### 6.5 `style` 属性命名

| CSS 属性 | JS 写法 |
| --- | --- |
| `filter` | `style.filter` |
| `background-color` | `style.backgroundColor` |
| `z-index` | `style.zIndex` |
| `transform` | `style.transform` |

- 连字符属性名转驼峰；`filter` 本身就是单词，直接 `style.filter`。
- 赋值必须是字符串：`img.style.filter = "blur(0px)"`。

### 6.6 行内样式与样式表

```js
img.style.filter = 'blur(0px)';
```

等价于在 HTML 上写：

```html
<img class="img1" style="filter: blur(0px);">
```

- 行内样式优先级最高（没有 `!important` 时）。
- 用 `img.style.filter = ''` 可以清空行内值，让样式表重新生效。

### 6.7 `<script>` 放哪

本题的 `<script>` 在 `<body>` 末尾，DOM 已经解析完，直接查询没问题。

如果放在 `<head>`，需要：

```js
document.addEventListener('DOMContentLoaded', () => {
  // 在这里查询 DOM
});
```

或者给 `<script>` 加 `defer`。

### 6.8 其他等价写法

```js
// 1. 只选需要清晰的两张
document.querySelectorAll('.img1, .img2').forEach((img) => {
  img.style.filter = 'blur(0px)';
});

// 2. 用 :not() 选其余图片
document.querySelectorAll('img:not(.img1):not(.img2)').forEach((img) => {
  img.style.filter = 'blur(2px)';
});

// 3. data 驱动
const filterMap = {
  img1: 'blur(0px)',
  img2: 'blur(0px)',
  img3: 'blur(2px)',
  img4: 'blur(2px)',
  img5: 'blur(2px)',
  img6: 'blur(2px)',
};

Object.entries(filterMap).forEach(([cls, value]) => {
  document.querySelector(`.${cls}`).style.filter = value;
});
```

## 七、错误写法对照

| 写法 | 结果 | 原因 |
| --- | --- | --- |
| 只在 CSS 里写 `.img1, .img2 { filter: blur(0px); }` | 视觉正确但可能 0 分 | 题目明确要求 JS 动态添加 |
| `img.style.filter = 'blur(2)'` | 无效果 | 非零长度必须带单位 `px` |
| `img.style.filter = 'blur(-2px)'` | 无效 | 模糊半径不能为负 |
| `img.style.filter = 'blur(50%)'` | 无效 | `blur()` 只接受长度，不接受百分比 |
| 给 `header` 加 `filter: blur(2px)` | 全部图片一起糊 | 滤镜作用于元素及后代，无法分组 |
| 给 `header > div` 加滤镜 | 整层一起糊 | 同上 |
| 只给 `.img1` 设清晰 | 人物仍然模糊 | 漏了 `img2` |
| 把 `img3`~`img6` 设成 `blur(0px)` | 前景清晰、主体也清晰，景深消失 | 分组反了 |
| 用 `filter: none` 处理 `img3`~`img6` | 前景变清晰 | `none` 等于关掉模糊 |
| `document.getElementsByTagName('img').forEach(...)` | 报错 | `HTMLCollection` 没有 `forEach` |
| `img.className.contains('img1')` | 报错 | 字符串没有 `contains`，应用 `classList.contains` |
| 修改类名 / 删除图片 / 改 DOM 结构 | 判分失败 | 题目禁止篡改 `id`、`class`、DOM |
| 用 `opacity` 冒充模糊 | 只是变透明 | 视觉和检测都不对 |
| 把 `<script>` 放 `<head>` 且不处理 DOMContentLoaded | 查询结果为空 | 脚本执行时图片还没解析 |
| CSS 里写 `filter: blur(2px) !important` | 行内 `style.filter` 覆盖失败 | `!important` 样式表声明压过普通行内样式 |
| 用 `blur` 属性名错误，如 `style.blur` | 不生效 | 没有 `style.blur`，必须 `style.filter` |

## 八、举一反三

### 1. 纯 CSS 版（只用于理解，不能提交）

```css
.img1,
.img2 {
  filter: blur(0px);
}

.img3,
.img4,
.img5,
.img6 {
  filter: blur(2px);
}
```

效果和 JS 版一致，但违反“必须 JS 动态”的要求。

### 2. 焦点切换动画（对焦拉风箱）

```js
const img = document.querySelector('.img1');
img.style.transition = 'filter .6s ease';
img.style.filter = 'blur(0px)';
```

- 从 `blur(2px)` 过渡到 `blur(0px)`，模拟相机对焦。
- `filter` 可动画，通常走合成层，性能比改 `width/height` 好。

### 3. 鼠标悬停时才清晰

```js
document.querySelectorAll('img').forEach((img) => {
  img.addEventListener('mouseenter', () => {
    img.style.filter = 'blur(0px)';
  });
  img.addEventListener('mouseleave', () => {
    img.style.filter = 'blur(2px)';
  });
});
```

### 4. 用 `data-*` 存模糊值

```html
<img class="img1" data-blur="0" src="...">
<img class="img3" data-blur="2" src="...">
```

```js
document.querySelectorAll('img').forEach((img) => {
  img.style.filter = `blur(${img.dataset.blur}px)`;
});
```

- 免去写死类名，新增图片只改 HTML 的 `data-blur`。
- 注意：题目禁止改 DOM 结构，这个方法只适合真实项目。

### 5. 其他滤镜组合

```js
img.style.filter = 'blur(2px) brightness(0.9)';
img.style.filter = 'grayscale(100%) contrast(120%)';
```

多个函数按顺序执行，顺序不同结果可能不同。

### 6. 毛玻璃卡片

```css
.card {
  backdrop-filter: blur(10px);
  background: rgba(255, 255, 255, 0.3);
}
```

- `backdrop-filter` 模糊的是卡片**背后**的内容，不是卡片自己。
- 和本题的 `filter` 要区分开。
