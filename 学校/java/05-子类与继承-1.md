## 一、判断题（共 9 题）

### 第 1 题
子类继承父类的构造方法。

- A. 对
- B. 错

> [!success]- 答案与解析
> **答案：错（B）**
>
> 构造方法不能被继承。父类构造方法的名字就是父类类名，它不会成为子类的构造方法；子类只能在自己的构造方法中用 `super(...)` 调用父类构造方法。

### 第 2 题
在子类中想使用被子类隐藏的实例成员变量或实例方法就需要使用关键字 `super`。

- A. 对
- B. 错

> [!success]- 答案与解析
> **答案：对（A）**
>
> 子类声明同名成员变量会“隐藏”父类变量，重写方法会“覆盖”父类方法；此时直接写 `x`、`f()` 访问的是子类自己的版本，要访问被隐藏/被覆盖的父类版本必须用 `super.x`、`super.f()`。

### 第 3 题
如果在子类的构造方法中没有显式地写出 `super` 关键字来调用父类的某个构造方法，那么编译器默认有“`super()`”调用父类的无参构造方法，如果父类没有这样的构造方法，代码将出现编译错误。

- A. 对
- B. 错

> [!success]- 答案与解析
> **答案：对（A）**
>
> 子类构造方法最终必须调用父类构造方法：若没显式写 `super(...)`（也没有用 `this(...)` 转调），编译器会自动插入 `super()`；父类若没有可访问的无参构造方法，就会编译错误。

### 第 4 题
子类继承的方法所操作的成员变量一定是被子类继承或隐藏的成员变量。

- A. 对
- B. 错

> [!success]- 答案与解析
> **答案：对（A）**
>
> 题干就是教材对「隐藏继承的成员变量」的原文描述：子类对象仍可调用从父类继承的方法去操作被隐藏的成员变量，也就是说，子类继承的方法所操作的成员变量一定是被子类继承或隐藏的成员变量。
>
> 注意与第 8 题对照：**继承来的**方法只能操作「继承的 / 被隐藏的」父类成员；而**子类新定义（重写或新增）的**方法操作的是子类自己新声明的成员，不能直接操作被隐藏的父类成员（要用 `super`）。

### 第 5 题
如果一个类的所有构造方法的访问权限都是 `private` 的，意味着这个类不能有子类。

- A. 对
- B. 错

> [!success]- 答案与解析
> **答案：对（A）**
>
> 子类构造方法必须调用父类构造方法，而 `private` 构造方法在类外（包括子类中）不可访问，因此子类无法通过编译，等价于“不能有子类”。

### 第 6 题
子类在执行方法重写时，不可以把父类的实例方法重写为类方法，也不可以把父类的静态方法重写为实例方法。

- A. 对
- B. 错

> [!success]- 答案与解析
> **答案：对（A）**
>
> Java 规定实例方法与 `static` 方法之间不能互相重写：父类实例方法被子类 `static` 方法“重写”、或父类 `static` 方法被子类实例方法“重写”，都会编译错误。

### 第 7 题
子类可以有多个超类。

- A. 对
- B. 错

> [!success]- 答案与解析
> **答案：错（B）**
>
> Java 类只支持单继承，一个类只能有一个直接超类；可以通过多层继承获得多个“祖先”，也可以通过实现多个接口扩展能力，但没有多继承。

### 第 8 题
子类重写或新增的方法也能直接操作被子类隐藏的成员变量。

- A. 对
- B. 错

> [!success]- 答案与解析
> **答案：错（B）**
>
> 「被子类隐藏的成员变量」指的是父类中那个被隐藏掉的变量。子类新定义（重写或新增）的方法里直接写变量名，操作的是**子类自己新声明**的那个变量；父类被隐藏的变量无法直接操作，必须用 `super.成员名` 访问。教材原话：“子类新定义的方法可以操作子类继承和子类新声明的成员变量，但无法操作子类隐藏的成员变量。”

### 第 9 题
一个超类可以有多个派生类。

- A. 对
- B. 错

> [!success]- 答案与解析
> **答案：对（A）**
>
> 一个超类可以被任意多个类继承（如 `Object` 是所有类的祖先），派生类数量不受限制。

## 二、单选题（共 3 题）

### 第 10 题
假设 C 是 B 的子类，B 是 A 的子类，`cat` 是 C 类的对象，`bird` 是 B 类的对象，下列表达式的值为 `false` 的是（ ）

- A. `cat instanceof B`
- B. `bird instanceof A`
- C. `cat instanceof A`
- D. `bird instanceof C`

> [!success]- 答案与解析
> **答案：D**
>
> `cat` 是 C 类对象，继承链 C → B → A，所以 `cat instanceof B`、`cat instanceof A` 均为 `true`；`bird` 是 B 类对象，`bird instanceof A` 为 `true`；但 `bird` 只是 B 的对象，不是 C 的对象（父类对象不可能是子类实例），故 `bird instanceof C` 为 `false`。

### 第 11 题
有超类定义如下：

```java
class A {
    public float getNum() {
        return 3.0f;
    }
}
```

下列关于派生类定义错误的是（ ）。

**A.**

```java
class B extends A {
    public float getNum() {
        return 4.0f;
    }
}
```

**B.**

```java
class B extends A {
    public void getNum() {
    }
}
```

**C.**

```java
class B extends A {
    public void getNum(double d) {
    }
}
```

**D.**

```java
class B extends A {
    public double getNum(float d) {
        return d;
    }
}
```

> [!success]- 答案与解析
> **答案：B**
>
> 方法重写要求：方法名相同、参数列表相同、返回类型兼容（相同或是其子类型）、访问权限不能更小。
> - A：返回类型 `float` 不变，是合法重写；
> - **B：参数列表相同但返回类型由 `float` 改成 `void`，不构成重写，编译错误**；
> - C：参数是 `double`，与父类 `getNum()` 参数列表不同，属于**重载**，合法；
> - D：参数是 `float`，同样属于**重载**，合法。

### 第 12 题
有代码如下：

```java
class A {
    public int i = 0;
    A(int m) {
        i = 1;
    }
}

public class B extends A {
    B(int m) {
        i = 2;
    }
    public static void main(String args[]) {
        B b = new B(100);
        System.out.println(b.i);
    }
}
```

下列叙述正确的是（ ）

- A. 程序提示编译错误
- B. 输出结果为 0
- C. 输出结果为 1
- D. 输出结果为 2

> [!success]- 答案与解析
> **答案：A**
>
> `B(int m)` 中没有显式调用 `super(...)`，编译器会插入 `super()`；但父类 A 只定义了带参构造方法 `A(int m)`，没有无参构造方法，因此 `super()` 找不到匹配，编译错误。
> 若改成 `B(int m) { super(m); i = 2; }`，则输出 2。

## 三、填空题（共 1 题）

### 第 13 题
有超类定义如下：

```java
class Dad {
    private int money = 12;
    float weight;
    Dad(int m, float w) {
        money = m;
        weight = w;
    }
    int getMoney() {
        return money
    }
    int setMoney(int m) {
        money = m;
    }
}
```

下列代码定义 Dad 类的派生类 Son，请参考注释文本，填写缺失的代码。

```java
_____________________ {            // 此处声明超类 Dad 的派生类 Son
    int weight；
    Son(int w) {
        ______________;            // 此处使用零值
        weight = w;
    }

    int lookAtMoney() {
        int m = ____________;      // 此处调用方法 getMoney
        return m;
    }
}
```

> 注：题干代码中的分号缺失、`int weight；` 使用中文分号等均按原题保留，未作改动。

> [!success]- 答案与解析
> | 空 | 答案 |
> |:---:|---|
> | 第 1 空 | `class Son extends Dad` |
> | 第 2 空 | `super(0, 0.0f)`（写成 `super(0, 0)` 也可编译） |
> | 第 3 空 | `super.getMoney()`（写成 `getMoney()` 也可编译） |
>
> **解析：**
> - **第 1 空**：声明 Dad 的派生类 Son，即 `class Son extends Dad`。
> - **第 2 空**：Dad 只提供了 `Dad(int m, float w)`，子类构造方法 `Son(int w)` 必须调用它；注释要求“使用零值”，故传 `0` 与 `0.0f`。注意 `super(0, 0.0)` 会因 `0.0` 是 `double` 而类型不匹配（`double` 不能自动转 `float`）。
> - **第 3 空**：`getMoney()` 是父类方法，子类未重写它，用 `super.getMoney()` 明确调用父类方法；由于没有同名方法遮蔽，直接写 `getMoney()` 同样正确。
>
> 完整代码示意：
> ```java
> class Son extends Dad {
>     int weight;
>     Son(int w) {
>         super(0, 0.0f);   // 调用父类构造方法，使用零值
>         weight = w;
>     }
>
>     int lookAtMoney() {
>         int m = super.getMoney();   // 调用父类方法 getMoney
>         return m;
>     }
> }
> ```
