## 使用约定

1. **笔记模板**：新建每日 / 每周任务与单词表时套用 `templates/` 下的模板，日期与命名由 Templater 脚本生成。
2. **单词命名**：`E` + 两位年份 + 月 + 日，重名时自动追加 `-2`、`-3`。
3. **附件就近存放**：`attachmentFolderPath` 为 `./`，图片与笔记同目录或同级 `img/` 中。
4. **标签**：常用标签如 `课表`、`Java`、`学习路线`，写在 frontmatter 的 `tags` 字段。
5. **双链优先**：知识点之间用 `[[双链]]` 关联，而非复制内容。
6. **自动生成文件勿手改**：[[学校/课表.md|课表]] 与 [[explorer-order.md|排序文件]] 由脚本 / 插件维护。

**AI 协作**（`.claude/`、`.claudian/`）：

- Claude Code 技能：`/查词`（批量生成词条写入 `英语/翻译功能.md` 的词条库）、`/翻译`（中英互译并附关键表达）。
- MCP 服务：`fetch`（网页抓取）与 `xt`（超星学习通，需本机 Python 环境）。
- 会话记录与本地设置已通过 `.gitignore` 排除，避免隐私外泄。

**版本控制与同步**：

- Git 自动备份提交（`vault backup: <时间>`）。
- `.gitignore` 只排除「每台机器不同 / 自动变化 / 含隐私」的文件：工作区布局、坚果云冲突产物（`*-冲突-*`）、AI 会话、插件运行时状态、系统临时文件。
- 插件代码与笔记一并纳入版本控制，便于灾难恢复。

## 维护建议

- **新增笔记**：先判断归属目录，再用对应模板创建，保持命名与标签一致。
- **定期复盘**：任务目录按月归档，单词表按日期自然排序，无需额外索引。
- **同步冲突**：坚果云产生的 `*-冲突-*` 文件已被忽略；若在本地看到，确认内容后合并再删除。
- **备份**：`git push` 是最后一道保险，重要改动后及时提交。
