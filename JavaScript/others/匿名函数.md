# 匿名函数

> 一句话：匿名函数就是**没有名字的函数**。它不能像函数声明那样单独站着，必须作为「值」使用——赋给变量、当作参数传给别人，或者写完后当场执行。

```js
// 有名字的函数声明
function greet() {
  console.log('hi');
}

// 匿名函数：右边的函数没有名字，整体是一个值
const greet2 = function () {
  console.log('hi');
};

greet2(); // hi
```

两者做的是同一件事，区别只在于「有没有名字」和「出现在哪里」。

---

## 一、先分清：函数声明 vs 函数表达式

### 1.1 两种写法

```js
// ① 函数声明（Function Declaration）
function sayHi() {
  console.log('Hello');
}

// ② 函数表达式（Function Expression）
const sayHi2 = function () {
  console.log('Hello');
};
```

`function` 后面没有名字、整体出现在 `=` 右边的，就是**匿名函数表达式**。

### 1.2 对比表

| | 函数声明 | 函数表达式（匿名） |
| --- | --- | --- |
| 是否必须写名字 | 是 | 否 |
| 语法位置 | 独立语句 | 表达式的一部分（`=`、参数、`return`…） |
| 提升 | 整体提升，定义前可调用 | 不提升，赋值前不可用 |
| 能否直接单独写 | 能 | **不能**（语法错误） |
| 常见用途 | 顶层工具函数 | 回调、一次性逻辑、赋值 |

### 1.3 为什么匿名函数不能单独写

```js
function () {
  console.log('hi');
}
// ❌ SyntaxError: Function statements require a function name
```

因为语句开头的 `function` 会被引擎当成**函数声明**，而声明必须有名字。想让它变成表达式，只要在前后加点东西：

```js
(function () {
  console.log('hi');
}); // ✅ 现在它是表达式，只是还没被调用
```

---

## 二、匿名函数的三个「去处」

匿名函数本身没有名字，所以必须有人接住它，或者立刻用掉它。

### 2.1 赋给变量或属性

```js
const add = function (a, b) {
  return a + b;
};

const obj = {
  greet: function () {
    console.log('hi');
  }
};

obj.greet(); // hi
```

### 2.2 作为参数传给别的函数（回调）

这是匿名函数最常见的场景：

```js
const nums = [1, 2, 3];

const doubled = nums.map(function (n) {
  return n * 2;
});

console.log(doubled); // [2, 4, 6]
```

### 2.3 写完立即执行（IIFE）

```js
(function () {
  console.log('只执行这一次');
})();
```

### 2.4 放进数组、作为返回值

```js
const actions = [
  function () { console.log('保存'); },
  function () { console.log('删除'); }
];

actions[0](); // 保存

function createAdder(n) {
  return function (x) {
    return x + n;
  };
}

const add5 = createAdder(5);
console.log(add5(3)); // 8
```

函数在 JS 里是**值**，所以凡是能放值的地方，都能放匿名函数。

---

## 三、回调：匿名函数的主场

### 3.1 数组方法

```js
const users = [
  { name: '小明', age: 18 },
  { name: '小红', age: 20 }
];

users.filter(function (user) {
  return user.age >= 18;
});

users.map(function (user) {
  return user.name;
});

users.forEach(function (user, index) {
  console.log(index, user.name);
});
```

### 3.2 定时器

```js
setTimeout(function () {
  console.log('1 秒后执行');
}, 1000);
```

### 3.3 事件监听

```js
button.addEventListener('click', function (event) {
  console.log('被点击了', event.target);
});
```

### 3.4 Promise

```js
fetch('/api/user')
  .then(function (res) {
    return res.json();
  })
  .then(function (data) {
    console.log(data);
  });
```

### 3.5 排序

```js
const nums = [3, 1, 4, 1, 5];

nums.sort(function (a, b) {
  return a - b;
});

console.log(nums); // [1, 1, 3, 4, 5]
```

这些地方的函数往往**只用一次**，给它起名字反而多余，这就是匿名函数的价值。

## 四、立即执行函数（IIFE）

IIFE = Immediately Invoked Function Expression，**定义完立刻调用**。

### 4.1 常见写法

```js
// 最标准：先包成表达式，再调用
(function () {
  console.log('run');
})();

// 调用括号放里面，效果一样
(function () {
  console.log('run');
}());

// 箭头函数版
(() => {
  console.log('run');
})();

// 用一元运算符把声明变成表达式
!function () {
  console.log('run');
}();

+function () {
  console.log('run');
}();
```

### 4.2 有什么用

**创建一个独立作用域，避免变量污染全局。**

在 `let` / `const` 和模块普及之前，这是隔离变量的主要手段：

```js
(function () {
  var secret = '内部变量';
  console.log(secret); // 内部变量
})();

// console.log(secret); // ❌ ReferenceError，外部拿不到
```

现在块级作用域也能做到：

```js
{
  let secret = '内部变量';
  console.log(secret);
}
// console.log(secret); // ❌ ReferenceError
```

所以现代代码里 IIFE 用得少了，但**读旧代码时必须认识它**，它也是「模块模式」的基础写法。

### 4.3 注意分号

如果上一行没有分号，下一行以 `(` 开头，可能被拼成函数调用：

```js
const a = 1
(function () {
  console.log('hi');
})()
// 被解析成：const a = 1(function () { ... })()
// ❌ TypeError: 1 is not a function
```

加上分号即可：

```js
const a = 1;
(function () {
  console.log('hi');
})();
```

## 五、箭头函数：匿名函数的简写

箭头函数**天生就是匿名的**，是匿名函数表达式的一种更短写法。

### 5.1 基本形式

```js
// 完整写法
const add = (a, b) => {
  return a + b;
};

// 一个参数：括号可省
const double = n => {
  return n * 2;
};

// 函数体只有一句 return：大括号和 return 都可省
const square = n => n * n;

// 没有参数：括号必须保留
const sayHi = () => console.log('hi');
```

### 5.2 返回对象字面量要加圆括号

```js
const makeUser = name => { name: name }; // ❌ 返回 undefined
const makeUser2 = name => ({ name: name }); // ✅ 返回对象
```

因为 `{` 会被当成**函数体**，不是对象。

### 5.3 与普通匿名函数的区别

| | 普通匿名函数 `function () {}` | 箭头函数 `() => {}` |
| --- | --- | --- |
| `this` | 调用时决定，可被 `call` / `apply` / `bind` 改变 | **词法作用域**，继承外层的 `this`，无法改变 |
| `arguments` | 有自己的 `arguments` 对象 | 没有，使用外层函数的 |
| 能否 `new` | 能（可作为构造函数） | **不能**，会抛 `TypeError` |
| `prototype` | 有 | 没有 |
| 能否做生成器 | 能（`function*`） | 不能 |
| 名字 | 可匿名也可具名 | 永远匿名 |
| 适合做 | 方法、构造函数、需要动态 `this` 的地方 | 回调、简单工具函数 |

### 5.4 `this` 的差异（最重要的坑）

```js
const obj = {
  name: '小明',
  sayLater() {
    setTimeout(function () {
      console.log(this.name); // ❌ this 是 window / undefined
    }, 0);

    setTimeout(() => {
      console.log(this.name); // ✅ 小明，继承 sayLater 的 this
    }, 0);
  }
};

obj.sayLater();
```

普通匿名函数的 `this` 由**调用方式**决定；箭头函数没有自己的 `this`，直接沿用**定义位置外层**的 `this`。

### 5.5 什么时候别用箭头函数

```js
// ❌ 对象方法：this 不是 obj
const obj = {
  name: '小明',
  say: () => console.log(this.name)
};

// ❌ 构造函数：箭头函数不能被 new
const Person = () => {};
new Person(); // TypeError

// ❌ 需要 arguments 的地方
const f = () => arguments[0]; // 用的是外层的 arguments
```

对象方法、构造函数、事件处理里需要 `this` 指向元素时，用普通函数更合适。

## 六、具名函数表达式（NFE）

匿名函数也能「给自己起个只在内部使用的名字」：

```js
const factorial = function fact(n) {
  return n <= 1 ? 1 : n * fact(n - 1);
};

console.log(factorial(5)); // 120

// fact 这个名字只存在于函数内部
// console.log(fact); // ❌ ReferenceError
```

好处有两个：

1. **递归时可以引用自己**，不必依赖外部变量名。
2. **调用栈里能看到名字**，调试时更清楚。

```js
const sum = function inner(n) {
  if (n <= 1) return 1;
  return n + inner(n - 1);
};
```

对比纯匿名写法：

```js
const factorial = function (n) {
  return n <= 1 ? 1 : n * factorial(n - 1);
};
```

这种写法靠外层变量 `factorial` 递归，只要变量被重新赋值就会出问题：

```js
let factorial = function (n) {
  return n <= 1 ? 1 : n * factorial(n - 1);
};

const original = factorial;
factorial = null;

// original(5); // ❌ TypeError: factorial is not a function
```

用 NFE 就不受影响。

> 补充：现代引擎会**推断**匿名函数的名字，`const f = function () {}` 的 `f.name` 是 `'f'`，调用栈也会显示 `f`。但这种推断依赖赋值形式，直接传进回调时通常拿不到。

## 七、匿名函数的优缺点

### 优点

- **写法短**：一次性逻辑不必先起名字。
- **不污染命名空间**：不会在作用域里留下多余标识符。
- **意图集中**：回调的代码就写在调用处，不用跳来跳去。
- **适合高阶函数**：`map` / `filter` / `then` / `addEventListener` 天然契合。

### 缺点

- **调试信息弱**：堆栈里容易显示 `anonymous`。
- **不能按名字递归**：除非用 NFE 或外部变量。
- **无法直接移除监听**：没有引用就 `removeEventListener` 不掉。
- **复用性差**：同一段逻辑写多次就只能复制。
- **太长时难读**：回调里塞几十行，不如抽成具名函数。

判断标准很简单：

> **只用一次、逻辑短 → 匿名；要复用、要递归、要移除、逻辑长 → 具名。**

## 八、常见坑

### 1. 匿名函数不能单独作为语句

```js
function () {} // ❌ SyntaxError
```

必须放进表达式上下文：

```js
const f = function () {}; // ✅
(function () {})();       // ✅
```

### 2. 函数表达式不会整体提升

```js
sayHi(); // ❌ TypeError: sayHi is not a function

var sayHi = function () {
  console.log('hi');
};
```

`var sayHi` 被提升了，但赋值发生在运行时，调用时它还是 `undefined`。

用 `const` / `let` 则是另一种错误：

```js
sayHi(); // ❌ ReferenceError: Cannot access 'sayHi' before initialization

const sayHi = function () {
  console.log('hi');
};
```

这叫**暂时性死区（TDZ）**——变量存在，但初始化前不能访问。

对比函数声明：

```js
sayHi(); // ✅ 正常执行

function sayHi() {
  console.log('hi');
}
```

### 3. 匿名函数递归会踩变量被改的坑

见「六、具名函数表达式」。需要递归时优先用 NFE。

### 4. 移除事件监听需要同一个引用

```js
// ❌ 无法移除：每次都是新的函数对象
button.addEventListener('click', function () {
  console.log('clicked');
});

button.removeEventListener('click', function () {
  console.log('clicked');
});
```

必须先把函数存起来：

```js
function onClick() {
  console.log('clicked');
}

button.addEventListener('click', onClick);
button.removeEventListener('click', onClick); // ✅
```

### 5. 箭头函数的 `this` 不会指向调用者

```js
const obj = {
  name: '小明',
  say: () => {
    console.log(this.name); // ❌ 不是 '小明'
  }
};
```

对象方法用普通函数或方法简写：

```js
const obj = {
  name: '小明',
  say() {
    console.log(this.name); // ✅ 小明
  }
};
```

### 6. 箭头函数不能当构造函数

```js
const Person = (name) => {
  this.name = name;
};

new Person('小明');
// ❌ TypeError: Person is not a constructor
```

### 7. 箭头函数没有自己的 `arguments`

```js
function outer() {
  const inner = () => arguments[0];
  return inner();
}

console.log(outer('hello')); // hello，拿到的是 outer 的 arguments
```

需要自己的参数列表时用 rest：

```js
const f = (...args) => args[0];
console.log(f(1, 2)); // 1
```

### 8. 返回对象要加括号

```js
const f = () => { name: '小明' };  // ❌ undefined
const g = () => ({ name: '小明' }); // ✅ 对象
```

### 9. `var` 循环里的匿名回调共享同一个变量

```js
for (var i = 0; i < 3; i++) {
  setTimeout(function () {
    console.log(i); // 3 3 3
  }, 0);
}
```

回调执行时循环早已结束，`i` 是最后的值。用 `let` 或 IIFE 解决：

```js
for (let i = 0; i < 3; i++) {
  setTimeout(function () {
    console.log(i); // 0 1 2
  }, 0);
}
```

### 10. 上一行没分号，下一行以 `(` 开头

```js
const f = function () {}

(function () {
  console.log('hi');
})()
// 被解析成 const f = function () {}(function () { ... })()
// ❌ TypeError
```

养成写分号的习惯，或在行首补分号：

```js
const f = function () {};
(function () {
  console.log('hi');
})();
```

### 11. 匿名不代表 `name` 一定为空

```js
const f = function () {};
console.log(f.name); // 'f'（现代引擎推断）

console.log((function () {}).name); // ''
console.log((() => {}).name);       // ''
```

不要把 `.name` 当作可靠的判断依据。

### 12. 方法简写不是匿名函数

```js
const obj = {
  say() {
    console.log('hi');
  }
};

console.log(obj.say.name); // 'say'
```

`say() {}` 是**方法简写**，它有名字，也和普通函数表达式有一些细微差别（不能当构造函数）。

## 九、速查表

### 9.1 三种常见函数写法

```js
// 函数声明
function f(a, b) { return a + b; }

// 匿名函数表达式
const f = function (a, b) { return a + b; };

// 箭头函数（也是匿名）
const f = (a, b) => a + b;
```

### 9.2 语法对照

| 写法 | 例子 | 说明 |
| --- | --- | --- |
| 函数声明 | `function f() {}` | 有名字，会提升 |
| 匿名函数表达式 | `const f = function () {}` | 赋值给变量 |
| 具名函数表达式 | `const f = function g() {}` | `g` 只在内部可见 |
| 箭头函数 | `const f = () => {}` | 永远匿名，无自己的 `this` |
| IIFE | `(function () {})()` | 定义后立即执行 |
| 方法简写 | `{ f() {} }` | 有名字，不是匿名 |

### 9.3 箭头函数 vs 普通函数

| 特性 | 普通函数 | 箭头函数 |
| --- | --- | --- |
| `this` | 调用时绑定 | 定义时继承 |
| `arguments` | 有 | 无 |
| `new` | 可以 | 不可以 |
| `prototype` | 有 | 无 |
| 生成器 | 可以 | 不可以 |
| 适合 | 方法、构造、动态 `this` | 回调、短函数 |

### 9.4 什么时候用哪种

| 场景 | 推荐 |
| --- | --- |
| 数组 `map` / `filter` / `reduce` | 箭头函数 |
| `setTimeout` 回调 | 箭头函数（想继承 `this` 时） |
| 事件监听、需要 `this` 指向元素 | 普通函数 |
| 对象方法 | 方法简写 `say() {}` |
| 构造函数 / `class` | 普通函数 / `class` |
| 需要递归 | 具名函数声明或 NFE |
| 需要 `removeEventListener` | 具名函数或先存变量 |
| 初始化隔离作用域 | IIFE 或块级作用域 |

> 记忆口诀：**匿名函数是值，必须有人接；回调最常用，箭头最省事；要递归就起名，要移除先存住。**
