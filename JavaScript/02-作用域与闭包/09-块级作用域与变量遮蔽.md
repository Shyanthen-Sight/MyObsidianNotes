# 第 9 讲：块级作用域与变量遮蔽（Block Scope & Shadowing in JS）

> [!abstract] 本讲要点
> - 块（Block）又称复合语句，用 `{...}` 把多条语句组合成一组。
> - let 和 const 具有块级作用域，而 var 被提升到全局作用域。
> - 遮蔽（Shadowing）指内层同名变量遮盖外层变量，var 的遮蔽会修改外层的值。
> - 不能直接用 var 遮蔽 let（非法遮蔽），否则会抛出 SyntaxError。

## 一、什么是块

**块**（Block）是什么？

- 块又称*复合语句*（compound statement），用于把 JS 语句组合成一组。我们用 `{...}` 将它们组合起来。

  ```js
  {
    var a = 10;
    let b = 20;
    const c = 30;
    // 这里 let 和 const 被提升到块作用域中，
    // 而 var 被提升到全局作用域中。
  }
  ```

## 二、块级作用域及其可访问性

- 块级作用域及其可访问性的示例：

  ```js
  {
    var a = 10;
    let b = 20;
    const c = 30;
  }
  console.log(a); // 10
  console.log(b); // Uncaught ReferenceError: b is not defined
  ```

- 原因？

  - 在块作用域中，作为提升的一部分，b 和 c 在块内部被初始化为 _undefined_（存放在一个称为 **block** 的独立内存空间中）。
  - 而 a 存储在全局作用域中。
  - 因此我们说，_let_ 和 _const_ 是块级作用域的（BLOCK SCOPED）。它们被存储在为该块保留的独立内存空间中，并且无法在这个块之外访问。而 var a 因为位于全局作用域，所以可以在任何地方访问。因此，我们无法在块外访问 b 和 c。

## 三、什么是遮蔽

**遮蔽**（Shadowing）是什么？

- ```js
  var a = 100;
  {
    var a = 10; // 与全局 var 同名
    let b = 20;
    const c = 30;
    console.log(a); // 10
    console.log(b); // 20
    console.log(c); // 30
  }
  console.log(a); // 10，而不是我们期望的 100。也就是说，块中的 "a" 同时修改了全局 "a" 的值。在控制台中，块空间里只有 b 和 c。a 最初在全局空间（a = 100），当执行 a = 10 这一行时，块空间里并不会新建 a，而是直接在全局空间把 100 替换成 10。
  ```

- 因此，如果块外部有同名变量，块内部的变量会*遮蔽*（shadow）外部变量。**这种情况只发生在 var 上。**

- 下面观察 let 和 const 的表现，并理解其原因。

  ```js
  let b = 100;
  {
    var a = 10;
    let b = 20;
    const c = 30;
    console.log(b); // 20
  }
  console.log(b); // 100，两个 b 位于不同空间（一个在 Block(20)，一个在 Script(另一个任意内存空间)(100)）。*const* 声明也是如此。
  ```

  ![块级作用域示意图](scope.jpg "块级作用域")

- 同样的逻辑也适用于**函数**。

  ```js
  const c = 100;
  function x() {
    const c = 10;
    console.log(c); // 10
  }
  x();
  console.log(c); // 100
  ```

## 四、什么是非法遮蔽

**非法遮蔽**（Illegal Shadowing）是什么？

- ```js
  let a = 20;
  {
    var a = 20;
  }
  // Uncaught SyntaxError: Identifier 'a' has already been declared
  ```

  - 我们不能用 var 遮蔽 let。但用 let 遮蔽 let 是**合法的**。不过，我们可以用 let 遮蔽 var。
  - 在函数中生效的所有作用域规则，在箭头函数中同样适用。
  - 由于 var 是函数作用域的，下面的代码没有问题。

    ```js
    let a = 20;
    function x() {
      var a = 20;
    }
    ```
