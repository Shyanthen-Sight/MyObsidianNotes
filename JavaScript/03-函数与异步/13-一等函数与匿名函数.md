# 第 13 讲：一等函数与匿名函数（First Class Functions ft. Anonymous Functions）

> 函数是 JavaScript 的心脏 ♥。

> [!abstract] 本讲要点
> - 函数语句会在内存创建阶段被提升，函数表达式则像变量一样先被赋值为 `undefined`。
> - 匿名函数没有名字，单独作为语句书写会抛出语法错误，通常只作为值使用。
> - 具名函数表达式的名字只在该函数内部可见，不会出现在全局作用域。
> - 一等函数指函数可以像值一样被传递、返回和赋值。

## 一、什么是函数语句（Function Statement）？

以下创建函数的方式就是函数语句。

```js
function a() {
  console.log("Hello");
}
a(); // Hello
```

## 二、什么是函数表达式（Function Expression）？

把一个函数赋值给一个变量。此时函数就像一个值。

```js
var b = function () {
  console.log("Hello");
};
b();
```

## 三、函数语句与函数表达式的区别

两者的主要区别在于**提升（Hoisting）**。

```js
a(); // "Hello A"
b(); // TypeError
function a() {
  console.log("Hello A");
}
var b = function () {
  console.log("Hello B");
};
// 为什么？在内存创建阶段，a 会被创建到内存中并把函数赋值给 a。但 b 是像变量一样被创建的（b: undefined），在代码执行到 function() 那部分之前，它一直是 undefined。因此 b 无法被调用。
```

> [!note] 理解要点
> 函数语句在内存创建阶段就整体可用，函数表达式只先得到一个值为 `undefined` 的变量，必须等执行到赋值那一行才真正成为函数。

## 四、什么是函数声明（Function Declaration）？

**函数语句**的另一个名称。

## 五、什么是匿名函数（Anonymous Function）？

没有名字的函数。

```js
function () {

}// 这会抛出语法错误（Syntax Error）——函数语句必须要有函数名。
```

- 它们没有自己的标识（identity）。因此，一个内部没有代码的匿名函数会导致错误。
- 匿名函数用于把函数当作值使用的地方，例如上文中**函数表达式**的示例。

## 六、什么是具名函数表达式（Named Function Expression）？

与函数表达式相同，只是函数拥有名字，而不是匿名的。

```js
var b = function xyz() {
  console.log("b called");
};
b(); // "b called"
xyz(); // 抛出 ReferenceError: xyz is not defined。
// xyz 函数并没有在全局作用域中创建，因此无法调用。
```

## 七、形参与实参（Parameters vs Arguments）

```js
var b = function (param1, param2) {
  // 标签/标识符就是形参（parameters）
  console.log("b called");
};
b(arg1, arg2); // 实参（arguments）——在函数调用中传入的值
```

## 八、什么是一等函数（First Class Function），又称一等公民？

我们可以把函数作为参数传入另一个函数，也可以从函数中返回一个函数（HOF，高阶函数）。这些能力统称为一等函数。它也是一种编程概念，在其他一些语言中同样存在。

```js
var b = function (param1) {
  console.log(param1); // 打印 " f() {} "
};
b(function () {});

// 实现同一件事的另一种方式：
var b = function (param1) {
  console.log(param1);
};
function xyz() {}
b(xyz); // 与上一段代码效果相同

// 我们也可以从函数中返回一个函数：
var b = function (param1) {
  return function () {};
};
console.log(b()); // 打印出 b 中返回的整个函数
```

> [!warning] 常见坑
> 匿名函数不能单独作为函数语句存在，只能作为值（例如函数表达式、回调函数）使用。
